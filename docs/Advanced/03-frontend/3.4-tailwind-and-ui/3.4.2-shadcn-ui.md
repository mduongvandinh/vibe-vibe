# 3.4.2 Copy paste là dùng được——shadcn/ui

### Tóm tắt một câu

shadcn/ui không phải npm package, mà là high-quality component code có thể copy vào project, bạn có toàn quyền kiểm soát.

### Giá trị cốt lõi

Component libraries truyền thống (như Ant Design, MUI) là black box—bạn dùng components của họ, customize theo rules của họ. shadcn/ui khác: component code được copy trực tiếp vào project của bạn, bạn có thể tùy ý modify.

### shadcn/ui vs Component libraries truyền thống

| Đặc tính | shadcn/ui | Component library truyền thống |
|------|-----------|------------|
| Cách cài đặt | Copy code vào project | npm install |
| Khả năng tùy chỉnh | Hoàn toàn kiểm soát | Bị giới hạn bởi API |
| Cách update | Update thủ công | npm update |
| Kích thước | Chỉ bao gồm cái dùng | Có thể thừa code |
| Chi phí học tập | Thấp (React chuẩn) | Cần học API cụ thể |

### Bắt đầu nhanh

**1. Khởi tạo**

```bash
npx shadcn@latest init
```

Chọn cấu hình:
- Style: Default
- Base color: Slate
- CSS variables: Yes

**2. Thêm components**

```bash
# Thêm single component
npx shadcn@latest add button

# Thêm nhiều components
npx shadcn@latest add card input label

# Xem tất cả components có sẵn
npx shadcn@latest add
```

**3. Sử dụng components**

```tsx
import { Button } from "@/components/ui/button"
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card"
import { Input } from "@/components/ui/input"

export function LoginForm() {
  return (
    <Card className="w-[400px]">
      <CardHeader>
        <CardTitle>Đăng nhập</CardTitle>
      </CardHeader>
      <CardContent className="space-y-4">
        <Input placeholder="Email" type="email" />
        <Input placeholder="Mật khẩu" type="password" />
        <Button className="w-full">Đăng nhập</Button>
      </CardContent>
    </Card>
  )
}
```

### Overview components thường dùng

| Component | Mục đích | Lệnh cài đặt |
|------|------|----------|
| `Button` | Nút bấm | `add button` |
| `Input` | Input box | `add input` |
| `Card` | Card container | `add card` |
| `Dialog` | Modal/popup | `add dialog` |
| `Select` | Dropdown select | `add select` |
| `Table` | Bảng | `add table` |
| `Form` | Form (có validation) | `add form` |
| `Toast` | Notification message | `add toast` |

### Component variants

shadcn/ui components thường cung cấp nhiều variants:

```tsx
// Button variants
<Button variant="default">Mặc định</Button>
<Button variant="secondary">Phụ</Button>
<Button variant="outline">Viền</Button>
<Button variant="ghost">Ghost</Button>
<Button variant="destructive">Nguy hiểm</Button>

// Sizes
<Button size="sm">Nhỏ</Button>
<Button size="default">Vừa</Button>
<Button size="lg">Lớn</Button>
```

### Tùy chỉnh components

Component code ở thư mục `components/ui/`, có thể modify trực tiếp:

```tsx
// components/ui/button.tsx
const buttonVariants = cva(
  "inline-flex items-center justify-center rounded-md text-sm font-medium...",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground hover:bg-primary/90",
        // Thêm custom variant
        brand: "bg-brand-500 text-white hover:bg-brand-600",
      },
      // ...
    },
  }
)
```

### Hàm tiện ích cn()

shadcn/ui sử dụng `cn()` để merge class names:

```tsx
import { cn } from "@/lib/utils"

// Merge default classes và custom classes
<Button className={cn("w-full", isLoading && "opacity-50")}>
  Submit
</Button>
```

### Tích hợp form

Form component của shadcn/ui tích hợp sâu với react-hook-form:

```bash
npx shadcn@latest add form
```

```tsx
import { useForm } from "react-hook-form"
import { zodResolver } from "@hookform/resolvers/zod"
import { z } from "zod"
import { Form, FormControl, FormField, FormItem, FormLabel, FormMessage } from "@/components/ui/form"

const formSchema = z.object({
  email: z.string().email("Vui lòng nhập email hợp lệ"),
  password: z.string().min(6, "Mật khẩu ít nhất 6 ký tự"),
})

export function LoginForm() {
  const form = useForm<z.infer<typeof formSchema>>({
    resolver: zodResolver(formSchema),
  })

  function onSubmit(values: z.infer<typeof formSchema>) {
    console.log(values)
  }

  return (
    <Form {...form}>
      <form onSubmit={form.handleSubmit(onSubmit)} className="space-y-4">
        <FormField
          control={form.control}
          name="email"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Email</FormLabel>
              <FormControl>
                <Input placeholder="your@email.com" {...field} />
              </FormControl>
              <FormMessage />
            </FormItem>
          )}
        />
        <Button type="submit">Đăng nhập</Button>
      </form>
    </Form>
  )
}
```

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Để AI sử dụng shadcn/ui components xây dựng UI.

**Công thức định nghĩa yêu cầu**:
- Mô tả chức năng: Tôi cần một giao diện [chức năng]
- Yêu cầu component: Sử dụng [danh sách components] của shadcn/ui
- Yêu cầu styling: [Tailwind classes bổ sung]

**Thuật ngữ chính**: `shadcn/ui`, `variant`, `cn()`, `Form`, `react-hook-form`

**Chiến lược tương tác**:
1. Trước tiên xác nhận cần shadcn components nào
2. Để AI generate code sử dụng các components này
3. Nếu cần form validation, chỉ định dùng Form + zod

### Hướng dẫn tránh hố

1. **Cài trước khi dùng**: Components không tự động cài, cần `add` thủ công
2. **Path alias**: Đảm bảo `@/components/ui` path được config đúng
3. **Dependencies**: Một số components phụ thuộc components khác, sẽ tự động cài cùng
4. **Dark mode**: Cần config ThemeProvider trong `layout.tsx`

### Checklist nghiệm thu

- [ ] Components cài đúng vào `components/ui/`
- [ ] Import paths dùng `@/components/ui/xxx`
- [ ] Sử dụng `cn()` để merge thêm class names
- [ ] Forms dùng Form component và config validation
