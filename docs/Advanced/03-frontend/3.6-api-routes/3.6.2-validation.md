# 3.6.2 Chặn request bất hợp lệ như thế nào——Validate request

### Tóm tắt một câu

Đừng bao giờ tin data từ client——dùng Zod validate ở cửa vào, chặn dirty data bên ngoài.

### Giá trị cốt lõi

User có thể nhầm lẫn, crawler có thể bừa bãi, attacker có thể cố tình tạo request độc hại. Param validation là tuyến phòng thủ đầu tiên của API, cũng là chìa khóa đảm bảo type safety.

### Tại sao chọn Zod?

| Phương án | Ưu điểm | Nhược điểm |
|------|------|------|
| **Validate thủ công** | Không dependency | Rườm rà, không type-safe |
| **JSON Schema** | Chuẩn hóa | Cú pháp phức tạp, type inference kém |
| **Zod** | Type inference, ngắn gọn, ecosystem tốt | Cần thêm dependency |

```tsx
// Validate thủ công (rườm rà và không type-safe)
if (!body.title || typeof body.title !== 'string') {
  return Response.json({ error: 'Tiêu đề bắt buộc' }, { status: 400 })
}
if (body.title.length < 3) {
  return Response.json({ error: 'Tiêu đề tối thiểu 3 ký tự' }, { status: 400 })
}
// ... còn rất nhiều field

// Validate với Zod (ngắn gọn và type-safe)
const result = schema.safeParse(body)
if (!result.success) {
  return Response.json({ error: result.error }, { status: 400 })
}
// result.data tự động có type
```

### Zod cơ bản

**Cài đặt**:

```bash
npm install zod
```

**Định nghĩa Schema**:

```tsx
import { z } from 'zod'

// Kiểu cơ bản
const stringSchema = z.string()
const numberSchema = z.number()
const booleanSchema = z.boolean()

// Object Schema
const userSchema = z.object({
  name: z.string().min(2, 'Tên tối thiểu 2 ký tự'),
  email: z.string().email('Định dạng email không đúng'),
  age: z.number().min(0).max(150).optional(),
})

// Infer TypeScript type từ Schema
type User = z.infer<typeof userSchema>
// { name: string; email: string; age?: number }
```

### Quy tắc validation thường dùng

**String**:

```tsx
z.string()
  .min(1, 'Không được để trống')
  .max(100, 'Tối đa 100 ký tự')
  .email('Định dạng email không đúng')
  .url('Định dạng URL không đúng')
  .regex(/^[a-z]+$/, 'Chỉ được chứa chữ thường')
  .trim() // Tự động xóa khoảng trắng đầu cuối
  .toLowerCase() // Tự động chuyển thành chữ thường
```

**Number**:

```tsx
z.number()
  .min(0, 'Không được âm')
  .max(100, 'Tối đa 100')
  .int('Phải là số nguyên')
  .positive('Phải là số dương')

// Convert string thành number (thường dùng cho query parameter)
z.coerce.number()
```

**Array**:

```tsx
z.array(z.string())
  .min(1, 'Ít nhất chọn 1 mục')
  .max(10, 'Tối đa chọn 10 mục')
```

**Enum**:

```tsx
z.enum(['pending', 'published', 'archived'])

// Hoặc dùng union
z.union([z.literal('pending'), z.literal('published')])
```

**Optional và default value**:

```tsx
z.string().optional()           // string | undefined
z.string().nullable()           // string | null
z.string().default('untitled')  // Giá trị mặc định
```

### Sử dụng trong API Route

```tsx
// lib/validations/post.ts
import { z } from 'zod'

export const createPostSchema = z.object({
  title: z.string().min(3, 'Tiêu đề tối thiểu 3 ký tự').max(100),
  content: z.string().min(10, 'Nội dung tối thiểu 10 ký tự'),
  published: z.boolean().default(false),
  tags: z.array(z.string()).optional(),
})

export const updatePostSchema = createPostSchema.partial()

export const queryPostsSchema = z.object({
  page: z.coerce.number().min(1).default(1),
  limit: z.coerce.number().min(1).max(100).default(10),
  status: z.enum(['draft', 'published']).optional(),
})

export type CreatePostInput = z.infer<typeof createPostSchema>
```

```tsx
// app/api/posts/route.ts
import { createPostSchema, queryPostsSchema } from '@/lib/validations/post'

export async function GET(request: Request) {
  const { searchParams } = new URL(request.url)
  const query = Object.fromEntries(searchParams)

  const result = queryPostsSchema.safeParse(query)
  if (!result.success) {
    return Response.json(
      { error: result.error.flatten() },
      { status: 400 }
    )
  }

  const { page, limit, status } = result.data
  // Bây giờ page và limit đều là kiểu number
}

export async function POST(request: Request) {
  const body = await request.json()

  const result = createPostSchema.safeParse(body)
  if (!result.success) {
    return Response.json(
      { error: result.error.flatten() },
      { status: 400 }
    )
  }

  // result.data có kiểu CreatePostInput
  const post = await postService.create(result.data)
  return Response.json(post, { status: 201 })
}
```

### Đóng gói validation function

```tsx
// lib/validate.ts
import { z, ZodSchema } from 'zod'

export function validate<T>(schema: ZodSchema<T>, data: unknown):
  | { success: true; data: T }
  | { success: false; error: Response } {

  const result = schema.safeParse(data)

  if (!result.success) {
    return {
      success: false,
      error: Response.json(
        { error: { code: 'VALIDATION_ERROR', details: result.error.flatten() } },
        { status: 400 }
      ),
    }
  }

  return { success: true, data: result.data }
}

// Sử dụng
export async function POST(request: Request) {
  const body = await request.json()
  const validation = validate(createPostSchema, body)

  if (!validation.success) {
    return validation.error
  }

  // validation.data đã type-safe
}
```

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Để AI generate param validation type-safe.

**Công thức định nghĩa yêu cầu**:
- Mô tả chức năng: Validate request tạo/update [resource]
- Yêu cầu field: [tên field]: [kiểu], [quy tắc validation]
- Yêu cầu kỹ thuật: Sử dụng Zod, export type

**Thuật ngữ chính**: `Zod`, `safeParse`, `z.infer`, `flatten`

**Ví dụ Prompt**:

```
Vui lòng dùng Zod tạo validation schema cho đăng ký user:
- username: bắt buộc, 3-20 ký tự, chỉ chứa chữ số và gạch dưới
- email: bắt buộc, định dạng email hợp lệ
- password: bắt buộc, tối thiểu 8 ký tự, chứa chữ hoa chữ thường và số
- confirmPassword: phải giống password
- age: optional, số nguyên từ 18-100
Export type và validation function
```

### Hướng dẫn tránh hố

1. **Query parameter đều là string**: Dùng `z.coerce` để convert kiểu
2. **parse vs safeParse**: `parse` sẽ throw error, `safeParse` trả về result object
3. **partial vs pick**: `partial` làm tất cả field optional, `pick` chọn một số field
4. **Thông báo lỗi phải thân thiện**: Cung cấp hướng dẫn rõ ràng bằng tiếng Việt
