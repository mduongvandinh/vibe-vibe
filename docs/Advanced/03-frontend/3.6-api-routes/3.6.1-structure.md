# 3.6.1 API của bạn trông như thế nào——Cấu trúc API Route

### Tóm tắt một câu

Trong App Router, file `route.ts` định nghĩa API endpoint bằng cách export named function, tên function chính là HTTP method.

### Giá trị cốt lõi

Next.js Route Handler cho phép bạn implement API ngay trong cùng project mà không cần dựng server backend riêng. Rất tiện lợi cho fullstack app và rapid prototyping.

### Tạo Route Handler

Tạo file `route.ts` trong thư mục `app`:

```
app/
└── api/
    └── posts/
        ├── route.ts          # /api/posts
        └── [id]/
            └── route.ts      # /api/posts/:id
```

### Cú pháp cơ bản

```tsx
// app/api/posts/route.ts

// GET /api/posts - Lấy danh sách
export async function GET(request: Request) {
  const posts = await prisma.post.findMany()
  return Response.json(posts)
}

// POST /api/posts - Tạo resource
export async function POST(request: Request) {
  const body = await request.json()
  const post = await prisma.post.create({ data: body })
  return Response.json(post, { status: 201 })
}
```

```tsx
// app/api/posts/[id]/route.ts

// GET /api/posts/:id - Lấy single resource
export async function GET(
  request: Request,
  { params }: { params: { id: string } }
) {
  const post = await prisma.post.findUnique({
    where: { id: params.id }
  })

  if (!post) {
    return Response.json({ error: 'Not found' }, { status: 404 })
  }

  return Response.json(post)
}

// PUT /api/posts/:id - Update resource
export async function PUT(
  request: Request,
  { params }: { params: { id: string } }
) {
  const body = await request.json()
  const post = await prisma.post.update({
    where: { id: params.id },
    data: body
  })
  return Response.json(post)
}

// DELETE /api/posts/:id - Xóa resource
export async function DELETE(
  request: Request,
  { params }: { params: { id: string } }
) {
  await prisma.post.delete({ where: { id: params.id } })
  return new Response(null, { status: 204 })
}
```

### Bảng so sánh HTTP method

| Method | Mục đích | Idempotent | Request body |
|------|------|--------|--------|
| **GET** | Đọc resource | Có | Không |
| **POST** | Tạo resource | Không | Có |
| **PUT** | Update toàn bộ | Có | Có |
| **PATCH** | Update một phần | Có | Có |
| **DELETE** | Xóa resource | Có | Không |

### Đọc request data

**Lấy JSON request body**:

```tsx
export async function POST(request: Request) {
  const body = await request.json()
  // body = { title: "Hello", content: "World" }
}
```

**Lấy URL query parameter**:

```tsx
export async function GET(request: Request) {
  const { searchParams } = new URL(request.url)
  const page = searchParams.get('page') || '1'
  const limit = searchParams.get('limit') || '10'
  // /api/posts?page=2&limit=20
}
```

**Lấy request header**:

```tsx
export async function GET(request: Request) {
  const authHeader = request.headers.get('Authorization')
  const contentType = request.headers.get('Content-Type')
}
```

**Lấy route parameter**:

```tsx
export async function GET(
  request: Request,
  { params }: { params: { id: string; slug: string } }
) {
  // /api/posts/123/comments/abc
  // params = { id: '123', slug: 'abc' }
}
```

### Trả về response

**JSON response**:

```tsx
// Viết tắt
return Response.json({ data: posts })

// Cách viết đầy đủ (có thể set thêm option)
return new Response(JSON.stringify({ data: posts }), {
  status: 200,
  headers: {
    'Content-Type': 'application/json',
  },
})
```

**Quy chuẩn status code**:

| Status code | Ý nghĩa | Tình huống sử dụng |
|--------|------|----------|
| 200 | OK | GET success, PUT/PATCH success |
| 201 | Created | POST tạo thành công |
| 204 | No Content | DELETE success |
| 400 | Bad Request | Request parameter error |
| 401 | Unauthorized | Chưa authenticate |
| 403 | Forbidden | Không có quyền |
| 404 | Not Found | Resource không tồn tại |
| 409 | Conflict | Resource conflict |
| 500 | Internal Error | Server error |

### RESTful design best practices

**Thiết kế URL**:

```
GET    /api/posts          # Danh sách
POST   /api/posts          # Tạo
GET    /api/posts/:id      # Chi tiết
PUT    /api/posts/:id      # Update
DELETE /api/posts/:id      # Xóa

GET    /api/posts/:id/comments    # Nested resource
POST   /api/posts/:id/comments
```

**Thống nhất response format**:

```tsx
// Success response
{
  "data": { ... },
  "meta": { "total": 100, "page": 1 }
}

// Error response
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Tiêu đề không được để trống"
  }
}
```

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Để AI generate API tuân theo chuẩn RESTful.

**Công thức định nghĩa yêu cầu**:
- Mô tả chức năng: Tạo CRUD API cho [tên resource]
- Quy chuẩn URL: Tuân theo RESTful design
- Response format: Cấu trúc JSON thống nhất

**Thuật ngữ chính**: `Route Handler`, `params`, `searchParams`, `Response.json`

**Ví dụ Prompt**:

```
Vui lòng tạo CRUD API cho /api/users:
- GET /api/users - Danh sách phân trang, hỗ trợ ?page và ?limit
- POST /api/users - Tạo user
- GET /api/users/:id - Lấy chi tiết user
- PUT /api/users/:id - Update user
- DELETE /api/users/:id - Xóa user
Sử dụng response format và error handling thống nhất
```

### Hướng dẫn tránh hố

1. **route.ts và page.tsx không thể cùng tồn tại**: Cùng thư mục chỉ có một trong hai
2. **Dynamic parameter là string**: `params.id` là string, cần convert type khi cần
3. **Chú ý cache behavior**: GET request mặc định có thể được cache, cần dynamic data thì set `dynamic = 'force-dynamic'`
4. **Xử lý CORS**: Cross-origin request cần set response header

```tsx
const headers = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE, OPTIONS',
}
```
