# 3.8.1 WCAG standard

### Tóm tắt một câu

WCAG là "luật giao thông" của accessibility, tuân thủ nó thì website của bạn sẽ nhiều người dùng được hơn.

### Giá trị cốt lõi

WCAG (Web Content Accessibility Guidelines) là chuẩn accessibility do W3C xây dựng. Đạt WCAG 2.1 AA level là chuẩn tối thiểu mà phần lớn pháp lý yêu cầu.

### Bốn nguyên tắc WCAG

| Nguyên tắc | Ý nghĩa | Yêu cầu chính |
|-----|------|---------|
| Perceivable | User có thể cảm nhận nội dung | Hình có alt text, video có phụ đề |
| Operable | User có thể thao tác interface | Keyboard accessible, đủ thời gian |
| Understandable | User hiểu được nội dung | Ngôn ngữ rõ ràng, hành vi dự đoán được |
| Robust | Tương thích assistive technology | Semantic HTML, ARIA attributes |

### Keyboard accessibility

**Yêu cầu cốt lõi**: Tất cả chức năng phải thao tác được bằng keyboard.

```tsx
// Tệ: div làm button, không keyboard accessible
<div onClick={handleClick}>Click me</div>

// Tốt: Dùng native button
<button onClick={handleClick}>Click me</button>

// Nếu phải dùng div, thêm attributes cần thiết
<div
  role="button"
  tabIndex={0}
  onClick={handleClick}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      handleClick()
    }
  }}
>
  Click me
</div>
```

**Focus management**:

```tsx
// Focus visible
.focus-visible:focus {
  outline: 2px solid #2563eb;
  outline-offset: 2px;
}

// Skip navigation link
<a href="#main" className="sr-only focus:not-sr-only">
  Nhảy tới nội dung chính
</a>

<main id="main">...</main>
```

### Semantic HTML

```tsx
// Tệ: div lồng tất cả
<div class="nav">
  <div class="nav-item">Trang chủ</div>
</div>

  <div class="title">Tiêu đề bài viết</div>
</div>

  <a href="/">Trang chủ</a>
</nav>
<main>
  <h1>Tiêu đề bài viết</h1>
  <article>...</article>

```

### ARIA attributes

Khi semantic HTML không đủ, dùng ARIA:

```tsx
// Modal
<div
  role="dialog"
  aria-labelledby="dialog-title"
  aria-describedby="dialog-description"
  aria-modal="true"
>
  <h2 id="dialog-title">Xác nhận xóa</h2>
  <p id="dialog-description">Sau khi xóa không thể khôi phục, chắc chắn chứ?</p>
  <button>Xác nhận</button>
  <button>Hủy</button>
</div>

// Loading state
<button aria-busy={isLoading} disabled={isLoading}>
  {isLoading ? 'Đang lưu...' : 'Lưu'}
</button>

// Expand/Collapse
<button
  aria-expanded={isOpen}
  aria-controls="menu-content"
>
  Menu
</button>
<div id="menu-content" hidden={!isOpen}>
  ...
</div>
```

### ARIA attributes thường dùng

| Attribute | Mục đích | Ví dụ |
|-----|------|-----|
| `aria-label` | Cung cấp label cho element | `<button aria-label="Đóng">X</button>` |
| `aria-labelledby` | Tham chiếu element khác làm label | `aria-labelledby="title"` |
| `aria-describedby` | Tham chiếu mô tả | `aria-describedby="help-text"` |
| `aria-hidden` | Ẩn với assistive technology | `<div aria-hidden="true">Nội dung trang trí</div>` |
| `aria-live` | Vùng nội dung động | `<div aria-live="polite">` |
| `role` | Định nghĩa vai trò element | `role="button"` |

### Image alt text

```tsx
// Informational image: mô tả nội dung
<img
  src="/chart.png"
  alt="Biểu đồ xu hướng doanh thu 2024, Q1 đến Q4 lần lượt là 100 triệu, 150 triệu, 200 triệu, 280 triệu"
/>

// Decorative image: alt rỗng
<img src="/decorative-line.png" alt="" />

// Functional image: mô tả chức năng
<button>
  <img src="/search-icon.svg" alt="Tìm kiếm" />
</button>
```

### Form accessibility

```tsx
// Liên kết label và input
<div>
  <label htmlFor="email">Địa chỉ email</label>
  <input
    id="email"
    type="email"
    aria-describedby="email-help"
    aria-invalid={!!errors.email}
  />
  <p id="email-help">Chúng tôi không chia sẻ email của bạn</p>
  {errors.email && (
    <p role="alert" className="text-red-500">
      {errors.email}
    </p>
  )}
</div>

// Required field
<label>
  Email <span aria-hidden="true">*</span>
  <span className="sr-only">(bắt buộc)</span>
</label>
<input required aria-required="true" />
```

### Screen reader only class

```css
/* Ẩn visual nhưng screen reader đọc được */
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}

/* Hiện khi focus */
.sr-only.focus:focus {
  position: static;
  width: auto;
  height: auto;
  padding: inherit;
  margin: inherit;
  overflow: visible;
  clip: auto;
  white-space: normal;
}
```

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Để AI giúp kiểm tra và fix lỗi accessibility.

**Công thức định nghĩa yêu cầu**:
- Phạm vi kiểm tra: Accessibility của [component/page]
- Standard level: WCAG 2.1 [A/AA/AAA]
- Điểm quan tâm: [keyboard/screen reader/color contrast]

**Ví dụ Prompt**:

```
Vui lòng kiểm tra accessibility của modal component này:
1. Đảm bảo keyboard có thể mở, đóng, navigate bên trong
2. Thêm ARIA attributes đúng
3. Khi mở thì focus vào, đóng thì focus về trigger element
4. Phím ESC đóng được
```
