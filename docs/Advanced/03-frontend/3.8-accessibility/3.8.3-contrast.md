# 3.8.3 Color contrast

### Tóm tắt một câu

Contrast đủ giúp mọi người nhìn rõ nội dung của bạn, kể cả user bình thường đang xem điện thoại dưới ánh nắng.

### Giá trị cốt lõi

Chữ contrast thấp khiến cả người mắt tốt cũng khó đọc khi ánh sáng không tốt. WCAG quy định yêu cầu contrast tối thiểu, đáp ứng nó có lợi cho tất cả user.

### WCAG contrast requirements

| Level | Chữ thường | Chữ to/đậm | Ghi chú |
|-----|---------|---------|-----|
| AA | 4.5:1 | 3:1 | Yêu cầu tối thiểu |
| AAA | 7:1 | 4.5:1 | Tiêu chuẩn cao hơn |

**Định nghĩa chữ to**: 18pt (24px) trở lên, hoặc 14pt (18.5px) đậm

### Contrast calculation tools

```tsx
// Hàm tính contrast ratio
function getLuminance(r: number, g: number, b: number): number {
  const [rs, gs, bs] = [r, g, b].map((c) => {
    c = c / 255
    return c <= 0.03928 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4)
  })
  return 0.2126 * rs + 0.7152 * gs + 0.0722 * bs
}

function getContrastRatio(color1: string, color2: string): number {
  const rgb1 = hexToRgb(color1)
  const rgb2 = hexToRgb(color2)

  const l1 = getLuminance(rgb1.r, rgb1.g, rgb1.b)
  const l2 = getLuminance(rgb2.r, rgb2.g, rgb2.b)

  const lighter = Math.max(l1, l2)
  const darker = Math.min(l1, l2)

  return (lighter + 0.05) / (darker + 0.05)
}

function hexToRgb(hex: string) {
  const result = /^#?([a-f\d]{2})([a-f\d]{2})([a-f\d]{2})$/i.exec(hex)
  return result ? {
    r: parseInt(result[1], 16),
    g: parseInt(result[2], 16),
    b: parseInt(result[3], 16),
  } : { r: 0, g: 0, b: 0 }
}

// Sử dụng
const ratio = getContrastRatio('#3B82F6', '#FFFFFF')
console.log(`Contrast ratio: ${ratio.toFixed(2)}:1`) // 4.51:1
```

### Common problematic colors

| Vấn đề | Màu tệ | Màu tốt |
|-----|---------|---------|
| Chữ xám | `#999` on `#fff` (2.85:1) | `#666` on `#fff` (5.74:1) |
| Link xanh | `#60A5FA` on `#fff` (2.77:1) | `#2563EB` on `#fff` (4.88:1) |
| Màu success | `#22C55E` on `#fff` (2.43:1) | `#15803D` on `#fff` (4.96:1) |

### Safe color schemes

```css
:root {
  /* Đảm bảo đạt chuẩn AA */

  /* Màu chữ */
  --text-primary: #111827;     /* on white: 16.02:1 */
  --text-secondary: #4B5563;   /* on white: 7.50:1 */
  --text-muted: #6B7280;       /* on white: 5.24:1 */

  /* Màu button */
  --btn-primary: #2563EB;      /* white text: 4.88:1 */
  --btn-success: #15803D;      /* white text: 4.96:1 */
  --btn-danger: #DC2626;       /* white text: 4.51:1 */

  /* Link */
  --link-color: #1D4ED8;       /* on white: 6.95:1 */
}
```

### Không chỉ phụ thuộc vào màu

User mù màu có thể không phân biệt được đỏ/xanh lá, nên đừng chỉ dùng màu để truyền đạt thông tin:

```tsx
// Tệ: Chỉ dùng màu phân biệt status
<span className="text-green-500">Thành công</span>
<span className="text-red-500">Thất bại</span>

// Tốt: Màu + icon
<span className="text-green-600 flex items-center">
  <CheckIcon className="w-4 h-4 mr-1" />
  Thành công
</span>
<span className="text-red-600 flex items-center">
  <XIcon className="w-4 h-4 mr-1" />
  Thất bại
</span>

// Form error: Màu + icon + vị trí
<div>
  <input
    className={cn(
      "border rounded",
      error ? "border-red-500" : "border-gray-300"
    )}
    aria-invalid={!!error}
    aria-describedby={error ? "email-error" : undefined}
  />
  {error && (
    <p id="email-error" className="text-red-600 text-sm mt-1 flex items-center">
      <AlertCircle className="w-4 h-4 mr-1" />
      {error}
    </p>
  )}
</div>
```

### Focus state contrast

```css
/* Focus outline cần contrast đủ */
:focus-visible {
  outline: 2px solid #2563EB;
  outline-offset: 2px;
}

/* Trên dark background */
.dark :focus-visible {
  outline: 2px solid #60A5FA;
}

/* High contrast mode */
@media (prefers-contrast: high) {
  :focus-visible {
    outline: 3px solid currentColor;
  }
}
```

### Hướng dẫn cộng tác AI

**Công thức định nghĩa yêu cầu**:

- Target level: WCAG [AA/AAA]
- Background color: [light/dark/cả hai]
