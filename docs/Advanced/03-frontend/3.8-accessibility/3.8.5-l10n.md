# 3.8.5 Localization l10n

### Tóm tắt một câu

Localization không chỉ dịch văn bản, mà còn phải thích nghi ngày tháng, tiền tệ, thói quen, thậm chí ý nghĩa văn hóa của màu sắc.

### Giá trị cốt lõi

Localization (l10n = localization) là làm cho sản phẩm thích nghi với văn hóa, pháp lý và thói quen user của khu vực cụ thể. Dịch trực tiếp có thể tạo ra xung đột văn hóa hoặc hiểu lầm.

### Localization vs Internationalization

| Khái niệm | Phạm vi | Ví dụ |
|-----|------|-----|
| Internationalization (i18n) | Kiến trúc kỹ thuật | Text externalization, formatting functions |
| Localization (l10n) | Content adaptation | Dịch thuật, điều chỉnh văn hóa, tuân thủ pháp lý |

### Date và time format

```tsx
const date = new Date('2024-01-15T14:30:00')

// Định dạng khác nhau tùy khu vực
const formats = {
  'vi-VN': '15/01/2024 14:30',             // Ngày/tháng/năm, 24h
  'en-US': 'January 15, 2024, 2:30 PM',    // Tháng ngày năm, 12h
  'de-DE': '15. Januar 2024, 14:30',       // Ngày.tháng.năm
  'ja-JP': '2024年1月15日 14:30',           // Giống Trung Quốc
}

// Dùng Intl.DateTimeFormat
function formatDate(date: Date, locale: string) {
  return new Intl.DateTimeFormat(locale, {
    year: 'numeric',
    month: 'long',
    day: 'numeric',
    hour: '2-digit',
    minute: '2-digit',
  }).format(date)
}
```

### Currency và numbers

```tsx
// Vị trí ký hiệu tiền tệ và số thập phân
const amount = 1234.56

const currencies = {
  'vi-VN': '1.234,56 ₫',
  'en-US': '$1,234.56',
  'de-DE': '1.234,56 €',  // Lưu ý: dấu phẩy và chấm ngược lại
  'ja-JP': '￥1,235',      // Yên Nhật không có thập phân
}

function formatCurrency(amount: number, locale: string, currency: string) {
  return new Intl.NumberFormat(locale, {
    style: 'currency',
    currency,
  }).format(amount)
}

// Sử dụng
formatCurrency(1234.56, 'vi-VN', 'VND') // 1.234,56 ₫
formatCurrency(1234.56, 'en-US', 'USD') // $1,234.56
formatCurrency(1234.56, 'de-DE', 'EUR') // 1.234,56 €
```

### Address format

```tsx
// Thứ tự thành phần địa chỉ khác nhau theo khu vực
interface Address {
  street: string
  city: string
  state: string
  postalCode: string
  country: string
}

// Việt Nam: Số nhà, đường, phường, quận, thành phố
// Mỹ: Đường, thành phố, tiểu bang, mã bưu điện
// Nhật: Mã bưu điện, tỉnh, thành phố, quận, đường

function formatAddress(address: Address, locale: string): string {
  switch (locale) {
    case 'vi-VN':
      return `${address.street}, ${address.city}, ${address.state}, ${address.country}`
    case 'en-US':
      return `${address.street}, ${address.city}, ${address.state} ${address.postalCode}`
    case 'ja-JP':
      return `〒${address.postalCode} ${address.state}${address.city}${address.street}`
    default:
      return `${address.street}, ${address.city}`
  }
}
```

### Name ordering

```tsx
interface Name {
  firstName: string
  lastName: string
}

// Phương Tây: firstName lastName
// Trung Nhật Hàn: lastName firstName

function formatName(name: Name, locale: string): string {
  const eastAsianLocales = ['zh-CN', 'zh-TW', 'ja-JP', 'ko-KR', 'vi-VN']

  if (eastAsianLocales.includes(locale)) {
    return `${name.lastName} ${name.firstName}`
  }
  return `${name.firstName} ${name.lastName}`
}
```

### Ý nghĩa văn hóa của màu sắc

| Màu | Trung Quốc | Phương Tây | Nhật Bản |
|-----|------|-----|-----|
| Đỏ | Vui vẻ, may mắn | Nguy hiểm, cảnh báo | Sự sống, đam mê |
| Trắng | Tang lễ | Trong sáng, đám cưới | Trong sáng |
| Xanh lá | Môi trường, sức khỏe | An toàn, tiền bạc | Thiên nhiên |
| Vàng | Hoàng gia, cao quý | Cảnh báo, hèn nhát | Dũng cảm |

### Text length adaptation

```tsx
// Độ dài text sau khi dịch có thể chênh lệch lớn
const translations = {
  'submit': {
    'vi-VN': 'Gửi',         // 3 ký tự
    'en-US': 'Submit',      // 6 ký tự
    'de-DE': 'Einreichen',  // 10 ký tự
  },
}

// Thiết kế cần xét đến text expansion
// Button dùng min-width thay vì fixed width
<button className="min-w-[80px] px-4">
  {t('submit')}
</button>

// Dùng flexible layout
<div className="flex flex-wrap gap-2">
  <button>{t('save')}</button>
  <button>{t('cancel')}</button>
</div>
```

### RTL language support

```tsx
// Arabic, Hebrew đọc từ phải sang trái

// Dùng logical properties
.container {
  /* Physical properties - RTL cần flip */
  margin-left: 1rem;  /* Không khuyến khích */

  /* Logical properties - tự động thích nghi */
  margin-inline-start: 1rem;  /* Khuyến khích */
}

// Tailwind logical properties
<div className="ms-4 me-2">  {/* margin-inline-start/end */}
  <p className="text-start">Nội dung</p>  {/* Tự động thích nghi hướng */}
</div>

// HTML dir attribute
<html lang="ar" dir="rtl">
  ...
</html>
```

### Legal compliance

```tsx
// GDPR (EU) - Cần cookie consent
// CCPA (California) - Cần link "Không bán thông tin cá nhân"
// Việt Nam - Cần đăng ký Bộ Công Thương

function Footer({ locale }: { locale: string }) {
  return (
    <footer>
      {locale.startsWith('vi') && (
        <p>Đăng ký Bộ Công Thương số: XXXXXXXX</p>
      )}
      {['en-US', 'en-GB', 'de-DE', 'fr-FR'].includes(locale) && (
        <CookieConsent />
      )}
      {locale === 'en-US' && (
        <a href="/ccpa">Do Not Sell My Personal Information</a>
      )}
    </footer>
  )
}
```

### Localization testing

```tsx
// Pseudo-localization testing - Thay bằng ký tự đặc biệt
// Nhanh chóng phát hiện hard-coded text và vấn đề layout

function pseudoLocalize(text: string): string {
  const map: Record<string, string> = {
    'a': 'å', 'b': 'ƀ', 'c': 'ç', 'd': 'ð',
    'e': 'é', 'f': 'ƒ', 'g': 'ğ', 'h': 'ĥ',
    // ...
  }

  return '[[ ' + text.split('').map(c => map[c.toLowerCase()] || c).join('') + ' ]]'
}

// "Hello" → "[[ ĥéļļö ]]"
// Dễ phát hiện:
// 1. Hard-coded text (không được thay thế)
// 2. Text truncation issues (chuỗi dài hơn)
// 3. Encoding issues (ký tự đặc biệt hiển thị lỗi)
```

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Để AI giúp xử lý chi tiết localization.

**Công thức định nghĩa yêu cầu**:
- Target market: [danh sách quốc gia/khu vực]
- Content type: [date/currency/address/name]
- Yêu cầu đặc biệt: [legal compliance/RTL support]

**Ví dụ Prompt**:

```
Sản phẩm của tôi cần hỗ trợ thị trường Việt Nam và Mỹ, vui lòng giúp:
1. Thiết kế date và currency formatting utility functions
2. Tạo address và name formatting functions
3. Liệt kê điểm khác biệt pháp lý giữa hai thị trường cần chú ý
4. Đề xuất giải pháp thích nghi độ dài text đa ngôn ngữ cho button và form
```
