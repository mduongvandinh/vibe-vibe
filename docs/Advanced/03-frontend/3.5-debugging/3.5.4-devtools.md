# 3.5.4 Component state đúng chưa——React DevTools

### Tóm tắt một câu

React DevTools cho bạn "xuyên thị" component tree như tia X——xem Props, State và lý do render của từng component.

### Giá trị cốt lõi

Khi UI không như kỳ vọng, vấn đề có thể nằm ở việc truyền Props, quản lý State hoặc logic render. React DevTools cho phép bạn kiểm tra trực tiếp runtime state của component, không cần thêm console.log.

### Cài đặt React DevTools

1. Tìm "React Developer Tools" trong Chrome Web Store
2. Cài extension
3. Refresh ứng dụng React của bạn
4. DevTools sẽ có thêm hai panel **Components** và **Profiler**

### Panel Components

**Component tree view**:

```
App
├── Layout
│   ├── Header
│   │   └── Navigation
│   └── Main
│       ├── Sidebar
│       └── Content
│           ├── ProductList
│           │   ├── ProductCard ← đang chọn
│           │   ├── ProductCard
│           │   └── ProductCard
│           └── Pagination
└── Footer
```

**Panel bên phải hiển thị**:

- **props**: Thuộc tính truyền từ component cha
- **hooks**: Hooks component đang dùng và giá trị hiện tại
- **rendered by**: Ai đã render component này

### Kiểm tra Props

Click vào bất kỳ component nào, xem Props nó nhận được:

```
ProductCard
├── props
│   ├── product: {id: 1, name: "iPhone", price: 999}
│   ├── onAddToCart: ƒ ()
│   └── isSelected: false
└── hooks
    └── State: 0
```

**Kỹ thuật debug**:

- Click vào object trong Props có thể mở rộng xem chi tiết
- Chuột phải → "Store as global variable" có thể truy cập giá trị trong Console
- Sửa giá trị Props trực tiếp trong DevTools, thấy UI thay đổi ngay

### Kiểm tra State

Khu vực Hooks hiển thị tất cả giá trị hiện tại của useState/useReducer:

```
hooks
├── State: "loading"           ← useState
├── State: [{...}, {...}]      ← useState
├── Reducer: {count: 5}        ← useReducer
├── Context: {theme: "dark"}   ← useContext
└── Memo: [1, 2, 3]            ← useMemo
```

**Sửa State realtime**:

Double click giá trị State có thể sửa trực tiếp, test UI ở các state khác nhau.

### Tìm kiếm component

Search box phía trên hỗ trợ:

- Tên component: `ProductCard`
- Filter Props: `[price]` tìm component có price prop
- Regular expression: `/Product.*/`

### Panel Profiler

Dùng để phân tích render performance:

1. Click **Record** bắt đầu recording
2. Thực hiện thao tác trên trang
3. Click **Stop** kết thúc
4. Xem số lần render và thời gian của từng component

**Flame chart hiển thị**:

```
Commit #1 (32ms)
├── App (2ms)
├── Layout (1ms)
└── ProductList (28ms) ← render chậm!
    ├── ProductCard (8ms)
    ├── ProductCard (8ms)
    └── ProductCard (8ms)
```

**Nhận diện render không cần thiết**:

Tick "Record why each component rendered", có thể thấy lý do render:

- **Props changed**: Props thay đổi
- **Hooks changed**: State hoặc giá trị Hook khác thay đổi
- **Parent rendered**: Component cha re-render gây ra

### Chức năng nâng cao

**Highlight updates**

Settings → General → Highlight updates when components render

Bật lên, component render sẽ nhấp nháy viền, giúp phát hiện render không cần thiết.

**Component filter**

Settings → Components → Hide components matching...

Có thể ẩn component không quan tâm (như Provider, Context).

**Debug Suspense**

Panel Components sẽ hiển thị Suspense boundary và fallback state của nó.

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Dùng DevTools data giúp AI định vị vấn đề component.

**Cách mô tả hiệu quả**:

```
Component ProductCard hiển thị không đúng:

DevTools hiển thị Props:
- product: {id: 1, name: null, price: 999}

Kỳ vọng name phải có giá trị, nhưng thực tế là null.
Nguồn data là data.products[0] trả về từ API.

Xin hỏi có thể là nguyên nhân gì?
```

**Thuật ngữ chính**: `Props`, `State`, `Hooks`, `Re-render`, `Profiler`

### Hướng dẫn tránh hố

1. **Chỉ có hiệu lực ở development mode**: Production build React app thông tin có hạn
2. **Extension có thể xung đột**: DevTools extension khác có thể ảnh hưởng React DevTools
3. **Anonymous component khó định vị**: Thêm displayName cho component tiện debug
4. **Context hiển thị anonymous**: Khuyến nghị đặt tên cho Context

```tsx
// Đặt tên cho Context
const ThemeContext = createContext(null)
ThemeContext.displayName = 'ThemeContext'
```
