# 3.2.1 Cách thiết kế khe cắm của khối lego——Định nghĩa kiểu Props

### Tóm tắt một câu

Props là "hợp đồng interface" của component, định nghĩa dữ liệu gì có thể truyền từ bên ngoài, format ra sao, có bắt buộc không.

### Giá trị cốt lõi

Thiết kế Props tốt làm cho component vừa linh hoạt vừa an toàn. Hệ thống kiểu của TypeScript có thể bắt lỗi lúc compile time, giúp code AI sinh ra đáng tin hơn, cũng giúp bạn tự tin hơn khi Review.

### Props cơ bản

**Định nghĩa Props của component:**

```tsx
// Cách 1: interface (khuyến nghị)
interface ButtonProps {
  label: string           // Bắt buộc
  variant?: 'primary' | 'secondary'  // Tùy chọn, union type
  disabled?: boolean      // Tùy chọn
  onClick?: () => void    // Tùy chọn, callback function
}

// Cách 2: type
type ButtonProps = {
  label: string
  variant?: 'primary' | 'secondary'
}

// Sử dụng Props
function Button({ label, variant = 'primary', disabled = false, onClick }: ButtonProps) {
  return (
    <button
      className={`btn-${variant}`}
      disabled={disabled}
      onClick={onClick}
    >
      {label}
    </button>
  )
}
```

### Thiết lập giá trị mặc định

**Hai cách thiết lập giá trị mặc định:**

```tsx
// Cách 1: Set khi destructure (khuyến nghị)
function Card({ title, size = 'medium' }: CardProps) {
  // ...
}

// Cách 2: defaultProps (không khuyến nghị, đã lỗi thời)
Card.defaultProps = {
  size: 'medium'
}
```

### children Props

`children` là prop đặc biệt, dùng để truyền nội dung lồng nhau:

```tsx
interface CardProps {
  title: string
  children: React.ReactNode  // Có thể là bất kỳ nội dung nào có thể render
}

function Card({ title, children }: CardProps) {
  return (
    <div className="card">
      <h2>{title}</h2>
      <div className="card-body">{children}</div>
    </div>
  )
}

// Sử dụng
<Card title="Thông tin người dùng">
  <p>Tên: Nguyễn Văn A</p>
  <p>Tuổi: 25</p>
</Card>
```

### Các kiểu Props thường dùng

| Kiểu | Mục đích | Ví dụ |
|------|------|------|
| `string` | Văn bản | `title: string` |
| `number` | Số | `count: number` |
| `boolean` | Bật/tắt | `disabled?: boolean` |
| `'a' \| 'b'` | Giá trị enum | `size: 'sm' \| 'md' \| 'lg'` |
| `() => void` | Callback không tham số | `onClick: () => void` |
| `(value: T) => void` | Callback có tham số | `onChange: (value: string) => void` |
| `React.ReactNode` | Nội dung có thể render | `children: React.ReactNode` |
| `React.CSSProperties` | Inline style | `style?: React.CSSProperties` |
| `React.ComponentProps<'button'>` | Kế thừa thuộc tính native | Kế thừa tất cả thuộc tính button |

### Kế thừa thuộc tính phần tử native

Khi component của bạn là wrapper của phần tử native:

```tsx
// Kế thừa tất cả thuộc tính native của button
interface ButtonProps extends React.ComponentProps<'button'> {
  variant?: 'primary' | 'secondary'
}

function Button({ variant = 'primary', children, ...rest }: ButtonProps) {
  return (
    <button className={`btn-${variant}`} {...rest}>
      {children}
    </button>
  )
}

// Bây giờ có thể dùng tất cả thuộc tính native của button
<Button variant="primary" type="submit" disabled>
  Gửi
</Button>
```

### Generic Props

Dùng generic khi xử lý component tổng quát:

```tsx
interface ListProps<T> {
  items: T[]
  renderItem: (item: T) => React.ReactNode
}

function List<T>({ items, renderItem }: ListProps<T>) {
  return (
    <ul>
      {items.map((item, index) => (
        <li key={index}>{renderItem(item)}</li>
      ))}
    </ul>
  )
}

// Khi sử dụng tự động suy luận kiểu
<List
  items={[{ id: 1, name: 'Nguyễn Văn A' }]}
  renderItem={(user) => <span>{user.name}</span>}  // user tự động suy luận là { id: number, name: string }
/>
```

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Để AI giúp bạn thiết kế component interface an toàn về kiểu.

**Công thức định nghĩa yêu cầu**:
- Mô tả chức năng: Component cần nhận [danh sách dữ liệu]
- Cách tương tác: Người dùng có thể [trigger event]
- Hiệu quả kỳ vọng: Component hiển thị [trạng thái khác nhau] theo props

**Thuật ngữ chính**: `interface`, `children`, `React.ReactNode`, `extends ComponentProps`, generic

**Chiến lược tương tác**:
1. Trước tiên để AI liệt kê tất cả props component cần
2. Để nó định nghĩa type interface
3. Phân biệt bắt buộc và tùy chọn
4. Thêm giá trị mặc định hợp lý

### Hướng dẫn tránh hố

1. **Props là read-only**: Không bao giờ trực tiếp sửa props, cần thay đổi thì dùng state
2. **Tránh thiết kế quá mức**: Đừng đặt trước quá nhiều props "có thể dùng sau này"
3. **Quy ước đặt tên callback**: Event callback bắt đầu bằng `on`, như `onClick`, `onChange`
4. **Props tùy chọn nhớ set giá trị mặc định**: Tránh vấn đề do undefined

### Checklist nghiệm thu

- [ ] Props interface định nghĩa đầy đủ, kiểu chính xác
- [ ] Props tùy chọn có giá trị mặc định hợp lý
- [ ] Dùng `children` để implement content slot
- [ ] Component phức tạp dùng generic để giữ type safety
