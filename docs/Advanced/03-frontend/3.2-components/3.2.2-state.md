# 3.2.2 Ai quản lý trạng thái của khối lego——Quản lý State

### Tóm tắt một câu

State là "bộ nhớ" của component, cho phép UI phản hồi và cập nhật theo tương tác người dùng và thay đổi dữ liệu.

### Giá trị cốt lõi

Props là dữ liệu chỉ đọc được truyền từ bên ngoài, còn State là dữ liệu component có thể tự quản lý và sửa đổi bên trong. Khi State thay đổi, React sẽ tự động re-render component.

### useState cơ bản

```tsx
'use client'  // Dùng Hooks bắt buộc là Client Component

import { useState } from 'react'

function Counter() {
  // Khai báo state: [giá trị hiện tại, hàm update] = useState(giá trị khởi tạo)
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Đếm hiện tại: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
      <button onClick={() => setCount(prev => prev - 1)}>-1</button>
    </div>
  )
}
```

### Hai cách cập nhật state

```tsx
// Cách 1: Đặt trực tiếp giá trị mới
setCount(5)

// Cách 2: Cập nhật dựa trên state trước (khuyến nghị, tránh closure trap)
setCount(prev => prev + 1)
```

**Khi nào dùng functional update?**

Khi state mới phụ thuộc vào state cũ, nhất định phải dùng functional update:

```tsx
// Sai: Có thể gây hành vi bất ngờ do closure
const handleClick = () => {
  setCount(count + 1)
  setCount(count + 1)  // Có thể không +2
}

// Đúng: Đảm bảo dựa trên state mới nhất
const handleClick = () => {
  setCount(prev => prev + 1)
  setCount(prev => prev + 1)  // Chắc chắn sẽ +2
}
```

### State object và array

**State object:**

```tsx
const [user, setUser] = useState({ name: '', age: 0 })

// Cập nhật một field của object (phải tạo object mới)
setUser(prev => ({ ...prev, name: 'Nguyễn Văn A' }))
```

**State array:**

```tsx
const [items, setItems] = useState<string[]>([])

// Thêm
setItems(prev => [...prev, 'new item'])

// Xóa
setItems(prev => prev.filter((_, i) => i !== index))

// Cập nhật
setItems(prev => prev.map((item, i) => i === index ? 'updated' : item))
```

### useReducer: Cứu tinh cho state phức tạp

Khi logic state trở nên phức tạp, `useReducer` rõ ràng hơn nhiều `useState`:

```tsx
'use client'

import { useReducer } from 'react'

// Định nghĩa kiểu State
interface State {
  count: number
  loading: boolean
  error: string | null
}

// Định nghĩa kiểu Action
type Action =
  | { type: 'increment' }
  | { type: 'decrement' }
  | { type: 'setLoading'; payload: boolean }
  | { type: 'setError'; payload: string }

// Hàm Reducer
function reducer(state: State, action: Action): State {
  switch (action.type) {
    case 'increment':
      return { ...state, count: state.count + 1 }
    case 'decrement':
      return { ...state, count: state.count - 1 }
    case 'setLoading':
      return { ...state, loading: action.payload }
    case 'setError':
      return { ...state, error: action.payload }
    default:
      return state
  }
}

function Counter() {
  const [state, dispatch] = useReducer(reducer, {
    count: 0,
    loading: false,
    error: null
  })

  return (
    <div>
      <p>{state.count}</p>
      <button onClick={() => dispatch({ type: 'increment' })}>+1</button>
    </div>
  )
}
```

### useState vs useReducer

| Kịch bản | Khuyến nghị |
|------|------|
| Giá trị đơn (số, string, boolean) | useState |
| Object đơn giản (2-3 field) | useState |
| Object phức tạp (nhiều field, nhiều cách update) | useReducer |
| Cập nhật state có ngữ nghĩa "action" rõ ràng | useReducer |
| Cần quản lý logic state tập trung | useReducer |

### State lifting

Khi nhiều component cần chia sẻ state, hãy nâng state lên component cha chung của chúng:

```tsx
// Component cha giữ state
function Parent() {
  const [value, setValue] = useState('')

  return (
    <div>
      <Input value={value} onChange={setValue} />
      <Display value={value} />
    </div>
  )
}

// Component con nhận state và hàm update qua Props
function Input({ value, onChange }: { value: string; onChange: (v: string) => void }) {
  return <input value={value} onChange={e => onChange(e.target.value)} />
}

function Display({ value }: { value: string }) {
  return <p>Đang nhập: {value}</p>
}
```

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Để AI giúp bạn thiết kế cấu trúc state của component.

**Công thức định nghĩa yêu cầu**:
- Mô tả chức năng: Component cần nhớ [dữ liệu nào]
- Cách tương tác: Người dùng có thể thông qua [thao tác] thay đổi state
- Hiệu quả kỳ vọng: Khi state thay đổi UI phản hồi như thế nào

**Thuật ngữ chính**: `useState`, `useReducer`, `dispatch`, state lifting, functional update

**Chiến lược tương tác**:
1. Trước tiên để AI phân tích cần những state nào
2. Đánh giá dùng useState hay useReducer
3. Implement logic cập nhật state
4. Xử lý state lifting (nếu cần)

### Hướng dẫn tránh hố

1. **Cập nhật State là bất đồng bộ**: Set xong không thể đọc ngay giá trị mới
2. **Không trực tiếp sửa state**: `state.count++` là sai, phải dùng setter
3. **Object/array phải tạo reference mới**: `{...obj}` hoặc `[...arr]`
4. **Tránh quá nhiều useState**: Hơn 3-4 cái cân nhắc dùng useReducer hoặc custom Hook

### Checklist nghiệm thu

- [ ] Khai báo `'use client'` chính xác
- [ ] Cập nhật state object/array tạo reference mới
- [ ] Cập nhật phụ thuộc giá trị trước dùng functional update
- [ ] Logic state phức tạp dùng useReducer
- [ ] State dùng chung được nâng đúng lên component cha chung
