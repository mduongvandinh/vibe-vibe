# 3.2.5 Đóng gói khối lego của riêng bạn——Custom Hooks

### Tóm tắt một câu

Custom Hook là function bắt đầu bằng `use`, cho phép bạn trích xuất logic có state để tái sử dụng giữa nhiều component.

### Giá trị cốt lõi

Khi phát hiện nhiều component có logic state tương tự, đừng copy-paste—hãy trích xuất thành custom Hook. Điều này không chỉ giảm code trùng lặp, mà còn làm cho logic dễ test và maintain hơn.

### Custom Hook cơ bản

```tsx
// hooks/useCounter.ts
import { useState, useCallback } from 'react'

export function useCounter(initialValue = 0) {
  const [count, setCount] = useState(initialValue)

  const increment = useCallback(() => setCount(c => c + 1), [])
  const decrement = useCallback(() => setCount(c => c - 1), [])
  const reset = useCallback(() => setCount(initialValue), [initialValue])

  return { count, increment, decrement, reset }
}

// Sử dụng
function Counter() {
  const { count, increment, decrement } = useCounter(10)

  return (
    <div>
      <span>{count}</span>
      <button onClick={increment}>+</button>
      <button onClick={decrement}>-</button>
    </div>
  )
}
```

### Các pattern custom Hooks thường dùng

**1. useToggle - Toggle boolean**

```tsx
function useToggle(initialValue = false) {
  const [value, setValue] = useState(initialValue)

  const toggle = useCallback(() => setValue(v => !v), [])
  const setTrue = useCallback(() => setValue(true), [])
  const setFalse = useCallback(() => setValue(false), [])

  return { value, toggle, setTrue, setFalse }
}

// Sử dụng
const { value: isOpen, toggle } = useToggle()
```

**2. useLocalStorage - Lưu trữ persistent**

```tsx
function useLocalStorage<T>(key: string, initialValue: T) {
  const [storedValue, setStoredValue] = useState<T>(() => {
    if (typeof window === 'undefined') return initialValue
    try {
      const item = window.localStorage.getItem(key)
      return item ? JSON.parse(item) : initialValue
    } catch {
      return initialValue
    }
  })

  const setValue = useCallback((value: T | ((val: T) => T)) => {
    setStoredValue(prev => {
      const valueToStore = value instanceof Function ? value(prev) : value
      window.localStorage.setItem(key, JSON.stringify(valueToStore))
      return valueToStore
    })
  }, [key])

  return [storedValue, setValue] as const
}
```

**3. useFetch - Lấy dữ liệu**

```tsx
interface UseFetchResult<T> {
  data: T | null
  loading: boolean
  error: Error | null
  refetch: () => void
}

function useFetch<T>(url: string): UseFetchResult<T> {
  const [data, setData] = useState<T | null>(null)
  const [loading, setLoading] = useState(true)
  const [error, setError] = useState<Error | null>(null)

  const fetchData = useCallback(async () => {
    setLoading(true)
    setError(null)
    try {
      const res = await fetch(url)
      if (!res.ok) throw new Error('Fetch failed')
      const json = await res.json()
      setData(json)
    } catch (e) {
      setError(e as Error)
    } finally {
      setLoading(false)
    }
  }, [url])

  useEffect(() => {
    fetchData()
  }, [fetchData])

  return { data, loading, error, refetch: fetchData }
}
```

**4. useDebounce - Debounce**

```tsx
function useDebounce<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState(value)

  useEffect(() => {
    const timer = setTimeout(() => setDebouncedValue(value), delay)
    return () => clearTimeout(timer)
  }, [value, delay])

  return debouncedValue
}

// Sử dụng: Debounce input tìm kiếm
function Search() {
  const [query, setQuery] = useState('')
  const debouncedQuery = useDebounce(query, 300)

  useEffect(() => {
    if (debouncedQuery) {
      // Gửi search request
    }
  }, [debouncedQuery])
}
```

### Quy tắc đặt tên

- **Bắt buộc bắt đầu bằng `use`**: Đây là cách React nhận diện Hook
- **Mô tả chức năng chứ không phải implementation**: `useAuth` thay vì `useAuthState`
- **Giá trị trả về nhất quán**: Object cho nhiều giá trị trả về, tuple cho trường hợp giống useState

### Khi nào nên trích xuất custom Hook

1. **Logic trùng lặp**: Hai component trở lên có cùng logic state
2. **Logic phức tạp**: Component gọi quá 5-6 Hook
3. **Separation of concerns**: Business logic và UI logic trộn lẫn
4. **Dễ test**: Cần test riêng một phần logic

### Hướng dẫn cộng tác AI

**Ý định cốt lõi**: Để AI giúp bạn nhận diện và trích xuất logic có thể tái sử dụng.

**Công thức định nghĩa yêu cầu**:
- Mô tả chức năng: Tôi có [logic tương tự] lặp lại ở nhiều component
- Cách tương tác: Logic này cần [tham số đầu vào]
- Hiệu quả kỳ vọng: Hook trả về [dữ liệu và method nào]

**Thuật ngữ chính**: `useCallback`, `useMemo`, generic, return type

**Chiến lược tương tác**:
1. Cho AI xem code trùng lặp
2. Để nó phân tích logic chung có thể trích xuất
3. Thiết kế interface input/output của Hook
4. Implement và sử dụng trong component gốc

### Hướng dẫn tránh hố

1. **Quy tắc Hooks áp dụng cho custom Hooks**: Không được gọi theo điều kiện, trong vòng lặp
2. **Đừng abstract quá sớm**: Đợi logic thực sự lặp lại mới trích xuất
3. **Giữ Hook có trách nhiệm đơn nhất**: Một Hook làm một việc
4. **Chú ý closure trap**: Callback nhớ wrap bằng useCallback

### Checklist nghiệm thu

- [ ] Tên Hook bắt đầu bằng `use`
- [ ] Kiểu trả về được định nghĩa rõ ràng
- [ ] Callback bên trong được wrap bằng useCallback
- [ ] Có use case và documentation rõ ràng
