# 1.5.1 Mài dao không nhầm chặt củi — Lựa chọn IDE: Cấu hình VS Code và Gợi ý plugin

### Một câu giải thích

VS Code là editor code phổ biến nhất thế giới, thông qua cấu hình plugin hợp lý có thể tạo ra một môi trường phát triển full-stack hiệu quả.

### Cấu hình được đề xuất

Thêm cấu hình sau vào settings VS Code (settings.json):

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit",
    "source.organizeImports": "explicit"
  },
  "editor.tabSize": 2,
  "editor.wordWrap": "on",
  "files.autoSave": "onFocusChange",
  "typescript.preferences.importModuleSpecifier": "relative",
  "tailwindCSS.includeLanguages": {
    "typescript": "javascript",
    "typescriptreact": "javascript"
  },
  "emmet.includeLanguages": {
    "javascript": "javascriptreact",
    "typescript": "typescriptreact"
  }
}
```

### Lưu ý cho người dùng Cursor

Nếu bạn dùng Cursor, các cấu hình trên đều áp dụng được. Cursor được xây dựng dựa trên VS Code, hoàn toàn tương thích với plugin và cấu hình của VS Code.

Cấu hình riêng của Cursor có thể tìm trong settings Cursor, chủ yếu là các tùy chọn liên quan đến AI (đã giới thiệu ở mục 1.1.2).

### Cấu hình workspace

Đối với dự án nhóm, đề xuất tạo `.vscode/settings.json` trong thư mục gốc dự án, đảm bảo các thành viên nhóm sử dụng cấu hình thống nhất:

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "[typescriptreact]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  }
}
```

### Hướng dẫn tránh lỗi

- **Đừng cài quá nhiều plugin**: Chỉ cài những gì cần, quá nhiều plugin sẽ làm chậm editor
- **Giữ plugin cập nhật**: Plugin cũ có thể có vấn đề tương thích
- **Backup cấu hình của bạn**: Dùng tính năng Settings Sync để đồng bộ cấu hình lên cloud
