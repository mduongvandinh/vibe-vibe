# 1.2.3 Cách hạ lệnh cho AI - Cơ bản Prompt Engineering: Cách giao tiếp hiệu quả với AI

### Điểm chính một câu

Bản chất của prompt engineering là **dùng ngôn ngữ có cấu trúc biểu đạt ý định rõ ràng**. Prompt tốt không phải từ ngữ hoa mỹ, mà là định nghĩa yêu cầu chính xác.

### Nguyên tắc cốt lõi: Rõ ràng, Cụ thể, Có cấu trúc

#### Nguyên tắc 1: Rõ ràng

AI không thể đọc tâm trí, nó chỉ có thể hiểu nội dung bạn biểu đạt ra.

```
❌ Mơ hồ: Giúp tôi tối ưu đoạn code này
✅ Rõ ràng: Giúp tôi tối ưu performance của hàm này, hiện tại xử lý 10000 dòng dữ liệu mất 5 giây,
           mục tiêu giảm xuống dưới 1 giây
```

#### Nguyên tắc 2: Cụ thể

Cung cấp đủ ngữ cảnh, cho AI biết bạn cần gì trong tình huống nào.

```
❌ Chung chung: Viết một chức năng đăng nhập
✅ Cụ thể: Dùng Next.js 16 App Router viết trang đăng nhập, dùng Server Actions xử lý submit form,
           hỗ trợ đăng nhập email+password, dùng Tailwind CSS làm style
```

#### Nguyên tắc 3: Có cấu trúc

Dùng cấu trúc rõ ràng tổ chức yêu cầu, để AI dễ hiểu và thực thi hơn.

```
## Mô tả yêu cầu
Triển khai component comment của user

## Yêu cầu kỹ thuật
- Framework: Next.js 16
- Style: Tailwind CSS
- Dữ liệu: Lấy danh sách comment từ API

## Điểm chức năng
1. Hiển thị danh sách comment (avatar, tên user, nội dung, thời gian)
2. Hỗ trợ like
3. Hỗ trợ reply

## Điều kiện ràng buộc
- Cần xử lý trạng thái loading và empty state
- Cần xử lý trường hợp lỗi
```

### Template prompt: Mô tả chức năng + Cách tương tác + Kết quả kỳ vọng

Đây là công thức vạn năng định nghĩa yêu cầu:

```
[Mô tả chức năng]: Tôi muốn triển khai chức năng gì
[Cách tương tác]: User tương tác với chức năng này như thế nào
[Kết quả kỳ vọng]: Thành công thì sẽ thấy kết quả gì
```

**Ví dụ**:

```
Mô tả chức năng: Triển khai component ô tìm kiếm
Cách tương tác: User nhập từ khóa, nhấn Enter hoặc click nút tìm kiếm để trigger search
Kết quả kỳ vọng: Khi search hiển thị animation loading, khi kết quả trả về hiển thị danh sách kết quả tìm kiếm,
                 không có kết quả thì hiển thị "Không tìm thấy nội dung liên quan"
```

### Chiến lược đối thoại từng bước

Đừng cố gắng để AI sinh toàn bộ code một lần. Đi từng bước, mỗi bước xác nhận OK rồi mới tiến hành bước tiếp:

```mermaid
graph LR
    A["Bước 1: Cấu trúc dữ liệu"] --> B["Xác nhận OK"]
    B --> C["Bước 2: Logic cốt lõi"]
    C --> D["Xác nhận OK"]
    D --> E["Bước 3: Style UI"]
    E --> F["Xác nhận OK"]
    F --> G["Bước 4: Xử lý lỗi"]
```

**Ví dụ đối thoại**:

```
Bạn: Giúp tôi thiết kế cấu trúc dữ liệu bài viết blog, cần có tiêu đề, nội dung, tác giả, thời gian publish, tag

AI: [Sinh cấu trúc dữ liệu]

Bạn: Tốt, bây giờ dựa trên cấu trúc dữ liệu này, giúp tôi viết API lấy danh sách bài viết

AI: [Sinh code API]

Bạn: API không vấn đề, bây giờ giúp tôi viết component hiển thị danh sách bài viết, dùng API vừa rồi

AI: [Sinh code component]
```

### Danh sách thuật ngữ quan trọng

Khi thảo luận code với AI, dùng thuật ngữ kỹ thuật chính xác có thể nâng cao đáng kể hiệu suất giao tiếp:

| Tình huống | Thuật ngữ quan trọng |
|------|----------|
| **Next.js** | App Router, Server Component, Client Component, Server Actions, Middleware |
| **React** | useState, useEffect, props, children, conditional rendering, list rendering |
| **TypeScript** | interface, type, generic, union type, type guard |
| **Tailwind** | flex, grid, responsive, dark mode, custom theme |
| **Database** | CRUD, join query, transaction, index, migration |

### Template prompt cho vấn đề thường gặp

#### Phát triển yêu cầu

```
Giúp tôi triển khai [tên chức năng].

Tech stack: [Next.js/React/TypeScript v.v.]
Yêu cầu:
1. [Yêu cầu cụ thể 1]
2. [Yêu cầu cụ thể 2]
3. [Yêu cầu cụ thể 3]

Tham khảo: [Nếu có chức năng tương tự để tham khảo, paste vào]
```

#### Sửa Bug

```
Tôi gặp một vấn đề: [Mô tả hiện tượng vấn đề]

Code liên quan:
[Paste code liên quan]

Thông báo lỗi:
[Paste toàn bộ thông báo lỗi]

Tôi đã thử:
1. [Phương pháp đã thử 1]
2. [Phương pháp đã thử 2]
```

#### Tối ưu Code

```
Giúp tôi tối ưu đoạn code sau:

[Paste code]

Mục tiêu tối ưu:
- [Tối ưu performance / Tối ưu khả năng đọc / Tối ưu bảo mật]

Điều kiện ràng buộc:
- [Giữ nguyên API / Tương thích phiên bản cũ / v.v.]
```

### Hướng dẫn tránh hố

- **Đừng yêu cầu quá nhiều một lúc**: Task càng lớn, xác suất AI sai càng cao
- **Kịp thời điều chỉnh lỗi**: Phát hiện vấn đề phải feedback ngay, đừng đợi đến cuối
- **Lưu prompt hiệu quả**: Prompt tốt có thể tái sử dụng
- **Hiểu giới hạn của AI**: Kiến thức của nó có thời điểm cắt, có thể không biết tính năng mới
