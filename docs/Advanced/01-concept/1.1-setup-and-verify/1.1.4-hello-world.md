# 1.1.4 Tận mắt nhìn thấy trang đầu tiên - Xác minh Hello World: Khởi động local dev server

### Điểm chính một câu

Đây là "khoảnh khắc khởi động" của phát triển fullstack - khởi động dev server, nhìn thấy trang đầu tiên trong trình duyệt.

### Giá trị cốt lõi

Hello World không chỉ là một trang test, nó xác minh toàn bộ môi trường phát triển được cấu hình đúng. Nếu bạn nhìn thấy trang này, có nghĩa:

- Node.js chạy bình thường
- Dependencies dự án cài đặt thành công
- Compiler Next.js hoạt động bình thường
- Local server có thể khởi động

### Khởi động dev server

Đảm bảo bạn đang ở trong thư mục dự án, chạy:

```bash
pnpm dev
```

Bạn sẽ thấy output tương tự như này:

```
  ▲ Next.js 16.x.x
  - Local:        http://localhost:3000
  - Environments: .env.local

 ✓ Ready in 2.1s
```

### Truy cập trang của bạn

Mở trình duyệt, truy cập `http://localhost:3000`. Bạn sẽ nhìn thấy trang welcome mặc định của Next.js.

**Chúc mừng! Bạn đã chạy thông dự án Next.js đầu tiên thành công.**

### Sửa đổi nội dung trang

Hãy làm một thay đổi đơn giản để xác minh hot reload:

1. Dùng editor mở `src/app/page.tsx`
2. Tìm văn bản trong trang, đổi thành nội dung bạn muốn
3. Lưu file

Bạn sẽ phát hiện **trình duyệt tự động refresh**, hiển thị nội dung sau khi bạn sửa đổi. Đây chính là tính năng Hot Module Replacement của Next.js, nó giúp trải nghiệm phát triển của bạn rất mượt mà.

### Ví dụ sửa đổi lần đầu

Thay nội dung `src/app/page.tsx` thành:

```tsx
export default function Home() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-center p-24">
      <h1 className="text-4xl font-bold">Ứng dụng Next.js đầu tiên của tôi</h1>
      <p className="mt-4 text-gray-600">Hello, Vibe Coding!</p>
    </main>
  );
}
```

Sau khi lưu, trình duyệt sẽ tự động hiển thị nội dung mới.

### Thao tác thường dùng với dev server

| Thao tác | Phím tắt/Lệnh |
|------|-------------|
| Khởi động server | `pnpm dev` |
| Dừng server | `Ctrl + C` |
| Restart server | Dừng rồi khởi động lại |
| Xóa cache restart | `rm -rf .next && pnpm dev` |

### Xử lý vấn đề thường gặp

**Vấn đề 1: Port bị chiếm**

```
Error: listen EADDRINUSE: address already in use :::3000
```

Giải pháp: Đổi port khác để khởi động

```bash
pnpm dev -p 3001
```

**Vấn đề 2: Dependencies chưa cài**

```
Cannot find module 'xxx'
```

Giải pháp: Cài lại dependencies

```bash
pnpm install
```

**Vấn đề 3: Trang trắng**

Mở developer tools của trình duyệt (F12), xem thông tin lỗi ở panel Console, copy cho AI giúp bạn xử lý.
