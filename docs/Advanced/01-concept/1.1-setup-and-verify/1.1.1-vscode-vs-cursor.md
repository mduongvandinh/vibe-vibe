# 1.1.1 Chọn công cụ đúng - So sánh trình soạn thảo: VSCode vs Cursor

### Tóm tắt nhanh

Cursor là phiên bản nâng cao VSCode tích hợp AI sâu - nó cho phép bạn "trò chuyện" với code bằng ngôn ngữ tự nhiên.

### Giá trị cốt lõi

Lựa chọn đúng trình soạn thảo quyết định trải nghiệm phát triển của bạn. Trong thời đại Vibe Coding, trình soạn thảo không chỉ là nơi viết code mà còn là "bộ chỉ huy" hợp tác với AI.

### So sánh nhanh

| Tính năng | VS Code | Cursor |
|------|---------|--------|
| **Chỉnh sửa cơ bản** | ✅ Hoàn thiện | ✅ Hoàn thiện (kế thừa VS Code) |
| **Hệ sinh thái plugin** | ✅ Phong phú | ✅ Tương thích plugin VS Code |
| **Hội thoại AI** | ⚠️ Cần cài plugin | ✅ Hỗ trợ sẵn |
| **Hoàn thành code** | ⚠️ Cần Copilot | ✅ Hoàn thành AI tích hợp |
| **Hiểu ngữ cảnh** | ⚠️ Hạn chế | ✅ Có thể lập chỉ mục toàn bộ codebase |
| **Giá** | Miễn phí | Miễn phí + gói Pro |

### Đề xuất của tôi

**Nếu bạn là người mới học Vibe Coding, chọn Cursor ngay.**

Lý do rất đơn giản: Cursor đã đưa khả năng AI thành "công dân hạng nhất". Bạn không cần phải lo lắng về cài đặt plugin, chỉ cần sử dụng ngay. Các tính năng chính bao gồm:

1. **Cmd/Ctrl + K**: Sau khi chọn code, mô tả những thay đổi bạn muốn bằng ngôn ngữ tự nhiên
2. **Cmd/Ctrl + L**: Mở bảng hội thoại AI, thảo luận các vấn đề code
3. **Hoàn thành Tab**: AI dự đoán code tiếp theo

### Bắt đầu nhanh

1. Truy cập [cursor.com](https://cursor.com) để tải xuống cài đặt
2. Lần khởi động đầu tiên, nó sẽ hỏi có muốn nhập cấu hình VS Code không, chọn "Có"
3. Đăng nhập tài khoản, phiên bản miễn phí có hạn ngạch gọi API hàng tháng

### Hướng dẫn tránh lỗi

- **Đừng lo lắng về lựa chọn công cụ**: Dù chọn cái nào cũng có thể hoàn thành khóa học. Công cụ là để giải quyết vấn đề, không phải để so sánh
- **Người dùng VS Code cũ**: Nếu bạn đã có cấu hình VS Code tùy chỉnh sâu, bạn có thể sử dụng plugin GitHub Copilot trước, sau đó xem xét chuyển đổi
- **Vấn đề mạng**: Cursor cần kết nối internet để gọi dịch vụ AI, đảm bảo môi trường mạng của bạn hoạt động tốt

### Bước tiếp theo

Sau khi chọn xong trình soạn thảo, hãy cấu hình trợ lý AI để nó thực sự "sống động".
