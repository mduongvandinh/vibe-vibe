# 9.3.1 Chọn framework test như thế nào——Jest Configuration: Test Framework và Assertion Library

**Jest là framework test phổ biến nhất trong hệ sinh thái JavaScript, có thể sử dụng mà không cần cấu hình, có chức năng mạnh mẽ và hệ sinh thái hoàn thiện.**

## So sánh framework test

| Đặc tính | Jest | Vitest | Mocha |
|---------|------|--------|-------|
| Độ phức tạp cấu hình | Thấp | Thấp | Cao |
| Tốc độ | Trung bình | Nhanh | Trung bình |
| TypeScript | Cần ts-jest | Native support | Cần cấu hình |
| Snapshot testing | Tích hợp | Tích hợp | Cần plugin |
| Mock | Tích hợp | Tích hợp | Cần plugin |
| Hệ sinh thái | Trưởng thành nhất | Tăng trưởng nhanh | Trưởng thành |

**Khuyên dùng**: Dự án mới dùng Vitest (nhanh hơn), dự án có Jest rồi tiếp tục dùng Jest (chi phí migration).

## Jest cấu hình hoàn chỉnh

### Cài đặt dependencies

```bash
npm install -D jest ts-jest @types/jest
```

### Tệp cấu hình

```typescript
// jest.config.ts
import type { Config } from 'jest';

const config: Config = {
  // Preset: hỗ trợ TypeScript
  preset: 'ts-jest',

  // Test environment: Node.js (server-side) hoặc jsdom (browser)
  testEnvironment: 'node',

  // Vị trí test files
  roots: ['<rootDir>/src', '<rootDir>/__tests__'],

  // Mẫu match test files
  testMatch: [
    '**/__tests__/**/*.test.ts',
    '**/__tests__/**/*.spec.ts',
  ],

  // Thư mục bị bỏ qua
  testPathIgnorePatterns: ['/node_modules/', '/dist/'],

  // Path aliases (giữ nhất quán với tsconfig.json)
  moduleNameMapper: {
    '^@/(.*)$': '<rootDir>/src/$1',
  },

  // File chạy trước test
  setupFilesAfterEnv: ['<rootDir>/jest.setup.ts'],

  // Cấu hình coverage
  collectCoverageFrom: [
    'src/**/*.ts',
    '!src/**/*.d.ts',
    '!src/**/index.ts',
  ],
  coverageThreshold: {
    global: {
      branches: 70,
      functions: 70,
      lines: 70,
      statements: 70,
    },
  },

  // Timeout (milliseconds)
  testTimeout: 10000,

  // Dọn sạch Mock
  clearMocks: true,
  restoreMocks: true,
};

export default config;
```

### Tệp khởi tạo

```typescript
// jest.setup.ts
import { PrismaClient } from '@prisma/client';

// Global Prisma instance
const prisma = new PrismaClient();

// Kết nối database trước test
beforeAll(async () => {
  await prisma.$connect();
});

// Ngắt kết nối sau test
afterAll(async () => {
  await prisma.$disconnect();
});

// Mở rộng expect matchers (optional)
expect.extend({
  toBeWithinRange(received: number, floor: number, ceiling: number) {
    const pass = received >= floor && received <= ceiling;
    return {
      message: () =>
        `expected ${received} ${pass ? 'not ' : ''}to be within range ${floor} - ${ceiling}`,
      pass,
    };
  },
});
```

## Sử dụng assertion library

### Assertion cơ bản

```typescript
describe('Assertion cơ bản', () => {
  // Tương đương
  it('toBe - strict equality', () => {
    expect(1 + 1).toBe(2);
    expect('hello').toBe('hello');
  });

  it('toEqual - deep equality', () => {
    expect({ a: 1 }).toEqual({ a: 1 });
    expect([1, 2, 3]).toEqual([1, 2, 3]);
  });

  // Kiểm tra truthiness
  it('toBeTruthy / toBeFalsy', () => {
    expect(1).toBeTruthy();
    expect(0).toBeFalsy();
    expect(null).toBeFalsy();
  });

  // So sánh số
  it('Assertion số', () => {
    expect(10).toBeGreaterThan(5);
    expect(10).toBeLessThanOrEqual(10);
    expect(0.1 + 0.2).toBeCloseTo(0.3);
  });

  // String matching
  it('Assertion chuỗi', () => {
    expect('hello world').toContain('world');
    expect('hello world').toMatch(/world$/);
  });

  // Array inclusion
  it('Assertion mảng', () => {
    expect([1, 2, 3]).toContain(2);
    expect([{ id: 1 }, { id: 2 }]).toContainEqual({ id: 1 });
  });
});
```

### Assertion async

```typescript
describe('Assertion async', () => {
  it('Sử dụng async/await', async () => {
    const result = await fetchData();
    expect(result).toBe('data');
  });

  it('Sử dụng resolves', async () => {
    await expect(fetchData()).resolves.toBe('data');
  });

  it('Sử dụng rejects', async () => {
    await expect(fetchBadData()).rejects.toThrow('Error');
  });
});
```

### Đối tượng matching

```typescript
describe('Đối tượng matching', () => {
  it('toMatchObject - partial match', () => {
    const user = { id: 1, name: 'John', email: 'john@example.com' };

    expect(user).toMatchObject({
      name: 'John',
    });
  });

  it('expect.any - type matching', () => {
    expect({
      id: expect.any(Number),
      name: expect.any(String),
      createdAt: expect.any(Date),
    }).toMatchObject({
      id: 1,
      name: 'John',
      createdAt: new Date(),
    });
  });

  it('expect.objectContaining', () => {
    const response = { success: true, data: { id: 1 }, meta: {} };

    expect(response).toEqual(
      expect.objectContaining({
        success: true,
        data: expect.objectContaining({ id: 1 }),
      })
    );
  });
});
```


## Chạy test

```json
// package.json
{
  "scripts": {
    "test": "jest",
    "test:watch": "jest --watch",
    "test:coverage": "jest --coverage",
    "test:ci": "jest --ci --coverage --runInBand"
  }
}
```

```bash
# Chạy tất cả test
npm test

# Chạy file cụ thể
npm test -- order.service.test.ts

# Chạy test phù hợp
npm test -- --testNamePattern="createOrder"

# Watch mode
npm test -- --watch
```

## Tóm tắt phần này

Jest là framework test đầy đủ chức năng, tích hợp assertion library, Mock và coverage statistics. Khi cấu hình, lưu ý path aliases phải nhất quán với tsconfig.json, sử dụng setupFilesAfterEnv để khởi tạo toàn cục. Nắm vững các assertion method phổ biến để mã test sạch sẽ và dễ hiểu.
