# 9.5.2 Phong cách code thống nhất chưa——Tiêu chuẩn code: Kiểm tra ESLint/Prettier tự động

**Tiêu chuẩn code không phải sở thích cá nhân——phong cách code thống nhất của nhóm có thể giảm ma sát trong Code Review.**

## ESLint vs Prettier

```mermaid
graph LR
    A[代码检查] --> B[ESLint]

    B --> D[代码质量]
```

## Cấu hình ESLint

```javascript
// eslint.config.js (ESLint 9 Flat Config)
import js from '@eslint/js';
import typescript from '@typescript-eslint/eslint-plugin';
import parser from '@typescript-eslint/parser';
import react from 'eslint-plugin-react';
import reactHooks from 'eslint-plugin-react-hooks';
import prettier from 'eslint-config-prettier';

export default [
  js.configs.recommended,
  {
    files: ['**/*.{ts,tsx}'],
    languageOptions: {
      parser,
      parserOptions: {
        ecmaVersion: 'latest',
        sourceType: 'module',
        ecmaFeatures: { jsx: true },
      },
    },
    plugins: {
      '@typescript-eslint': typescript,
      react,
      'react-hooks': reactHooks,
    },
    rules: {
      // Quy tắc TypeScript
      '@typescript-eslint/no-unused-vars': ['error', { argsIgnorePattern: '^_' }],
      '@typescript-eslint/no-explicit-any': 'warn',
      '@typescript-eslint/explicit-function-return-type': 'off',

      // Quy tắc React
      'react/react-in-jsx-scope': 'off',
      'react-hooks/rules-of-hooks': 'error',
      'react-hooks/exhaustive-deps': 'warn',

      // Quy tắc chung
      'no-console': ['warn', { allow: ['warn', 'error'] }],
      'prefer-const': 'error',
    },
  },
  prettier,
];
```

## Cấu hình CI

```yaml
# .github/workflows/ci.yml
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - run: npm ci

      - name: ESLint
        run: npm run lint

      - name: Prettier check
        run: npm run format:check
```

## Kịch bản package.json

```json
{
  "scripts": {
    "lint": "eslint . --ext .ts,.tsx --max-warnings 0",
    "lint:fix": "eslint . --ext .ts,.tsx --fix",
    "format": "prettier --write .",
    "format:check": "prettier --check ."
  }
}
```

## Lỗi Lint phổ biến

### 1. Biến không sử dụng

```typescript
// ❌ Sai
const unused = 'hello';
function greet(name: string, age: number) {
  return `Hello, ${name}`;
}

// ✅ Đúng
function greet(name: string, _age: number) {
  return `Hello, ${name}`;
}
```

### 2. Phụ thuộc React Hooks

```typescript
// ❌ Cảnh báo: phụ thuộc bị thiếu
useEffect(() => {
  fetchUser(userId);
}, []); // Thiếu phụ thuộc userId

// ✅ Đúng
useEffect(() => {
  fetchUser(userId);
}, [userId]);
```

### 3. Tàn dư console.log

```typescript
// ❌ Cảnh báo
console.log('Thông tin gỡ lỗi');

// ✅ Sử dụng logger
logger.debug('Thông tin gỡ lỗi');
```

## Sửa chữa tự động trước commit

```bash
npm install -D husky lint-staged
npx husky init
```

```json
// package.json
{
  "lint-staged": {
    "*.{ts,tsx}": [
      "eslint --fix",
      "prettier --write"
    ],
    "*.{json,md,yml}": [
      "prettier --write"
    ]
  }
}
```

```bash
# .husky/pre-commit
npx lint-staged
```

## Quy tắc tùy chỉnh

```javascript
// eslint.config.js
{
  rules: {
    // Cấm nhập cụ thể
    'no-restricted-imports': ['error', {
      patterns: [{
        group: ['@/lib/prisma'],
        importNames: ['prisma'],
        message: 'Vui lòng sử dụng getPrisma() để lấy Prisma instance',
      }],
    }],

    // Yêu cầu quy ước đặt tên
    '@typescript-eslint/naming-convention': [
      'error',
      { selector: 'interface', format: ['PascalCase'] },
      { selector: 'typeAlias', format: ['PascalCase'] },
      { selector: 'enum', format: ['PascalCase'] },
    ],
  },
}
```

## Tóm tắt chương

ESLint kiểm tra chất lượng code, Prettier thống nhất định dạng code. Trong CI, chạy `--max-warnings 0` để đảm bảo không có cảnh báo, sử dụng lint-staged để tự động sửa trước commit. Phong cách code thống nhất giúp Code Review tập trung vào logic thay vì định dạng.
