# 0.6.2 Bạn đã đặt mật khẩu đúng chỗ chưa—Biến môi trường và quản lý khóa: Best practice lưu trữ an toàn

## Một câu tóm tắt

Khóa không vào code repository, không vào log. **Biến môi trường + dịch vụ quản lý khóa + cơ chế xoay vòng**, là cơ bản trong cơ bản.

## Phân cấp file .env

- `.env.local`: Riêng tư local, cấu hình bí mật trên máy developer; không commit vào repository.
- `.env.development`: Biến môi trường development được team chia sẻ (không chứa khóa).
- `.env.production`: Biến môi trường production (không chứa khóa plaintext); khóa do dịch vụ quản lý khóa inject.

## Quản lý khóa và .gitignore

- Ví dụ `.gitignore`:

```
.env*
.env.local
.env.production.local
```

- Cấm đặt API Key, connection string database v.v. dạng plaintext vào code hoặc log.
- Môi trường production dùng dịch vụ khóa cloud: AWS Secrets Manager, Azure Key Vault, GCP Secret Manager.

## Thao tác Windows PowerShell

- Xem: `Get-ChildItem Env:`
- Thiết lập phiên: `$env:DB_URL = 'postgres://user:pass@host:5432/db'`
- Lưu trữ lâu dài: `setx DB_URL "postgres://user:pass@host:5432/db"`

## Ví dụ đọc an toàn trong TypeScript

```ts
type EnvVars = {
  NODE_ENV: 'development' | 'production' | 'test'
  API_BASE: string
  DB_URL: string
}

const required: ReadonlyArray<keyof EnvVars> = ['NODE_ENV', 'API_BASE', 'DB_URL']

function readEnv(): EnvVars {
  const missing: string[] = []
  const env = process.env
  required.forEach((k) => {
    if (!env[k]) {
      missing.push(k)
    }
  })
  if (missing.length > 0) {
    throw new Error('Missing env: ' + missing.join(','))
  }
  return {
    NODE_ENV: env.NODE_ENV as EnvVars['NODE_ENV'],
    API_BASE: env.API_BASE as string,
    DB_URL: env.DB_URL as string,
  }
}

const cfg = readEnv()
```

## Xoay vòng khóa

- Cập nhật định kỳ: Mỗi quý xoay vòng khóa quan trọng; khóa rủi ro cao xoay thường xuyên hơn.
- Quản lý phiên bản: Khóa đánh dấu phiên bản bằng tag, phiên bản cũ giữ lại trong thời gian ngắn để hỗ trợ chuyển đổi mượt mà.
- Tự động hóa: CI/CD pull khóa mới nhất trước khi deploy; sau khi release xác minh kết nối khả dụng.

## Khóa môi trường production: Quản lý khóa của cloud provider

- Tạo khóa ở phía cloud, cấu hình chính sách truy cập (quyền tối thiểu), chỉ cho phép service cụ thể đọc.
- Ứng dụng khởi động thì inject khóa động, tránh lưu trữ plaintext trong image và code.
- Kiểm toán và cảnh báo: Sự kiện đọc được ghi chép; truy cập bất thường kích hoạt cảnh báo.

## Hướng dẫn cộng tác với AI

- Ý định cốt lõi: Để AI tạo **quy chuẩn biến môi trường** và **quy trình xoay vòng**, và output lệnh PowerShell.
- Công thức định nghĩa yêu cầu:
  - "Thiết kế biến môi trường cho production và quy trình inject khóa, bao gồm quy tắc `.gitignore` và chiến lược xoay vòng, output lệnh PowerShell."
- Thuật ngữ quan trọng: `env`, `Secrets Manager`, `Key Vault`, `xoay vòng`, `quyền tối thiểu`.

## Hướng dẫn tránh lỗi

- Đừng đặt khóa vào `.env.development` hoặc bất kỳ file chia sẻ nào; chỉ lưu trong `.env.local` hoặc dịch vụ khóa cloud.
- Đừng print `process.env` trong log; thông tin cần thiết phải xử lý che giấu.
