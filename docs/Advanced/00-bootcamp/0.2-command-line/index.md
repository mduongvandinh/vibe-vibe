# 0.2 Dòng lệnh (Command Line)

Dòng lệnh là giao diện mạnh mẽ cho phép bạn tương tác với máy tính thông qua các lệnh văn bản. Chương này sẽ giới thiệu các kỹ năng cơ bản về điều hướng, thao tác file, quản lý quyền hạn và xử lý sự khác biệt giữa các nền tảng khác nhau.
