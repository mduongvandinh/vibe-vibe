# 0.4.3 Thuê vệ sĩ cú pháp cho code JS - Cấu hình TypeScript và Best Practices

## Tóm tắt một câu

TypeScript biến "lỗi runtime" thành "lỗi compile time". Dùng đúng `tsconfig.json`, để hệ thống type trở thành thủ môn của bạn.

## Giải thích chi tiết cấu hình tsconfig.json

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "Node",
    "strict": true,
    "noImplicitAny": true,
    "noImplicitReturns": true,
    "forceConsistentCasingInFileNames": true,
    "skipLibCheck": true,
    "esModuleInterop": true,
    "baseUrl": "./",
    "paths": {
      "@src/*": ["src/*"],
      "@components/*": ["src/components/*"],
      "@lib/*": ["src/lib/*"]
    },
    "outDir": "dist"
  },
  "include": ["src"],
  "exclude": ["node_modules", "dist"]
}
```

## Cấu hình chế độ nghiêm ngặt

- `strict`: Bật tất cả kiểm tra nghiêm ngặt.
- `noImplicitAny`: Cấm `any` ngầm định; kết hợp khai báo type tường minh với suy luận.
- `noImplicitReturns`: Hàm phải return giá trị ở tất cả các nhánh.

## Module resolution và path alias

- `baseUrl`: Thiết lập thư mục chuẩn để resolve.
- `paths`: Định nghĩa alias mapping, giảm relative path.

### Ví dụ: Sử dụng alias để import

```ts
import { Button } from '@components/Button'
import { createClient } from '@lib/client'

type User = {
  id: string
  name: string
}

function getDisplayName(u: User): string {
  return u.name
}
```

## Quản lý file khai báo type

- Type từ cộng đồng: `npm i -D @types/node @types/react @types/react-dom`
- Khai báo tùy chỉnh: Khai báo global type trong `src/types/global.d.ts`.

```ts
declare global {
  interface EnvConfig {
    API_BASE: string
    ENV: 'development' | 'production' | 'test'
  }
}

export {}
```

## Hướng dẫn cộng tác với AI

- Ý định cốt lõi: Để AI sinh `tsconfig.json` **chế độ nghiêm ngặt** và **phương án alias** dựa trên kiến trúc dự án.
- Công thức định nghĩa yêu cầu:
  - "Sinh một `tsconfig.json` chế độ nghiêm ngặt, và cung cấp alias cho `src/components`, `src/lib`."
- Thuật ngữ quan trọng: `strict`, `noImplicitAny`, `paths`, `declaration`, `@types`.

## Hướng dẫn tránh các vấn đề

- Cấm dùng `any` trong code; nếu không chắc type, dùng union type hoặc `unknown` rồi thu hẹp tường minh.
- Alias và cấu trúc thư mục thực tế phải nhất quán; thứ tự tương đối của path mapping sẽ ảnh hưởng đến resolve.
- Khi đổi build tool, kiểm tra tương thích của `module` và `moduleResolution`.
