# 0.3.3 Làm Cho Trang Web Động—JavaScript: Cơ Bản Về Biến/Hàm/Sự Kiện

Nếu HTML là bộ khung, CSS là vẻ ngoài, thì JavaScript chính là ma thuật trao linh hồn cho trang web. Nó khiến trang tĩnh "sống" lại, có thể phản hồi các thao tác của người dùng và thay đổi nội dung một cách động.

## Định Nghĩa Ranh Giới: Nhiệm Vụ Cốt Lõi Của JS Frontend

Trong lĩnh vực frontend, nhiệm vụ cốt lõi của JavaScript có thể được tóm gọn thành hai việc:

1.  **Input (Đầu vào)**: Lắng nghe và phản hồi các hành vi khác nhau của người dùng (click, scroll, nhập bàn phím, v.v.) và thay đổi trạng thái của trình duyệt (trang tải xong, mất kết nối mạng, v.v.). Trong lập trình, chúng được gọi là **Events (Sự kiện)**.
2.  **Output (Đầu ra)**: Dựa trên đầu vào nhận được, chỉnh sửa nội dung trang một cách động. Điều này thường được gọi là **DOM Manipulation (Thao tác DOM)**—thêm, xóa, sửa, tìm kiếm các phần tử HTML và kiểu dáng của chúng.

Tất cả các tương tác frontend đẹp mắt, từ đơn giản như "click nút để chuyển sang chế độ tối" đến phức tạp như "kéo thả file upload", bản chất đều là vòng lặp **"lắng nghe một sự kiện, sau đó thao tác DOM"**.

## Phân Tích Nguyên Tử: Thực Hiện Chức Năng "Click Đổi Màu"

Chúng ta hãy phân tích một yêu cầu tương tác đơn giản nhất: "Sau khi click một nút, thay đổi màu của một đoạn văn."

Yêu cầu này có thể được phân tách thành ba bước độc lập, có thể thực thi:

1.  **Định vị mục tiêu**: Trước tiên, chương trình cần tìm "nút" đó và đoạn "văn bản" đó.
2.  **Gắn kết hành vi**: Sau đó, nói với chương trình cần "lắng nghe" sự kiện "click" của nút đó.
3.  **Thực thi thay đổi**: Cuối cùng, định nghĩa thao tác cụ thể cần thực hiện khi sự kiện click xảy ra—"thay đổi màu văn bản".

## Tư Duy Xác Minh: Checklist Nghiệm Thu

Sau khi để AI hoàn thành nhiệm vụ tương tự, bạn có thể dùng checklist sau để nghiệm thu kết quả:

*   [ ] **Lấy phần tử**: Code có sử dụng các phương thức như `document.getElementById` hoặc `document.querySelector` để lấy chính xác phần tử HTML cần thao tác không?
*   [ ] **Lắng nghe sự kiện**: Code có sử dụng phương thức `addEventListener` để gắn loại sự kiện chính xác (như `click`, `mouseover`) cho phần tử mục tiêu không?
*   [ ] **Hàm callback**: Có cung cấp một hàm (hàm callback), làm tập hợp các lệnh cần thực thi khi sự kiện xảy ra không?
*   [ ] **Chỉnh sửa DOM**: Bên trong hàm callback có chứa code chỉnh sửa thuộc tính phần tử (như `style.color` hoặc `textContent`) không?
*   [ ] **Không có side effect**: Sau khi click nút, có chỉ ảnh hưởng đến phần tử dự kiến mà không phá hủy cấu trúc hay kiểu dáng của các phần khác trên trang không?

## Chiến Lược Phát Triển Tuần Tự: Bắt Đầu Từ MVP

1.  **Bước một (MVP)**: Thực hiện chức năng cốt lõi. Trước tiên tạo một nút và một phần tử văn bản. Dùng JavaScript thực hiện sau khi click nút, nội dung văn bản thay đổi (ví dụ từ "Xin chào" thành "Thế giới"). Đảm bảo logic cốt lõi này chạy đúng.
2.  **Bước hai (Thêm chức năng)**: Thêm thay đổi kiểu dáng trên chức năng cốt lõi. Chỉnh sửa code để sau khi click nút, màu văn bản cũng đổi từ đen sang đỏ.
3.  **Bước ba (Tối ưu code)**: Đóng gói logic thao tác thành một hàm độc lập, có thể tái sử dụng. Như vậy, trong tương lai có thể dễ dàng áp dụng chức năng "click đổi màu" này cho các phần tử khác.

## Phân Tích Logic Quan Trọng

Giả sử chúng ta có HTML sau:

```html
<p id="welcome-text">Xin chào, Thế giới</p>
<button id="color-changer">Đổi Màu</button>
```

Code JavaScript cốt lõi để thực hiện "click đổi màu" như sau:

```javascript
// 1. Định vị phần tử mục tiêu
const textElement = document.getElementById('welcome-text');
const changeButton = document.getElementById('color-changer');

// 2. Gắn kết hành vi: Thêm event listener click cho nút
changeButton.addEventListener('click', function() {
  // 3. Thực thi thay đổi: Đây là hàm callback được thực thi sau khi click
  textElement.style.color = 'red';
});
```

Đoạn code này thể hiện rõ ràng quy trình hoàn chỉnh "định vị -> gắn kết -> thực thi".

## Hướng Dẫn Cộng Tác Với AI

### Ý Định Cốt Lõi

Nói với AI mục tiêu của bạn là **"thêm chức năng tương tác cho trang tĩnh"**.

### Công Thức Định Nghĩa Yêu Cầu

**"Khi [một sự kiện] xảy ra trên [một phần tử], để [một phần tử khác] có [một thay đổi nào đó]."**

*   **Ví dụ**: "Tôi cần thực hiện một chức năng. Khi chuột của người dùng **di chuyển qua** hình ảnh có ID `user-avatar`, để tooltip có ID `user-tooltip` **thay đổi trạng thái hiển thị** từ `none` thành `block`."

### Thuật Ngữ Quan Trọng

*   `document.getElementById()`: Lấy phần tử theo ID, nhanh và chính xác nhất.
*   `document.querySelector()`: Lấy phần tử theo CSS selector, linh hoạt hơn.
*   `addEventListener('click', callback)`: Lắng nghe sự kiện click.
*   `element.style`: Chỉnh sửa inline style của phần tử.
*   `element.textContent` / `element.innerHTML`: Chỉnh sửa nội dung văn bản của phần tử.

### Chiến Lược Tương Tác

1.  **Cung cấp ngữ cảnh HTML**: Gửi cấu trúc HTML liên quan cho AI, để nó biết rõ cần thao tác những phần tử nào.
2.  **Nói rõ loại sự kiện**: Nói rõ với AI là `click` (click chuột), `mouseover` (di chuột qua), `keydown` (nhấn phím) hay sự kiện khác.
3.  **Mô tả hiệu ứng cuối cùng**: Đừng nói "để nó động một chút", mà hãy nói "để margin trái của nó đổi từ 0px sang 20px trong 0.3 giây". Mô tả càng cụ thể, code AI tạo ra càng đúng mong đợi.

Thông qua cách này, bạn có thể hướng dẫn AI chính xác để thêm các tương tác động cho trang tĩnh của bạn, thực sự làm cho sản phẩm "sống" lên.
