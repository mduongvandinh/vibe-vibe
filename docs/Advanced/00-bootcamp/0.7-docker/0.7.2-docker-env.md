# 0.7.2 Dán nhãn lên container—Cấu hình biến môi trường Docker

## Một câu tóm tắt

Cấu hình của container nên inject qua biến môi trường. Tách "môi trường và khóa" ra khỏi image, làm cho image thông dụng, deploy có thể cấu hình.

## Cách dùng cơ bản: --env và --env-file

```powershell
$env:API_BASE = 'https://api.example.com'
docker run -d --name app -p 3000:3000 --env API_BASE=$env:API_BASE myapp:latest
```

Inject hàng loạt bằng file:

`.env.app`

```
API_BASE=https://api.example.com
DB_URL=postgres://user:pass@host:5432/db
```

```powershell
docker run -d --name app -p 3000:3000 --env-file .env.app myapp:latest
```

## Biến môi trường trong Compose

`.env`

```
API_BASE=https://api.example.com
DB_URL=postgres://user:pass@host:5432/db
```

`docker-compose.yml`

```yaml
version: '3.9'
services:
  app:
    image: myapp:latest
    ports:
      - "3000:3000"
    environment:
      - API_BASE=${API_BASE}
      - DB_URL=${DB_URL}
```

## Nhận thức: Bảo mật và Dễ bảo trì

- Không ghi khóa vào image hoặc code; inject thống nhất từ biến môi trường hoặc dịch vụ khóa.
- Phát triển local dùng `.env.local`, team chia sẻ dùng `.env.development` (không chứa khóa).
- Production inject qua dịch vụ quản lý khóa; `.env.production` không chứa khóa plaintext.

## Hướng dẫn cộng tác với AI

- Ý định cốt lõi: Để AI output "quy chuẩn biến môi trường và phương án inject".

  - "Thiết kế phương án inject biến môi trường cho ứng dụng, bao gồm `--env-file` và `.env` của Compose, và cho lệnh PowerShell."
