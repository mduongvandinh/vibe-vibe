# 0.7.4 Tắt chương trình rồi dữ liệu còn không—Volume

## Một câu tóm tắt

Dữ liệu container là tạm thời, tắt là mất. **Volume (Ổ dữ liệu)** giữ "nhà" cho dữ liệu, giúp dữ liệu vẫn còn sau khi service restart.

## Loại volume

- Named volume: Do Docker quản lý, chia sẻ giữa các container, bền vững qua restart.
- Bind mount: Gắn thư mục host vào container, phù hợp phát triển hoặc tương tác file với host.

## Ví dụ named volume

```powershell
docker volume create pgdata
docker run -d --name db -p 5432:5432 -v pgdata:/var/lib/postgresql/data postgres:15-alpine
```

## Ví dụ bind mount (đường dẫn Windows)

```powershell
docker run -d --name app -p 3000:3000 -v "D:\\data:/app/data" myapp:latest
```

## Compose: Điều phối nhiều service

`docker-compose.yml`

```yaml
version: '3.9'
services:
  db:
    image: postgres:15-alpine
    ports:
      - "5432:5432"
    environment:
      - POSTGRES_PASSWORD=secret
    volumes:
      - pgdata:/var/lib/postgresql/data
  app:
    image: myapp:latest
    ports:
      - "3000:3000"
    environment:
      - DB_URL=postgres://postgres:secret@db:5432/postgres
    depends_on:
      - db
volumes:
  pgdata:
```

Khởi động: `docker compose up -d`, xem: `docker compose ps`.

## Nhận thức: Bền vững và Di động

- Dữ liệu không ghi vào lớp container; ghi thống nhất vào volume hoặc bind mount.
- Khi bind đường dẫn trong Windows dùng đường dẫn tuyệt đối; môi trường production ưu tiên named volume.
