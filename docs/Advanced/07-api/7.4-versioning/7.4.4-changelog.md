# 7.4.4 Changelog

## Giải thích một câu

Thay đổi API không chỉ là sửa mã xong——cần ghi chép lại, thông báo cho mọi người, như vậy người dùng mới không bị sốc.

## Định dạng Changelog

### Cấu trúc chuẩn

```markdown
# API Changelog

## [2.0.0] - 2024-06-01

### Breaking Changes
- Trường `name` của object `User` chia thành `firstName` và `lastName`
- Xóa interface `GET /api/users/:id/profile` không dùng nữa

### Added
- Thêm interface `PATCH /api/users/:id/avatar`
- Object `User` thêm trường `lastLoginAt`

### Changed
- Phân trang, số lượng mặc định mỗi trang từ 20 đổi thành 10

### Deprecated
- `GET /api/users/:id/settings` sẽ xóa trong v3.0.0, hãy dùng `/api/settings/:userId`

### Fixed
- Sửa lỗi 500 khi tìm kiếm người dùng với ký tự đặc biệt
```

### Quy tắc phân loại

| Phân loại | Ý nghĩa | Ví dụ |
|------|------|------|
| **Breaking** | Thay đổi không tương thích | Xóa trường, thay đổi loại |
| **Added** | Tính năng mới | Interface mới, trường mới |
| **Changed** | Thay đổi chức năng | Thay đổi hành vi, tối ưu hiệu năng |
| **Deprecated** | Sắp loại bỏ | Đánh dấu interface cũ |
| **Fixed** | Sửa lỗi | Sửa vấn đề |
| **Security** | Cập nhật bảo mật | Sửa lỗ hổng |

## Cơ chế thông báo

### Thông báo response header

```typescript
// Thêm cảnh báo loại bỏ vào phản hồi
function addDeprecationHeaders(response: NextResponse) {
  response.headers.set('Deprecation', 'true')
  response.headers.set('Sunset', 'Sat, 01 Jun 2024 00:00:00 GMT')
  response.headers.set(
    'Link',
    '</api/v2/users>; rel="successor-version"'
  )
  return response
}
```

### Cảnh báo trong response body

## Hướng dẫn di chuyển

### Cấu trúc tài liệu

```markdown
# Hướng dẫn di chuyển từ v1 sang v2

## Tổng quan
Hướng dẫn này giúp bạn di chuyển từ API v1 sang v2.

## Thay đổi chính

### 1. Thay đổi trường tên người dùng

**v1:**
```json
{ "name": "Nguyễn Văn A" }
```

**v2:**
```json
{ "firstName": "Văn", "lastName": "Nguyễn" }
```

**Cách di chuyển:**
```typescript
// Mã cũ
const displayName = user.name

// Mã mới
const displayName = `${user.lastName}${user.firstName}`
```

### 2. Thay đổi cách xác thực

**v1:** Dùng API Key
**v2:** Dùng JWT Token

Chi tiết hướng dẫn di chuyển xem tại tài liệu xác thực.

## Kiểm thử
API v2 hiện khả dụng trong môi trường staging:
`https://staging-api.example.com/v2`

## Lịch trình
- 2024-04-01: Phát hành v2 beta
- 2024-06-01: Phát hành v2 chính thức
- 2024-09-01: Dừng cập nhật v1
- 2024-12-01: Ngừng hoàn toàn v1
```
