# 7.1.2 JSON Định Dạng Dữ Liệu

## Tóm Tắt Một Câu

JSON là "ngôn ngữ chung" giữa frontend và backend——trình duyệt hiểu nó, server hiểu nó, gần như tất cả ngôn ngữ lập trình đều có thể đọc và viết nó.

## JSON Cơ Bản

```json
{
  "id": 1,
  "name": "Alice",
  "email": "alice@example.com",
  "age": 25,
  "isActive": true,
  "tags": ["developer", "designer"],
  "profile": {
    "avatar": "avatar.png",
    "bio": "Hello world"
  },
  "createdAt": "2024-01-15T10:30:00Z"
}
```

### Các kiểu dữ liệu được hỗ trợ

| Kiểu | Ví dụ | Lưu ý |
|------|------|----------|
| **String** | `"hello"` | Phải dùng dấu ngoặc kép |
| **Number** | `123`, `3.14` | Không hỗ trợ NaN, Infinity |
| **Boolean** | `true`, `false` | Viết thường |
| **null** | `null` | Biểu thị giá trị rỗng |
| **Array** | `[1, 2, 3]` | Danh sách có thứ tự |
| **Object** | `{"key": "value"}` | Cặp khóa-giá trị |

### Các kiểu không được hỗ trợ

```typescript
// ❌ Các kiểu này JSON không hỗ trợ
const data = {
  date: new Date(),      // Đối tượng Date
  fn: () => {},          // Hàm
  undef: undefined,      // undefined
  symbol: Symbol('x'),   // Symbol
  bigint: 123n,          // BigInt
}

// Sau khi serialization:
JSON.stringify(data)
// { "date": "2024-01-15T10:30:00.000Z" }
// Hàm, undefined, Symbol sẽ bị bỏ qua
// BigInt sẽ gây lỗi
```

### Cách dùng cơ bản

```typescript
// Serialization: object → string
const user = { name: 'Alice', age: 25 }
const jsonString = JSON.stringify(user)
// '{"name":"Alice","age":25}'

// Deserialization: string → object
const parsed = JSON.parse(jsonString)
// { name: 'Alice', age: 25 }
```

### Xử lý ngày tháng

```typescript
// Vấn đề: Date bị serialization thành string
const data = { createdAt: new Date() }
const json = JSON.stringify(data)
// '{"createdAt":"2024-01-15T10:30:00.000Z"}'

const parsed = JSON.parse(json)
parsed.createdAt  // String chứ không phải Date!

// Giải pháp 1: Dùng hàm reviver
const parsed2 = JSON.parse(json, (key, value) => {
  if (key === 'createdAt') {
    return new Date(value)
  }
  return value
})

// Giải pháp 2: Dùng superjson (được khuyến khích)
import superjson from 'superjson'

const json2 = superjson.stringify({ date: new Date() })
const parsed3 = superjson.parse(json2)
// parsed3.date là thực sự là đối tượng Date
```

## Quy chuẩn Định Dạng API Response

### Cấu trúc response thống nhất

```typescript
// Response thành công
interface SuccessResponse<T> {
  success: true
  data: T
}

// Response danh sách (có phân trang)
interface ListResponse<T> {
  success: true
  data: T[]
  pagination: {
    page: number
    pageSize: number
    total: number
    totalPages: number
  }
}

// Response lỗi
interface ErrorResponse {
  success: false
  error: {
    code: string
    message: string
  }
}
```

### Ví dụ thực tế

```typescript
// Lấy một user
// GET /api/users/123
{
  "success": true,
  "data": {
    "id": "123",
    "name": "Alice",
    "email": "alice@example.com"
  }
}

// Lấy danh sách user
// GET /api/users?page=1&pageSize=10
{
  "success": true,
  "data": [
    { "id": "1", "name": "Alice" },
    { "id": "2", "name": "Bob" }
  ],
  "pagination": {
    "page": 1,
    "pageSize": 10,
    "total": 100,
    "totalPages": 10
  }
}

// Response lỗi
// GET /api/users/999
{
  "success": false,
  "error": {
    "code": "USER_NOT_FOUND",
    "message": "Người dùng không tồn tại"
  }
}
```

## Quy Ước Đặt Tên

### Frontend thường dùng camelCase

```typescript
// Frontend TypeScript
interface User {
  userId: string
  firstName: string
  lastName: string
  createdAt: string
}
```

### Backend có thể dùng snake_case

```python
# Python/Database
{
  "user_id": "123",
  "first_name": "Alice",
  "last_name": "Smith",
  "created_at": "2024-01-15T10:30:00Z"
}
```

### Phương án chuyển đổi

```typescript
// Dùng thư viện để chuyển đổi
import camelcaseKeys from 'camelcase-keys'
import snakecaseKeys from 'snakecase-keys'

// Khi nhận dữ liệu: snake_case → camelCase
const apiResponse = await fetch('/api/users')
const data = camelcaseKeys(await apiResponse.json(), { deep: true })

// Khi gửi dữ liệu: camelCase → snake_case
const body = snakecaseKeys(userData, { deep: true })
await fetch('/api/users', {
  method: 'POST',
  body: JSON.stringify(body),
})
```

## Nhận Thức: Vấn Đề Thường Gặp

### 1. Tham chiếu vòng tròn

```typescript
// ❌ Sẽ gây lỗi
const obj: any = { name: 'Alice' }
obj.self = obj  // Tham chiếu vòng tròn

JSON.stringify(obj)  // TypeError: Converting circular structure to JSON
```

### 2. Quên đặt Content-Type

```typescript
// ❌ Server có thể không phân tích đúng
fetch('/api/users', {
  method: 'POST',
  body: JSON.stringify(data),
})

// ✅ Phải đặt Content-Type
fetch('/api/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify(data),
})
```

### 3. Mất độ chính xác số

```typescript
// Số lớn có thể mất độ chính xác
const bigNumber = 9007199254740993  // Vượt quá phạm vi số nguyên an toàn của JS
JSON.parse('{"id": 9007199254740993}')
// { id: 9007199254740992 }  Mất độ chính xác!

// Giải pháp: Truyền số lớn dưới dạng string
{ "id": "9007199254740993" }
```

## Tóm Tắt Phần Này

| Điểm chính | Giải thích |
|------|------|
| **JSON.stringify** | Chuyển object thành string |
| **JSON.parse** | Chuyển string thành object |
| **Xử lý Date** | Cần chuyển đổi thủ công hoặc dùng superjson |
| **Content-Type** | Gửi JSON phải đặt header |
| **Quy ước đặt tên** | Frontend và backend thống nhất |
