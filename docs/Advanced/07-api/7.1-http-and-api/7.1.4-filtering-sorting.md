# 7.1.4 Lọc và Sắp Xếp

## Tóm Tắt Một Câu

Không phải tất cả dữ liệu đều cần thiết, cũng không phải tất cả dữ liệu đều theo thứ tự mặc định——lọc và sắp xếp cho phép client lấy chính xác dữ liệu cần thiết.

## Thiết Kế Query Parameter

### Định dạng cơ bản

```
GET /api/posts?status=published&author=alice&sort=-createdAt&page=1&pageSize=10
```

| Tham số | Tác dụng | Ví dụ |
|------|------|------|
| `status` | Điều kiện lọc | `status=published` |
| `author` | Điều kiện lọc | `author=alice` |
| `sort` | Sắp xếp trường | `sort=-createdAt`（- biểu thị giảm dần） |
| `page` | Phân trang | `page=1` |
| `pageSize` | Số bản ghi mỗi trang | `pageSize=10` |

## Triển Khai Lọc

### Lọc cơ bản

```typescript
// app/api/posts/route.ts
export async function GET(request: NextRequest) {
  const { searchParams } = new URL(request.url)

  // Xây dựng điều kiện lọc
  const where: Prisma.PostWhereInput = {}

  const status = searchParams.get('status')
  if (status) where.status = status

  const authorId = searchParams.get('authorId')
  if (authorId) where.authorId = authorId

  const posts = await prisma.post.findMany({ where })

  return NextResponse.json({ data: posts })
}
```

### Tìm kiếm mờ

```typescript
const search = searchParams.get('search')
if (search) {
  where.OR = [
    { title: { contains: search, mode: 'insensitive' } },
    { content: { contains: search, mode: 'insensitive' } },
  ]
}
```

### Lọc theo phạm vi

```typescript
// Phạm vi ngày tháng
const startDate = searchParams.get('startDate')
const endDate = searchParams.get('endDate')

if (startDate || endDate) {
  where.createdAt = {}
  if (startDate) where.createdAt.gte = new Date(startDate)
  if (endDate) where.createdAt.lte = new Date(endDate)
}

// Phạm vi giá trị
const minPrice = searchParams.get('minPrice')
const maxPrice = searchParams.get('maxPrice')

if (minPrice || maxPrice) {
  where.price = {}
  if (minPrice) where.price.gte = parseFloat(minPrice)
  if (maxPrice) where.price.lte = parseFloat(maxPrice)
}
```

### Lọc nhiều giá trị

```typescript
// GET /api/posts?tags=tech,design,ai

const tags = searchParams.get('tags')?.split(',')
if (tags?.length) {
  where.tags = { hasSome: tags }
}
```

## Triển Khai Sắp Xếp

### Sắp xếp một trường

```typescript
// sort=createdAt（tăng dần）
// sort=-createdAt（giảm dần，dùng tiền tố - ）

const sort = searchParams.get('sort') || '-createdAt'
const isDesc = sort.startsWith('-')
const field = isDesc ? sort.slice(1) : sort

const posts = await prisma.post.findMany({
  where,
  orderBy: { [field]: isDesc ? 'desc' : 'asc' },
})
```

### Sắp xếp nhiều trường

```typescript
// sort=-createdAt,title

const sortParam = searchParams.get('sort') || '-createdAt'
const orderBy = sortParam.split(',').map(s => {
  const isDesc = s.startsWith('-')
  const field = isDesc ? s.slice(1) : s
  return { [field]: isDesc ? 'desc' : 'asc' }
})

const posts = await prisma.post.findMany({
  where,
  orderBy,
})
```

## Ví Dụ Hoàn Chỉnh

```typescript
// app/api/posts/route.ts
import { NextRequest, NextResponse } from 'next/server'
import { Prisma } from '@prisma/client'

export async function GET(request: NextRequest) {
  const { searchParams } = new URL(request.url)

  // Tham số phân trang
  const page = Math.max(1, parseInt(searchParams.get('page') || '1'))
  const pageSize = Math.min(100, parseInt(searchParams.get('pageSize') || '10'))
  const skip = (page - 1) * pageSize

  // Điều kiện lọc
  const where: Prisma.PostWhereInput = {}

  const status = searchParams.get('status')
  if (status) where.status = status

  const search = searchParams.get('search')
  if (search) {
    where.OR = [
      { title: { contains: search, mode: 'insensitive' } },
      { content: { contains: search, mode: 'insensitive' } },
    ]
  }

  // Sắp xếp
  const sortParam = searchParams.get('sort') || '-createdAt'
  const isDesc = sortParam.startsWith('-')
  const sortField = isDesc ? sortParam.slice(1) : sortParam
  const orderBy = { [sortField]: isDesc ? 'desc' : 'asc' }

  // Truy vấn
  const [posts, total] = await Promise.all([
    prisma.post.findMany({
      where,
      orderBy,
      skip,
      take: pageSize,
      include: { author: true },
    }),
    prisma.post.count({ where }),
  ])

  return NextResponse.json({
    data: posts,
    pagination: {
      page,
      pageSize,
      total,
      totalPages: Math.ceil(total / pageSize),
    },
  })
}
```

## Lựa Chọn Trường

```typescript
// Chỉ trả về các trường cần thiết
// GET /api/posts?fields=id,title,author

const fieldsParam = searchParams.get('fields')
const select = fieldsParam
  ? Object.fromEntries(fieldsParam.split(',').map(f => [f, true]))
  : undefined

const posts = await prisma.post.findMany({
  where,
  select,
})
```

## Nhận Thức: Vấn Đề Bảo Mật

### 1. Danh sách trắng các trường sắp xếp

```typescript
// ❌ Dùng trực tiếp tên trường của người dùng
const orderBy = { [userInput]: 'desc' }  // Nguy hiểm!

// ✅ Dùng danh sách trắng
const allowedSortFields = ['createdAt', 'title', 'viewCount']
const field = allowedSortFields.includes(sortField)
  ? sortField
  : 'createdAt'
```

### 2. Giới hạn tham số phân trang

```typescript
// Ngăn chặn yêu cầu quá nhiều dữ liệu
const pageSize = Math.min(100, parseInt(params.pageSize || '10'))
const page = Math.max(1, parseInt(params.page || '1'))
```

### 3. Bảo vệ chống tiêm nhập tìm kiếm

```typescript
// Prisma đã xử lý tiêm nhập SQL
// Nhưng vẫn cần chú ý tiêm nhập regex
const search = searchParams.get('search')
const sanitized = search?.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
```

## Tóm Tắt Phần Này

| Điểm chính | Giải thích |
|------|------|
| **Lọc** | Truyền điều kiện thông qua query parameter |
| **Sắp xếp** | `-field` biểu thị giảm dần |
| **Lựa chọn trường** | Giảm truyền dữ liệu không cần thiết |
| **Bảo mật** | Xác thực danh sách trắng, giới hạn tham số |
