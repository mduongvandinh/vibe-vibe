# 7.2.4 Định dạng phản hồi lỗi

## Giải thích ngắn gọn

Phản hồi lỗi tốt cần trả lời ba câu hỏi: lỗi ở đâu (code), tại sao lỗi (message), cách sửa lỗi (details).

## Định dạng lỗi thống nhất

```typescript
interface ErrorResponse {
  error: {
    code: string           // Mã lỗi có thể đọc bằng máy
    message: string        // Thông báo lỗi có thể đọc bằng người
    details?: ErrorDetail[] // Lỗi chi tiết từng trường
    traceId?: string       // ID theo dõi yêu cầu
  }
}

interface ErrorDetail {
  field: string            // Trường có lỗi
  message: string          // Thông báo lỗi trường
  code?: string            // Mã lỗi trường
}
```

### Ví dụ

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Xác thực tham số yêu cầu thất bại",
    "details": [
      { "field": "email", "message": "Định dạng email không chính xác", "code": "INVALID_FORMAT" },
      { "field": "password", "message": "Mật khẩu ít nhất 8 ký tự", "code": "TOO_SHORT" }
    ],
    "traceId": "abc-123-xyz"
  }
}
```

## Triển khai xử lý lỗi thống nhất

### Định nghĩa lớp lỗi

```typescript
// lib/errors.ts
export class AppError extends Error {
  constructor(
    public code: string,
    message: string,
    public statusCode: number = 400,
    public details?: ErrorDetail[]
  ) {
    super(message)
    this.name = 'AppError'
  }
}

export class ValidationError extends AppError {
  constructor(details: ErrorDetail[]) {
    super('VALIDATION_ERROR', 'Xác thực tham số yêu cầu thất bại', 400, details)
  }
}

export class NotFoundError extends AppError {
  constructor(resource: string) {
    super('NOT_FOUND', `${resource}không tồn tại`, 404)
  }
}

export class UnauthorizedError extends AppError {
  constructor(message = 'Vui lòng đăng nhập trước') {
    super('UNAUTHORIZED', message, 401)
  }
}

export class ForbiddenError extends AppError {
  constructor(message = 'Không có quyền truy cập tài nguyên này') {
    super('FORBIDDEN', message, 403)
  }
}
```

### Công cụ phản hồi lỗi

```typescript
// lib/api-response.ts
export function errorResponse(error: AppError, traceId?: string) {
  return NextResponse.json(
    {
      error: {
        code: error.code,
        message: error.message,
        details: error.details,
        traceId,
      },
    },
    { status: error.statusCode }
  )
}

export function successResponse<T>(data: T, status = 200) {
  return NextResponse.json({ data }, { status })
}
```

### Sử dụng tuyến API

```typescript
// app/api/users/route.ts
import { AppError, ValidationError, NotFoundError } from '@/lib/errors'
import { errorResponse, successResponse } from '@/lib/api-response'

export async function POST(request: NextRequest) {
  const traceId = crypto.randomUUID()

  try {
    const body = await request.json()

    // Xác thực
    const errors: ErrorDetail[] = []
    if (!body.email) {
      errors.push({ field: 'email', message: 'Email không thể trống', code: 'REQUIRED' })
    }
    if (!body.password || body.password.length < 8) {
      errors.push({ field: 'password', message: 'Mật khẩu ít nhất 8 ký tự', code: 'TOO_SHORT' })
    }

    if (errors.length > 0) {
      throw new ValidationError(errors)
    }

    // Kiểm tra email đã tồn tại chưa
    const existing = await prisma.user.findUnique({
      where: { email: body.email },
    })
    if (existing) {
      throw new AppError('EMAIL_EXISTS', 'Email đã được đăng ký', 409)
    }

    // Tạo người dùng
    const user = await prisma.user.create({ data: body })
    return successResponse(user, 201)

  } catch (error) {
    if (error instanceof AppError) {
      return errorResponse(error, traceId)
    }

    console.error(`[${traceId}] Lỗi không xác định:`, error)
    return errorResponse(
      new AppError('INTERNAL_ERROR', 'Lỗi nội bộ máy chủ', 500),
      traceId
    )
  }
}
```

## Xử lý lỗi phía trước

```typescript
// lib/api-client.ts
interface ApiError {
  code: string
  message: string
  details?: { field: string; message: string }[]
  traceId?: string
}

async function fetchApi<T>(url: string, options?: RequestInit): Promise<T> {
  const response = await fetch(url, options)
  const data = await response.json()

  if (!response.ok) {
    const error = data.error as ApiError
    throw new ApiClientError(error)
  }

  return data.data
}

class ApiClientError extends Error {
  constructor(public error: ApiError) {
    super(error.message)
  }

  // Lấy lỗi trường
  getFieldError(field: string): string | undefined {
    return this.error.details?.find(d => d.field === field)?.message
  }

  // Xác định loại lỗi
  isUnauthorized() {
    return this.error.code === 'UNAUTHORIZED'
  }

  isValidationError() {
    return this.error.code === 'VALIDATION_ERROR'
  }
}
```

### Sử dụng trong biểu mẫu

```typescript
// Gửi biểu mẫu
async function handleSubmit(data: FormData) {
  try {
    await fetchApi('/api/users', {
      method: 'POST',
      body: JSON.stringify(data),
    })
    toast.success('Đăng ký thành công')
  } catch (error) {
    if (error instanceof ApiClientError) {
      if (error.isValidationError()) {
        // Hiển thị lỗi trường
        setErrors({
          email: error.getFieldError('email'),
          password: error.getFieldError('password'),
        })
      } else {
        toast.error(error.message)
      }
    }
  }
}
```


## Tổng kết phần này

| Điểm chính | Giải thích |
|------|------|
| **Định dạng thống nhất** | code + message + details |
| **Mã lỗi** | Chữ hoa gạch dưới, có thể đọc bằng máy |
| **Lớp lỗi** | Gói các loại lỗi phổ biến |
| **Xử lý phía trước** | Xử lý khác nhau dựa trên code |
