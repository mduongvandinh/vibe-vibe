# 11.1.4 Thông báo Phát hành: Nhật ký Thay đổi và Hướng dẫn Nâng cấp

## Một Câu nói Xuyên suốt

**CHANGELOG** （Nhật ký Thay đổi）ghi lại Nội dung Thay đổi của mỗi Phiên bản, Giúp Người dùng Hiểu rõ Những gì Đã cập nhật, Có cần Nâng cấp không, Khi Nâng cấp cần Lưu ý gì.

## Giá trị Cốt lõi

Duy trì CHANGELOG cho phép bạn:
- Giúp Người dùng Hiểu Nhanh chóng Sự thay đổi Phiên bản
- Giảm Không chắc chắn Khi Nâng cấp
- Thiết lập Lịch sử Dự án Có thể Truy tìm được

## Quy cách CHANGELOG

Tuân theo Quy cách [Keep a Changelog](https://keepachangelog.com/):

```markdown
# Changelog

## [Unreleased]
### Added
- Thêm Tính năng Tải lên Hình đại diện Người dùng

## [1.2.0] - 2024-01-15
### Added
- Thêm Hỗ trợ Chế độ Tối
- Thêm Tính năng Chuyển đổi Ngôn ngữ Đa ngôn

### Changed
- Tối ưu hóa Tốc độ Tải Trang chủ

### Fixed
- Sửa Vấn đề Kiểu dáng Trang Đăng nhập

### Deprecated
- API `getUserInfo` Sẽ được Loại bỏ ở Phiên bản 2.0.0

### Removed
- Loại bỏ Điểm cuối `oldApi` Lỗi thời

### Security
- Sửa Lỗ hổng XSS Bảo mật

## [1.1.0] - 2024-01-01
### Added
- Phát hành Phiên bản Ban đầu
```

## Giải thích Loại Thay đổi

| Loại | Giải thích | Ví dụ |
|------|------|------|
| `Added` | Thêm Chức năng Mới | Thêm Tính năng Đăng ký Người dùng |
| `Changed` | Thay đổi Chức năng | Tối ưu hóa Thuật toán Tìm kiếm |
| `Deprecated` | Sắp Bị loại bỏ | API này Sẽ được Loại bỏ ở Phiên bản Tiếp theo |
| `Removed` | Đã Loại bỏ | Loại bỏ Giao diện Đăng nhập Cũ |
| `Fixed` | Sửa Lỗi | Sửa Lỗi Hiển thị Ngày tháng |
| `Security` | Liên quan Bảo mật | Sửa Lỗ hổng Vượt qua Quyền hạn |

## Bắt đầu Nhanh chóng

### Duy trì Thủ công

Cập nhật Đồng bộ `CHANGELOG.md` mỗi khi Commit:

```bash
# Thêm Thay đổi vào Phần Unreleased
echo "- Thêm Chức năng XX" >> CHANGELOG.md
git add CHANGELOG.md
git commit -m "docs: update changelog"
```

### Tạo tự động

Sử dụng Công cụ để Tạo từ Lịch sử Commit Git:

```bash
# Cài đặt conventional-changelog-cli
npm install -g conventional-changelog-cli

# Tạo CHANGELOG
conventional-changelog -p angular -i CHANGELOG.md -s
```

### Sử dụng cùng với npm version

```json
{
  "scripts": {
    "version": "conventional-changelog -p angular -i CHANGELOG.md -s && git add CHANGELOG.md"
  }
}
```

Bằng cách này, mỗi khi Chạy `npm version` sẽ Tự động Cập nhật CHANGELOG.

## Hướng dẫn Nâng cấp

Đối với Thay đổi Phá vỡ, cần Cung cấp Hướng dẫn Nâng cấp Chi tiết:

```markdown
## Nâng cấp từ 1.x lên 2.0

### Thay đổi Phá vỡ

#### 1. Thay đổi Định dạng Phản hồi API

**Định dạng Cũ**:
```json
{ "data": [...], "total": 100 }
```

**Định dạng Mới**:
```json
{ "items": [...], "pagination": { "total": 100 } }
```

**Phương pháp Di chuyển**:
```typescript
// Mã Cũ
const { data, total } = response

// Mã Mới
const { items, pagination } = response
const { total } = pagination
```

#### 2. Đổi tên Biến môi trường

| Tên Cũ | Tên Mới |
|--------|--------|
| `DB_URL` | `DATABASE_URL` |
| `API_KEY` | `NEXT_PUBLIC_API_KEY` |
```

## GitHub Release

Ngoài CHANGELOG, bạn cũng có thể Tạo Release trên GitHub:

```bash
# Sử dụng gh CLI để Tạo Release
gh release create v1.2.0 \
  --title "v1.2.0" \
  --notes-file CHANGELOG.md \
  --latest
```

## Hướng dẫn Tránh Lỗi

::: danger Lỗi Dễ mắc nhất của Người mới bắt đầu
1. Chỉ Cập nhật CHANGELOG khi Phát hành（Nên Cập nhật cùng Mã）
2. Mô tả Thay đổi Quá Chung chung（"Sửa một số Vấn đề" Không có Giá trị）
3. Thay đổi Phá vỡ Không có Hướng dẫn Di chuyển
4. Quên Cập nhật Phần Unreleased
:::
