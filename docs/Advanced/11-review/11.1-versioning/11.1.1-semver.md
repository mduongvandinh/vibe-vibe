# 11.1.1 SemVer Specification: Phiên bản Chính/Phụ/Bản vá

## Một Câu nói Xuyên suốt

**Semantic Versioning (SemVer)** là một bộ quy tắc đặt tên phiên bản, định dạng là `Phiên bản Chính.Phiên bản Phụ.Bản vá`, mỗi con số thay đổi đều truyền tải một ý nghĩa cụ thể.

## Giá trị Cốt lõi

Hiểu rõ SemVer cho phép bạn:
- Xác định đúng rủi ro khi nâng cấp các phụ thuộc
- Đặt số phiên bản hợp lý cho dự án của riêng bạn
- Thiết lập hợp đồng phiên bản rõ ràng với nhóm và người dùng

## Ý nghĩa của Ba Con số

```
1.2.3
│ │ └── Bản vá (Patch): Sửa lỗi, Tương thích ngược
│ └──── Phiên bản Phụ (Minor): Chức năng Mới, Tương thích ngược
└────── Phiên bản Chính (Major): Thay đổi Phá vỡ, Không tương thích ngược
```

| Thay đổi Phiên bản | Ý nghĩa | Người dùng Cần làm gì |
|----------|------|----------------|
| `1.0.0` → `1.0.1` | Đã sửa Lỗi | Nâng cấp với Yên tâm |
| `1.0.0` → `1.1.0` | Thêm Chức năng Mới | Nâng cấp với Yên tâm, Có thể Dùng Chức năng Mới |
| `1.0.0` → `2.0.0` | Có Thay đổi Phá vỡ | Cần đọc Hướng dẫn Nâng cấp |

## Bắt đầu Nhanh chóng

### Đặt Phiên bản trong package.json

```json
{
  "name": "my-app",
  "version": "1.2.3"
}
```

### Sử dụng lệnh npm để Cập nhật Phiên bản

```bash
# Sửa Lỗi: 1.2.3 → 1.2.4
npm version patch

# Thêm Chức năng Mới: 1.2.3 → 1.3.0
npm version minor

# Thay đổi Phá vỡ: 1.2.3 → 2.0.0
npm version major
```

### Phiên bản Tiền phát hành

```bash
# 1.2.3 → 1.2.4-alpha.0
npm version prerelease --preid=alpha

# 1.2.3 → 1.2.4-beta.0
npm version prerelease --preid=beta

# 1.2.3 → 1.2.4-rc.0
npm version prerelease --preid=rc
```

## Quy tắc Đặc biệt

### Phiên bản 0.x.x

Phiên bản `0.x.x` biểu thị rằng dự án vẫn đang trong giai đoạn phát triển ban đầu, API có thể thay đổi bất kỳ lúc nào:

```
0.1.0  ─→  Phiên bản Phát triển Ban đầu
0.2.0  ─→  Có thể có Thay đổi Phá vỡ
0.2.1  ─→  Sửa Lỗi
1.0.0  ─→  Phiên bản Ổn định Đầu tiên
```

### So sánh Số Phiên bản

```typescript
// Triển khai Đơn giản So sánh Số Phiên bản
function compareVersions(a: string, b: string): number {
  const [aMajor, aMinor, aPatch] = a.split('.').map(Number)
  const [bMajor, bMinor, bPatch] = b.split('.').map(Number)

  if (aMajor !== bMajor) return aMajor - bMajor
  if (aMinor !== bMinor) return aMinor - bMinor
  return aPatch - bPatch
}

compareVersions('1.2.3', '1.2.4')  // -1（a < b）
compareVersions('2.0.0', '1.9.9')  // 1（a > b）
```

## Phạm vi Phiên bản Phụ thuộc

Trong `package.json`, bạn có thể chỉ định Phạm vi Phiên bản của Phụ thuộc:

| Ký hiệu | Ý nghĩa | Ví dụ |
|------|------|------|
| `^` | Cho phép Cập nhật Phiên bản Phụ và Bản vá | `^1.2.3` → `1.x.x` |
| `~` | Chỉ cho phép Cập nhật Bản vá | `~1.2.3` → `1.2.x` |
| Không có ký hiệu | Khóa Phiên bản Chính xác | `1.2.3` → Chỉ dùng `1.2.3` |

```json
{
  "dependencies": {
    "react": "^18.2.0",      // 18.2.0 ~ 18.x.x
    "lodash": "~4.17.21",    // 4.17.21 ~ 4.17.x
    "typescript": "5.3.2"    // Khóa Chính xác
  }
}
```

## Hướng dẫn Tránh Lỗi

::: danger Lỗi Dễ mắc nhất của Người mới bắt đầu
1. Đưa Thay đổi Phá vỡ vào Phiên bản `1.x.x` nhưng không nâng Phiên bản Chính
2. Quên cập nhật Số Phiên bản trước khi Phát hành
3. Thay đổi Tệp `package.json` Thủ công thay vì dùng `npm version`
4. Không hiểu rõ Sự khác biệt giữa `^` và `~` dẫn đến Nâng cấp Không mong muốn
:::
