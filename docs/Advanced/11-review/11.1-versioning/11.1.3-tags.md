# 11.1.3 Git Tag: Đánh dấu Phiên bản và Điểm Phát hành

## Một Câu nói Xuyên suốt

**Git Tag** là một cách để Đánh Thẻ Vĩnh viễn lên Một Commit cụ thể, được sử dụng để Đánh dấu Phiên bản Phát hành, Tiện Tìm kiếm và Rollback về Sau.

## Giá trị Cốt lõi

Sử dụng Git Tag cho phép bạn:
- Xác định chính xác Trạng thái Mã của mỗi Phiên bản Phát hành
- Rollback nhanh chóng về Bất kỳ Phiên bản Lịch sử nào
- Kích hoạt Quy trình Phát hành CI/CD Tự động

## Hai Loại Tag

| Loại | Lệnh | Trường hợp Sử dụng |
|------|------|----------|
| Lightweight Tag | `git tag v1.0.0` | Đánh dấu Tạm thời |
| Annotated Tag | `git tag -a v1.0.0 -m "..."` | Phát hành Chính thức |

## Bắt đầu Nhanh chóng

### Tạo Tag

```bash
# Tạo Annotated Tag（Khuyên dùng cho Phát hành）
git tag -a v1.2.0 -m "Release version 1.2.0"

# Tạo Lightweight Tag
git tag v1.2.0

# Đánh Tag cho Commit Lịch sử
git tag -a v1.1.0 abc1234 -m "Release version 1.1.0"
```

### Xem Tag

```bash
# Liệt kê Tất cả Tag
git tag

# Lọc theo Mẫu
git tag -l "v1.*"

# Xem Chi tiết Tag
git show v1.2.0
```

### Đẩy Tag lên Kho lưu trữ Từ xa

```bash
# Đẩy Một Tag Đơn
git push origin v1.2.0

# Đẩy Tất cả Tag
git push origin --tags

# Đẩy Tất cả Annotated Tag
git push origin --follow-tags
```

### Xóa Tag

```bash
# Xóa Tag Cục bộ
git tag -d v1.2.0

# Xóa Tag Từ xa
git push origin --delete v1.2.0
```

## Hoạt động dựa trên Tag

### Checkout Phiên bản Cụ thể

```bash
# Checkout đến Tag Cụ thể（Tách rời HEAD）
git checkout v1.2.0

# Tạo Branch Mới dựa trên Tag
git checkout -b hotfix/v1.2.1 v1.2.0
```

### Xem Sự khác biệt giữa Phiên bản

```bash
# So sánh Hai Phiên bản
git diff v1.1.0 v1.2.0

# Xem Commit giữa Phiên bản
git log v1.1.0..v1.2.0 --oneline
```

## Quy tắc Đặt tên Tag

```
v1.2.3          # Phiên bản Tiêu chuẩn
v1.2.3-alpha.1  # Tiền phát hành Alpha
v1.2.3-beta.1   # Tiền phát hành Beta
v1.2.3-rc.1     # Release Candidate
```

## Sử dụng cùng với CI/CD

GitHub Actions có thể lắng nghe Đẩy Tag để Kích hoạt Phát hành:

```yaml
# .github/workflows/release.yml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Get version
        run: echo "VERSION=${GITHUB_REF#refs/tags/v}" >> $GITHUB_ENV
      - name: Build and deploy
        run: |
          echo "Deploying version $VERSION"
```

## Hướng dẫn Tránh Lỗi

::: danger Lỗi Dễ mắc nhất của Người mới bắt đầu
1. Quên Đẩy Tag lên Kho lưu trữ Từ xa
2. Dùng Lightweight Tag cho Phát hành Chính thức（Thiếu Thông tin Siêu dữ liệu）
3. Đánh Tag trên Commit Sai
4. Sửa đổi Tag Đã Đẩy（Phá hủy Lịch sử Ghi chép）
:::
