# 11.2.1 Cấu hình Workflow: Điều kiện kích hoạt và môi trường thực thi

## Giải quyết vấn đề bằng một câu

Workflow của GitHub Actions là quy trình tự động hóa được định nghĩa bằng YAML, thông qua chỉ định **điều kiện kích hoạt** và **các bước thực thi** để triển khai CI/CD.

## Giá trị cốt lõi

Hiểu rõ cấu hình Workflow cho phép bạn:
- Tự động chạy kiểm tra khi code được gửi
- Bắt buộc phải vượt qua test trước khi merge PR
- Tự động triển khai đến môi trường sản xuất khi phát hành

## Cấu trúc tệp

```
.github/
└── workflows/
    ├── ci.yml        # Continuous Integration
    ├── deploy.yml    # Deployment Process
    └── release.yml   # Release Process
```

## Bắt đầu nhanh chóng

### Cấu hình điều kiện kích hoạt

```yaml
name: CI

on:
  # Kích hoạt khi push đến nhánh chỉ định
  push:
    branches: [main, develop]
    paths:
      - 'src/**'           # Chỉ kích hoạt khi src thay đổi
      - '!src/**/*.test.ts' # Bỏ qua các thay đổi tệp test

  # Kích hoạt khi PR được tạo cho nhánh chỉ định
  pull_request:
    branches: [main]

  # Kích hoạt theo lịch (8:00 sáng giờ Bắc Kinh)
  schedule:
    - cron: '0 0 * * *'

  # Kích hoạt thủ công
  workflow_dispatch:
    inputs:
      environment:
        description: 'Deployment environment'
        required: true
        default: 'staging'
```

### Cấu hình môi trường thực thi

```yaml
jobs:
  build:
    runs-on: ubuntu-latest  # Môi trường chạy

    strategy:
      matrix:
        node-version: [18, 20]  # Test đa phiên bản

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node-version }}
          cache: 'npm'  # Lưu trữ npm dependencies

      - run: npm ci
      - run: npm test
```

### Phụ thuộc Job và chạy song song

```yaml
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npm run lint

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npm test

  build:
    needs: [lint, test]  # Phụ thuộc vào lint và test thành công
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci
      - run: npm run build
```

## Sự kiện kích hoạt thường dùng

| Sự kiện | Giải thích | Trường hợp sử dụng |
|------|------|----------|
| `push` | Gửi code | Build nhánh chính |
| `pull_request` | Hoạt động PR | Kiểm tra trước code review |
| `release` | Release | Triển khai tự động |
| `schedule` | Nhiệm vụ lịch định | Quét bảo mật hàng ngày |
| `workflow_dispatch` | Kích hoạt thủ công | Triển khai khẩn cấp |

## Thực thi có điều kiện

```yaml
jobs:
  deploy:
    runs-on: ubuntu-latest
    # Chỉ thực thi trên nhánh main và không phải PR
    if: github.ref == 'refs/heads/main' && github.event_name != 'pull_request'
    steps:
      - run: echo "Deploying to production"
```

## Hướng dẫn tránh sai lầm

::: danger Sai lầm dễ mắc phải nhất của người mới
1. Lỗi thụt lề YAML dẫn đến lỗi phân tích cấu hình
2. Quên cấu hình `actions/checkout` dẫn đến không có code
3. Không lưu trữ dependencies dẫn đến tải lại mỗi lần
4. Lưu trữ thông tin nhạy cảm trực tiếp trong tệp cấu hình
:::
