# 6.1.3 Đăng nhập GitHub như thế nào—GitHub OAuth thực hành

## Tóm tắt trong một câu

GitHub OAuth là cách đăng nhập thân thiện nhất với lập trình viên—chỉ cần 2 phút để đăng ký ứng dụng, cấu hình đơn giản hơn Google rất nhiều.

## Tại sao nên đề xuất đăng nhập GitHub

| Tính năng | GitHub | Google |
|------|--------|--------|
| Độ phức tạp đăng ký | Đơn giản | Cần dự án + màn hình agree |
| Yêu cầu duyệt | Không | Chế độ test cần thêm người dùng |
| Thân thiện với lập trình viên | Cực cao | Bình thường |
| Trường hợp sử dụng | Sản phẩm kỹ thuật | Sản phẩm chung |

## Bước 1: Tạo GitHub OAuth App

1. Đăng nhập GitHub → Hình đại diện góc trên cùng → **Settings**
2. Menu bên trái ở dưới cùng → **Developer settings**
3. Chọn **OAuth Apps** → **New OAuth App**
4. Điền thông tin ứng dụng:

| Trường | Môi trường phát triển | Môi trường sản xuất |
|------|----------|----------|
| Application name | My Dev App | My Production App |
| Homepage URL | `http://localhost:3000` | `https://your-domain.com` |
| Authorization callback URL | `http://localhost:3000/api/auth/callback/github` | `https://your-domain.com/api/auth/callback/github` |

5. Nhấp vào **Register application**
6. Sau khi tạo, nhấp vào **Generate a new client secret**
7. Sao chép **Client ID** và **Client Secret**

::: danger Quan trọng
Client Secret chỉ hiển thị một lần! Sao chép ngay lập tức, nếu không cần tạo lại.
:::

## Bước 2: Cấu hình biến môi trường

```bash
# .env.local
GITHUB_ID=your-github-client-id
GITHUB_SECRET=your-github-client-secret
```

## Bước 3: Cấu hình NextAuth

```typescript
// app/api/auth/[...nextauth]/route.ts
import NextAuth from "next-auth"
import GitHubProvider from "next-auth/providers/github"

const handler = NextAuth({
  providers: [
    GitHubProvider({
      clientId: process.env.GITHUB_ID!,
      clientSecret: process.env.GITHUB_SECRET!,
    }),
  ],
})

export { handler as GET, handler as POST }
```

## Lấy dữ liệu GitHub của người dùng

Dữ liệu người dùng mà GitHub trả về bao gồm:

```typescript
interface GitHubProfile {
  id: number
  login: string        // Tên người dùng GitHub
  name: string | null  // Tên hiển thị
  email: string | null // Email (có thể trống)
  avatar_url: string   // Đường dẫn avatar
  html_url: string     // Trang chủ GitHub
}
```

### Lấy email người dùng

Một số người dùng có email riêng tư, cần cấu hình scope bổ sung:

```typescript
GitHubProvider({
  clientId: process.env.GITHUB_ID!,
  clientSecret: process.env.GITHUB_SECRET!,
  authorization: {
    params: {
      scope: "read:user user:email",
    },
  },
})
```

### Xử lý trong Callback

```typescript
callbacks: {
  async signIn({ user, account, profile }) {
    // profile chứa dữ liệu thô được GitHub trả về
    const githubProfile = profile as {
      login: string
      html_url: string
    }

    console.log("Tên người dùng GitHub:", githubProfile.login)
    console.log("Trang chủ GitHub:", githubProfile.html_url)

    return true
  },
}
```

## Hỗ trợ đồng thời Google và GitHub

```typescript
import NextAuth from "next-auth"
import GoogleProvider from "next-auth/providers/google"
import GitHubProvider from "next-auth/providers/github"

const handler = NextAuth({
  providers: [
    GoogleProvider({
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    }),
    GitHubProvider({
      clientId: process.env.GITHUB_ID!,
      clientSecret: process.env.GITHUB_SECRET!,
    }),
  ],
})

export { handler as GET, handler as POST }
```

Khi người dùng nhấp đăng nhập, NextAuth sẽ tự động hiển thị tất cả các tùy chọn đăng nhập có sẵn.

## GitHub Apps vs OAuth Apps

GitHub cung cấp hai loại ứng dụng:

| Tính năng | OAuth Apps | GitHub Apps |
|------|------------|-------------|
| Mục đích | Xác thực người dùng | Tích hợp kho/tổ chức |
| Mức độ chi tiết quyền hạn | Thô | Chi tiết |
| Cách cài đặt | Ủy quyền người dùng | Cài đặt tổ chức/kho |
| Hỗ trợ NextAuth | ✅ | Cần cấu hình thêm |

**Đối với trường hợp đăng nhập, sử dụng OAuth Apps là đủ.**

## Các câu hỏi thường gặp

### Lỗi địa chỉ callback

```
The redirect_uri MUST match the registered callback URL
```

**Giải pháp**: Đảm bảo callback URL trong GitHub OAuth App hoàn toàn khớp với `NEXTAUTH_URL`, bao gồm giao thức (http/https) và số cổng.

### Không lấy được email người dùng

**Nguyên nhân**: Người dùng đã đặt email thành riêng tư trong cài đặt GitHub

**Giải pháp**:
1. Thêm scope `user:email`
2. Hoặc yêu cầu người dùng tự điền email trong quy trình đăng ký
