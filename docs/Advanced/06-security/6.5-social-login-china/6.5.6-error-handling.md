# 6.5.6 Error Handling

## Phá vỡ vấn đề bằng một câu

Quy trình đăng nhập bên thứ ba liên quan đến tương tác nhiều bên, bất kỳ bước nào cũng có thể bị lỗi. Xử lý lỗi tốt giúp người dùng **biết chuyện gì đã xảy ra, cần phải làm gì**, thay vì đối mặt với trang trắng.

## Giá trị cốt lõi

Xử lý lỗi hoàn thiện sẽ cho phép bạn:
- Cải thiện trải nghiệm người dùng, giảm mất khách
- Nhanh chóng xác định nguyên nhân vấn đề
- Giảm áp lực hỗ trợ khách hàng

## Các loại lỗi phổ biến

| Loại lỗi | Nguyên nhân phổ biến | Thông báo cho người dùng |
|----------|----------|----------|
| Người dùng hủy ủy quyền | Nhấp vào "Từ chối" | Bạn đã hủy ủy quyền, vui lòng thử lại |
| Xác minh state không thành công | Cuộc tấn công CSRF/link hết hạn | Yêu cầu đã hết hạn, vui lòng đăng nhập lại |
| Lấy access_token không thành công | Vấn đề mạng/sai khóa | Dịch vụ đăng nhập tạm thời không khả dụng |
| Lấy thông tin người dùng không thành công | token hết hạn/quyền không đủ | Không thể lấy thông tin của bạn |

## Xử lý lỗi thống nhất

```typescript
// lib/oauth-errors.ts
export class OAuthError extends Error {
  constructor(
    public code: string,
    public userMessage: string,
    public debugMessage?: string
  ) {
    super(userMessage)
    this.name = 'OAuthError'
  }
}

export const OAuthErrors = {
  USER_CANCELLED: new OAuthError(
    'user_cancelled',
    'Bạn đã hủy ủy quyền, nếu muốn sử dụng dịch vụ vui lòng thử lại',
    'User denied authorization'
  ),
  STATE_MISMATCH: new OAuthError(
    'state_mismatch',
    'Yêu cầu đăng nhập đã hết hạn, vui lòng đăng nhập lại',
    'State parameter validation failed'
  ),
  TOKEN_FAILED: new OAuthError(
    'token_failed',
    'Dịch vụ đăng nhập tạm thời không khả dụng, vui lòng thử lại sau',
    'Failed to exchange code for token'
  ),
  USER_INFO_FAILED: new OAuthError(
    'user_info_failed',
    'Không thể lấy thông tin tài khoản của bạn, vui lòng thử lại',
    'Failed to fetch user info'
  ),
  BINDING_CONFLICT: new OAuthError(
    'binding_conflict',
    'Tài khoản này đã được ràng buộc với người dùng khác',
    'OAuth account already linked to another user'
  ),
}
```

## Ví dụ xử lý callback

```typescript
// app/api/auth/wechat/callback/route.ts
export async function GET(request: Request) {
  const { searchParams } = new URL(request.url)

  try {
    // 1. Kiểm tra xem người dùng có hủy ủy quyền không
    const error = searchParams.get('error')
    if (error === 'access_denied') {
      throw OAuthErrors.USER_CANCELLED
    }

    // 2. Xác minh state
    const state = searchParams.get('state')
    if (!verifyState(state)) {
      throw OAuthErrors.STATE_MISMATCH
    }

    // 3. Lấy code
    const code = searchParams.get('code')
    if (!code) {
      throw new OAuthError('no_code', 'Ủy quyền không thành công', 'No code in callback')
    }

    // 4. Trao đổi token
    const tokenRes = await fetch(TOKEN_URL)
    if (!tokenRes.ok) {
      throw OAuthErrors.TOKEN_FAILED
    }

    const tokenData = await tokenRes.json()
    if (tokenData.errcode) {
      console.error('WeChat token error:', tokenData)
      throw OAuthErrors.TOKEN_FAILED
    }

    // 5. Lấy thông tin người dùng
    const userRes = await fetch(USER_INFO_URL)
    if (!userRes.ok) {
      throw OAuthErrors.USER_INFO_FAILED
    }

    // 6. Đăng nhập thành công
    const user = await handleOAuthLogin(userInfo)
    await createSession(user)
    return Response.redirect('/dashboard')

  } catch (error) {
    // Ghi lại lỗi chi tiết để gỡ lỗi
    console.error('OAuth callback error:', {
      error,
      url: request.url,
      timestamp: new Date().toISOString(),
    })

    // Trả về trang lỗi thân thiện với người dùng
    const errorCode = error instanceof OAuthError ? error.code : 'unknown'
    const message = error instanceof OAuthError ? error.userMessage : 'Đăng nhập không thành công'

    return Response.redirect(
      `/login?error=${encodeURIComponent(errorCode)}&message=${encodeURIComponent(message)}`
    )
  }
}
```

## Trang hiển thị lỗi

```tsx
// app/login/page.tsx
export default function LoginPage({ searchParams }) {
  const error = searchParams.error
  const message = searchParams.message

  return (
    <div>
      {error && (
        <div className="bg-red-50 border border-red-200 rounded p-4 mb-4">
          <p className="text-red-700">{message || 'Đăng nhập không thành công, vui lòng thử lại'}</p>
          {error === 'user_cancelled' && (
            <p className="text-sm text-red-500 mt-1">
              Nếu bạn muốn sử dụng dịch vụ này, bạn cần ủy quyền cho chúng tôi để lấy thông tin cơ bản
            </p>
          )}
        </div>
      )}

      <div className="space-y-4">
        <button onClick={() => signIn('wechat')}>
          WeChat Login
        </button>
      </div>
    </div>
  )
}
```

## Giám sát và Cảnh báo

```typescript
// lib/error-reporting.ts
interface OAuthErrorLog {
  code: string
  provider: string
  timestamp: string
  ip?: string
  userAgent?: string
  debugMessage?: string
}

export async function reportOAuthError(
  error: OAuthError,
  request: Request,
  provider: string
) {
  const log: OAuthErrorLog = {
    code: error.code,
    provider,
    timestamp: new Date().toISOString(),
    ip: request.headers.get('x-forwarded-for') || undefined,
    userAgent: request.headers.get('user-agent') || undefined,
    debugMessage: error.debugMessage,
  }

  // Gửi đến dịch vụ logging
  console.error('[OAuth Error]', JSON.stringify(log))

  // Nếu tỷ lệ lỗi quá cao, kích hoạt cảnh báo

}
```

## Hướng dẫn tránh cạm bẫy

::: danger Lỗi phổ biến nhất của người mới bắt đầu
1. Hiển thị trực tiếp thông báo lỗi backend cho người dùng——tiết lộ thông tin nhạy cảm
2. Tất cả các lỗi đều hiển thị "Đăng nhập không thành công"——người dùng không biết cách giải quyết
3. Không ghi nhật ký lỗi——không thể khắc phục vấn đề
4. Không xử lý timeout mạng——người dùng chờ đợi rồi thấy trang trắng
:::
