# 6.4.3 CORS: Chiến lược yêu cầu cross-origin an toàn

## Phá vỡ vấn đề bằng một câu

CORS là trình duyệt đang hỏi máy chủ: "Yêu cầu này từ một trang web khác, bạn cho phép không?" Nó không phải là cố tình làm khó bạn, mà là để bảo vệ người dùng.

## Giá trị cốt lõi

Hiểu CORS sẽ giúp bạn:
- Biết tại sao yêu cầu cross-origin bị chặn
- Cấu hình đúng các nguồn gốc cross-origin được phép
- Tránh "tốt ở phát triển nhưng báo lỗi khi lên production"

## Bắt đầu nhanh

### Cấu hình tối thiểu

```typescript
// app/api/data/route.ts
export async function GET() {
  return Response.json({ data: 'hello' }, {
    headers: {
      'Access-Control-Allow-Origin': 'https://your-frontend.com',
    }
  })
}

export async function OPTIONS() {
  return new Response(null, {
    headers: {
      'Access-Control-Allow-Origin': 'https://your-frontend.com',
      'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
      'Access-Control-Allow-Headers': 'Content-Type',
    }
  })
}
```

### Danh sách trắng tên miền

```typescript
const allowedOrigins = [
  'https://app.example.com',
  'https://admin.example.com',
]

export async function GET(request: Request) {
  const origin = request.headers.get('origin')
  const headers: Record<string, string> = {}

  if (origin && allowedOrigins.includes(origin)) {
    headers['Access-Control-Allow-Origin'] = origin
  }

  return Response.json({ data: 'hello' }, { headers })
}
```

### Cho phép mang theo thông tin xác thực

```typescript
// Khi cần gửi Cookie
headers: {
  'Access-Control-Allow-Origin': 'https://your-frontend.com', // không thể dùng *
  'Access-Control-Allow-Credentials': 'true',
}

// Yêu cầu từ phía client
fetch(url, { credentials: 'include' })
```

## Hướng dẫn tránh lỗi

::: danger Lỗi phổ biến nhất mà người mới làm
1. Sử dụng `Access-Control-Allow-Origin: *` trong production
2. Sử dụng `*` trong khi cũng đặt `Allow-Credentials: true`
3. Quên xử lý yêu cầu preflight OPTIONS
:::
