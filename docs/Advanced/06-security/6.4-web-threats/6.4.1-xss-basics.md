# 6.4.1 XSS: Xác thực đầu vào và mã hóa đầu ra

## Phá vỡ vấn đề bằng một câu

XSS attack là làm cho trang web của bạn giúp kẻ tấn công thực thi code JavaScript. Chìa khóa phòng chống là: **những gì vào phải xác thực, những gì ra phải mã hóa**.

## Giá trị cốt lõi

Hiểu XSS sẽ giúp bạn:
- Tránh dữ liệu người dùng bị đánh cắp
- Bảo vệ an toàn tài khoản người dùng
- Vượt qua kiểm toán bảo mật

## Bắt đầu nhanh

### Bảo vệ mặc định của React

React sẽ tự động thoát nội dung trong JSX, đây là lớp bảo vệ đầu tiên:

```tsx
function Comment({ content }) {
  // ✅ An toàn: React tự động thoát
  return <div>{content}</div>
}
```

### Các tình huống cần cảnh báo

```tsx
// ❌ Nguy hiểm: Vượt qua bảo vệ React
<div dangerouslySetInnerHTML={{ __html: userContent }} />

// ❌ Nguy hiểm: Tạo script động
const script = document.createElement('script')
script.src = userInput
document.body.appendChild(script)

// ❌ Nguy hiểm: Thực thi eval
eval(userInput)
```

### Sử dụng DOMPurify để làm sạch HTML

Khi thực sự cần render HTML của người dùng:

```typescript
import DOMPurify from 'isomorphic-dompurify'

function SafeHtml({ html }) {
  const clean = DOMPurify.sanitize(html, {
    ALLOWED_TAGS: ['p', 'b', 'i', 'em', 'strong', 'a'],
    ALLOWED_ATTR: ['href'],
  })

  return <div dangerouslySetInnerHTML={{ __html: clean }} />
}
```

### Cấu hình header phản hồi CSP

Content Security Policy giới hạn những script nào có thể được thực thi:

```typescript
// next.config.js
module.exports = {
  async headers() {
    return [{
      source: '/:path*',
      headers: [{
        key: 'Content-Security-Policy',
        value: "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'"
      }]
    }]
  }
}
```

## Hướng dẫn tránh lỗi

::: danger Lỗi phổ biến nhất mà người mới làm
1. Nghĩ rằng "Tôi chỉ hiển thị đầu vào của người dùng, sẽ không có vấn đề"——hiển thị bản thân đã là lối vào để thực thi
2. Sử dụng `innerHTML` hoặc `dangerouslySetInnerHTML` nhưng không làm sạch nội dung
3. Chèn dữ liệu chưa được xác thực vào tham số URL
:::
