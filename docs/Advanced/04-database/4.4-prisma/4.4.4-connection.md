# 4.4.4 Kết nối Database: Connection string và cấu hình môi trường

### Tóm tắt trong một câu

Cấu hình đúng kết nối database là bước đầu tiên khi dùng Prisma — connection string quyết định ứng dụng của bạn giao tiếp với database như thế nào.

### Định dạng connection string

```
postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=SCHEMA
```

| Thành phần | Mô tả | Ví dụ |
|------|------|------|
| `USER` | Tên user database | `postgres` |
| `PASSWORD` | Mật khẩu user | `mypassword` |
| `HOST` | Địa chỉ database server | `localhost` |
| `PORT` | Cổng | `5432` |
| `DATABASE` | Tên database | `myapp` |
| `schema` | PostgreSQL schema | `public` |

### Cấu hình cho các môi trường khác nhau

**Local development (SQLite)**:

```env
# .env
DATABASE_URL="file:./dev.db"
```

```prisma
datasource db {
  provider = "sqlite"
  url      = env("DATABASE_URL")
}
```

**Local development (PostgreSQL + Docker)**:

```yaml
# docker-compose.yml
services:
  db:
    image: postgres:15
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: myapp
    ports:
      - "5432:5432"
```

```env
# .env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/myapp?schema=public"
```

**Supabase**:

```env
# .env
DATABASE_URL="postgresql://postgres:[YOUR-PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres"
```

**Neon (Serverless PostgreSQL)**:

```env
# .env
DATABASE_URL="postgresql://[user]:[password]@[endpoint].neon.tech/[database]?sslmode=require"
```

### Quản lý biến môi trường

**Cấu hình đa môi trường**:

```
.env                 # Cấu hình mặc định (development)
.env.local           # Override local (không commit vào Git)
.env.development     # Môi trường development
.env.test            # Môi trường test
.env.production      # Môi trường production
```

**Cấu hình .gitignore**:

```gitignore
# Không commit file chứa mật khẩu
.env
.env.local
.env.*.local

# File mẫu có thể commit
!.env.example
```

**File .env.example mẫu**:

```env
# Copy file này thành .env và điền giá trị thực
DATABASE_URL="postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=public"
```

### Khởi tạo Prisma Client

**Cách dùng cơ bản**:

```typescript
import { PrismaClient } from '@prisma/client'

const prisma = new PrismaClient()

export default prisma
```

**Singleton pattern cho development environment** (tránh tạo nhiều connection khi hot reload):

```typescript
// lib/prisma.ts
import { PrismaClient } from '@prisma/client'

const globalForPrisma = globalThis as unknown as {
  prisma: PrismaClient | undefined
}

export const prisma = globalForPrisma.prisma ?? new PrismaClient()

if (process.env.NODE_ENV !== 'production') {
  globalForPrisma.prisma = prisma
}
```

**Với cấu hình logging**:

```typescript
const prisma = new PrismaClient({
  log: [
    { level: 'query', emit: 'event' },   // Query log
    { level: 'error', emit: 'stdout' },  // Error log
    { level: 'warn', emit: 'stdout' },   // Warning log
  ],
})

// Lắng nghe query event
prisma.$on('query', (e) => {
  console.log('Query: ' + e.query)
  console.log('Duration: ' + e.duration + 'ms')
})
```

### Cấu hình connection pool

**Cách dùng URL parameter**:

```env
DATABASE_URL="postgresql://user:pass@host:5432/db?connection_limit=5&pool_timeout=10"
```

| Tham số | Mô tả | Giá trị mặc định |
|------|------|--------|
| `connection_limit` | Số connection tối đa | `num_cpus * 2 + 1` |
| `pool_timeout` | Timeout lấy connection (giây) | `10` |
| `connect_timeout` | Timeout thiết lập connection (giây) | `5` |

**Cấu hình cho môi trường Serverless**:

```env
# Vercel / Netlify và các môi trường Serverless
DATABASE_URL="postgresql://...?connection_limit=1"
```

Môi trường Serverless khuyến nghị dùng connection pooler service (như Supabase Pooler, PgBouncer).

### Cấu hình nhiều data source

```prisma
// Database chính
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// Nếu cần kết nối nhiều database, dùng nhiều Prisma Client
// prisma/schema-analytics.prisma
datasource analytics {
  provider = "postgresql"
  url      = env("ANALYTICS_DATABASE_URL")
}
```

### Kiểm tra kết nối

```typescript
async function testConnection() {
  try {
    await prisma.$connect()
    console.log('Database connected successfully')
  } catch (error) {
    console.error('Failed to connect to database:', error)
    process.exit(1)
  }
}

testConnection()
```

### Hướng dẫn tránh lỗi

1. **Ký tự đặc biệt trong mật khẩu cần URL encode**:
   ```
   # Mật khẩu gốc: p@ss#word
   # Sau encode: p%40ss%23word
   DATABASE_URL="postgresql://user:p%40ss%23word@host:5432/db"
   ```

2. **SSL connection** (thường cần cho cloud database):
   ```env
   DATABASE_URL="postgresql://...?sslmode=require"
   ```

3. **Quá nhiều connection trong development**: Dùng singleton pattern để tránh hot reload tạo nhiều connection

4. **Quên set biến môi trường ở production**: Kiểm tra tất cả biến môi trường cần thiết trước khi deploy

### Tóm tắt phần này

- Connection string bao gồm username, password, host, port và database name
- Dùng file `.env` để quản lý biến môi trường, không commit thông tin nhạy cảm
- Môi trường development dùng singleton pattern để tránh quá nhiều connection
- Môi trường Serverless cần cấu hình connection pool nhỏ hơn
