# 4.4.8 Query hiệu quả hơn như thế nào — Kỹ thuật query nâng cao: Query liên kết và tối ưu hiệu năng

### Tóm tắt trong một câu

Cốt lõi của tối ưu query Prisma là giảm số lượng query và lượng dữ liệu trả về — học những kỹ thuật này có thể giúp ứng dụng của bạn nhanh hơn 10 lần.

### Tránh vấn đề N+1

**Code có vấn đề**:

```typescript
// Vấn đề N+1: 100 user sẽ tạo ra 101 query
const users = await prisma.user.findMany()
for (const user of users) {
  const posts = await prisma.post.findMany({
    where: { authorId: user.id }
  })
}
```

**Giải pháp: Dùng include**

```typescript
// Chỉ có 1 query
const users = await prisma.user.findMany({
  include: { posts: true }
})
```

### select vs include

| Phương thức | Công dụng | Tình huống |
|------|------|------|
| `include` | Load dữ liệu liên kết | Cần object liên kết đầy đủ |
| `select` | Chọn field cụ thể | Chỉ cần một phần field |

```typescript
// include: Trả về tất cả field + dữ liệu liên kết
const user = await prisma.user.findUnique({
  where: { id },
  include: { posts: true }
})

// select: Chỉ trả về field cần thiết
const user = await prisma.user.findUnique({
  where: { id },
  select: {
    id: true,
    name: true,
    posts: {
      select: { id: true, title: true }
    }
  }
})
```

### Kỹ thuật query điều kiện

**Điều kiện phức tạp**:

```typescript
const posts = await prisma.post.findMany({
  where: {
    AND: [
      { status: 'PUBLISHED' },
      { authorId: userId }
    ],
    OR: [
      { title: { contains: keyword } },
      { content: { contains: keyword } }
    ],
    NOT: { deletedAt: { not: null } }
  }
})
```

**Xây dựng điều kiện động**:

```typescript
function buildFilter(params: {
  status?: string
  authorId?: string
  keyword?: string
}) {
  const where: Prisma.PostWhereInput = {}

  if (params.status) {
    where.status = params.status
  }
  if (params.authorId) {
    where.authorId = params.authorId
  }
  if (params.keyword) {
    where.OR = [
      { title: { contains: params.keyword } },
      { content: { contains: params.keyword } }
    ]
  }

  return where
}

const posts = await prisma.post.findMany({
  where: buildFilter({ status: 'PUBLISHED', keyword: 'prisma' })
})
```

### Best practices cho phân trang

**Phân trang Offset** (đơn giản nhưng chậm với dữ liệu lớn):

```typescript
const posts = await prisma.post.findMany({
  skip: (page - 1) * pageSize,
  take: pageSize,
  orderBy: { createdAt: 'desc' }
})

const total = await prisma.post.count()
```

**Phân trang Cursor** (hiệu năng tốt hơn):

```typescript
const posts = await prisma.post.findMany({
  take: pageSize,
  skip: cursor ? 1 : 0,  // Bỏ qua chính cursor
  cursor: cursor ? { id: cursor } : undefined,
  orderBy: { id: 'asc' }
})

const nextCursor = posts.length === pageSize
  ? posts[posts.length - 1].id
  : null
```

### Tối ưu thao tác hàng loạt

**Tạo hàng loạt**:

```typescript
// Dùng createMany thay vì lặp create
await prisma.user.createMany({
  data: users,
  skipDuplicates: true
})
```

**Cập nhật hàng loạt**:

```typescript
await prisma.post.updateMany({
  where: { status: 'DRAFT', createdAt: { lt: oneMonthAgo } },
  data: { status: 'ARCHIVED' }
})
```

**Xóa hàng loạt**:

```typescript
await prisma.post.deleteMany({
  where: { authorId: userId }
})
```

### Bật query log

```typescript
const prisma = new PrismaClient({
  log: [
    { level: 'query', emit: 'event' }
  ]
})

prisma.$on('query', (e) => {
  console.log(`Query: ${e.query}`)
  console.log(`Duration: ${e.duration}ms`)
})
```

### Checklist tối ưu hiệu năng

| Vấn đề | Giải pháp |
|------|----------|
| Query N+1 | Dùng `include` hoặc `select` |
| Trả về quá nhiều dữ liệu | Dùng `select` chỉ chọn field cần thiết |
| Hiệu năng phân trang kém | Dùng phân trang Cursor thay Offset |
| Query quá chậm | Kiểm tra xem có thiếu index không |
| Thao tác hàng loạt chậm | Dùng `createMany`/`updateMany` |

### Dùng SQL thuần

Khi Prisma API không đáp ứng được nhu cầu:

```typescript
// Raw query
const result = await prisma.$queryRaw`
  SELECT u.*, COUNT(p.id) as post_count
  FROM users u
  LEFT JOIN posts p ON p.author_id = u.id
  GROUP BY u.id
  ORDER BY post_count DESC
  LIMIT 10
`

// Raw execute (không có giá trị trả về)
await prisma.$executeRaw`
  UPDATE posts SET view_count = view_count + 1 WHERE id = ${postId}
`
```

### Tóm tắt phần này

- Dùng `include` để tránh vấn đề N+1
- Dùng `select` để giảm lượng dữ liệu trả về
- Phân trang dữ liệu lớn dùng Cursor thay vì Offset
- Thao tác hàng loạt dùng `createMany`/`updateMany`
- Bật log để xác định slow query
