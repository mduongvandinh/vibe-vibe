# 4.4.1 Cài đặt và cấu hình Prisma: CLI tools và quản lý dependencies

### Tóm tắt trong một câu

Cài đặt Prisma chỉ cần hai bước: cài đặt dependencies + khởi tạo cấu hình.

### Các bước cài đặt

**1. Cài đặt dependencies**

```bash
# Cài đặt Prisma CLI (dev dependency) và Prisma Client (runtime dependency)
npm install prisma --save-dev
npm install @prisma/client
```

| Tên package | Vai trò | Môi trường |
|------|------|------|
| `prisma` | CLI tools (migration, generate, etc.) | Development |
| `@prisma/client` | Database query client | Runtime |

**2. Khởi tạo project**

```bash
npx prisma init
```

Lệnh này sẽ tạo:
```
project/
├── prisma/
│   └── schema.prisma   # Định nghĩa data model
└── .env                # Cấu hình kết nối database
```

### Nội dung ban đầu của schema.prisma

```prisma
// Cấu hình generator: sinh Prisma Client
generator client {
  provider = "prisma-client-js"
}

// Cấu hình datasource: kết nối database
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

### Cấu hình .env

```env
# Connection string PostgreSQL
DATABASE_URL="postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=public"

# Ví dụ: Local development
DATABASE_URL="postgresql://postgres:password@localhost:5432/mydb?schema=public"

# Ví dụ: Supabase
DATABASE_URL="postgresql://postgres:[PASSWORD]@db.[PROJECT].supabase.co:5432/postgres"
```

### Các lệnh CLI thường dùng

| Lệnh | Công dụng |
|------|------|
| `npx prisma init` | Khởi tạo Prisma project |
| `npx prisma generate` | Sinh Prisma Client |
| `npx prisma migrate dev` | Tạo và áp dụng migration |
| `npx prisma db push` | Đẩy Schema lên database (không migration) |
| `npx prisma studio` | Khởi động giao diện quản lý data trực quan |
| `npx prisma db seed` | Chạy script seed data |

### Development environment vs Production environment

| Tình huống | Database khuyến nghị | Cấu hình |
|------|-----------|------|
| **Local development** | SQLite | Đơn giản, không cần cài đặt |
| **Team development** | PostgreSQL (Docker) | Giữ môi trường nhất quán |
| **Production environment** | PostgreSQL (Cloud service) | Supabase/Neon |

**Cấu hình SQLite cho development**:
```prisma
datasource db {
  provider = "sqlite"
  url      = "file:./dev.db"
}
```

### Cấu hình scripts trong package.json

```json
{
  "scripts": {
    "db:generate": "prisma generate",
    "db:migrate": "prisma migrate dev",
    "db:push": "prisma db push",
    "db:studio": "prisma studio",
    "db:seed": "prisma db seed",
    "postinstall": "prisma generate"
  },
  "prisma": {
    "seed": "tsx prisma/seed.ts"
  }
}
```

`postinstall` đảm bảo Prisma Client được sinh tự động sau mỗi lần chạy `npm install`.

### Xác minh cài đặt

```bash
# Kiểm tra phiên bản Prisma CLI
npx prisma --version

# Khởi động Studio để xác minh kết nối
npx prisma studio
```

### Tóm tắt phần này

- Cài đặt `prisma` (CLI) và `@prisma/client` (runtime)
- Chạy `npx prisma init` để khởi tạo project
- Cấu hình `DATABASE_URL` trong `.env`
- Development dùng SQLite, production dùng PostgreSQL
