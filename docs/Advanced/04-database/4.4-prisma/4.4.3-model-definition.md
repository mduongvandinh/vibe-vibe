# 4.4.3 Định nghĩa Model: Kiểu field và mapping quan hệ

### Tóm tắt trong một câu

Định nghĩa model là cốt lõi của Prisma — nó quyết định cấu trúc dữ liệu, quan hệ và constraints của bạn được map như thế nào vào database.

### Ví dụ model đầy đủ

```prisma
model User {
  // Field nhận dạng
  id        String   @id @default(cuid())

  // Field nghiệp vụ
  email     String   @unique
  name      String?
  role      Role     @default(USER)

  // Field audit
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  deletedAt DateTime?

  // Field quan hệ
  posts     Post[]
  profile   Profile?

  // Constraint cấp table
  @@index([email])
  @@map("users")  // Map tới tên bảng database
}
```

### Chi tiết về kiểu field

**Kiểu scalar**:

| Kiểu Prisma | TypeScript | PostgreSQL | Mô tả |
|-------------|------------|------------|------|
| `String` | `string` | `TEXT` | Chuỗi ký tự |
| `Int` | `number` | `INTEGER` | Số nguyên |
| `BigInt` | `bigint` | `BIGINT` | Số nguyên lớn |
| `Float` | `number` | `DOUBLE PRECISION` | Số thực |
| `Decimal` | `Decimal` | `DECIMAL` | Số thập phân chính xác (tiền tệ) |
| `Boolean` | `boolean` | `BOOLEAN` | Boolean |
| `DateTime` | `Date` | `TIMESTAMP` | Ngày giờ |
| `Json` | `JsonValue` | `JSONB` | Dữ liệu JSON |
| `Bytes` | `Buffer` | `BYTEA` | Dữ liệu binary |

**Kiểu đặc biệt**:

```prisma
// Kiểu enum
enum Role {
  USER
  ADMIN
  MODERATOR
}

model User {
  role Role @default(USER)
}

// Mảng string (PostgreSQL hỗ trợ)
model Post {
  tags String[]
}
```

### Field modifier

**Tùy chọn và bắt buộc**:

```prisma
model User {
  name     String   // Bắt buộc
  nickname String?  // Tùy chọn (có thể null)
}
```

**Giá trị mặc định**:

```prisma
model Post {
  id        String   @id @default(cuid())   // CUID
  uuid      String   @id @default(uuid())   // UUID
  createdAt DateTime @default(now())        // Thời gian hiện tại
  status    String   @default("DRAFT")      // Giá trị cố định
  views     Int      @default(0)            // Số
  isPublic  Boolean  @default(false)        // Boolean
}
```

**Database mapping**:

```prisma
model User {
  firstName String @map("first_name")  // Map field

  @@map("users")  // Map tên bảng
}
```

### Định nghĩa quan hệ

**Quan hệ một-một**:

```prisma
model User {
  id      String   @id @default(cuid())
  profile Profile?
}

model Profile {
  id     String @id @default(cuid())
  bio    String?
  userId String @unique  // Phải unique
  user   User   @relation(fields: [userId], references: [id])
}
```

**Quan hệ một-nhiều**:

```prisma
model User {
  id    String @id @default(cuid())
  posts Post[]  // Một user có nhiều bài viết
}

model Post {
  id       String @id @default(cuid())
  authorId String
  author   User   @relation(fields: [authorId], references: [id])
}
```

**Quan hệ nhiều-nhiều (implicit)**:

```prisma
model Post {
  id   String @id @default(cuid())
  tags Tag[]
}

model Tag {
  id    String @id @default(cuid())
  name  String @unique
  posts Post[]
}
// Prisma tự động tạo bảng trung gian _PostToTag
```

**Quan hệ nhiều-nhiều (explicit)**:

```prisma
model Post {
  id       String    @id @default(cuid())
  postTags PostTag[]
}

model Tag {
  id       String    @id @default(cuid())
  postTags PostTag[]
}

model PostTag {
  postId    String
  tagId     String
  createdAt DateTime @default(now())

  post Post @relation(fields: [postId], references: [id], onDelete: Cascade)
  tag  Tag  @relation(fields: [tagId], references: [id], onDelete: Cascade)

  @@id([postId, tagId])
}
```

### Hành vi cascade

```prisma
model Post {
  authorId String
  author   User @relation(fields: [authorId], references: [id], onDelete: Cascade)
}
```

| Hành vi | Khi xóa record cha | Khi cập nhật record cha |
|------|-------------|-------------|
| `Cascade` | Record con cũng bị xóa | Record con cũng được cập nhật |
| `SetNull` | Foreign key đặt thành null | Foreign key đặt thành null |
| `Restrict` | Ngăn xóa | Ngăn cập nhật |
| `NoAction` | Giống Restrict | Giống Restrict |

### Quan hệ tự tham chiếu

```prisma
// Quan hệ follow user
model User {
  id        String @id @default(cuid())
  followers User[] @relation("UserFollows")
  following User[] @relation("UserFollows")
}

// Comment trả lời
model Comment {
  id       String    @id @default(cuid())
  parentId String?
  parent   Comment?  @relation("CommentReplies", fields: [parentId], references: [id])
  replies  Comment[] @relation("CommentReplies")
}
```

### Constraint cấp table

```prisma
model TeamMember {
  id     String @id @default(cuid())
  userId String
  teamId String
  role   String

  // Composite unique constraint
  @@unique([userId, teamId])

  // Composite index
  @@index([teamId, role])

  // Composite primary key (thay thế @id)
  // @@id([userId, teamId])
}
```

### Checklist kiểm tra

Khi định nghĩa model, kiểm tra các điểm sau:

- [ ] Mỗi model đều có `@id` primary key
- [ ] Field bắt buộc không có `?`
- [ ] Kiểu foreign key field trùng với field được tham chiếu
- [ ] Foreign key của quan hệ một-một có `@unique`
- [ ] Field cần tìm kiếm/sắp xếp có index
- [ ] Đã thêm các field audit (createdAt, updatedAt)

### Tóm tắt phần này

- Định nghĩa model bao gồm field, kiểu, modifier và quan hệ
- Dùng `?` để đánh dấu field tùy chọn, `@default()` để đặt giá trị mặc định
- Quan hệ một-một cần `@unique` foreign key, nhiều-nhiều có thể dùng implicit hoặc explicit
- Dùng `@@index` và `@@unique` để định nghĩa constraint cấp table
