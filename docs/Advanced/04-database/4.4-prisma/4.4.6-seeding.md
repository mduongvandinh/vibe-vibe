# 4.4.6 Seed data: prisma/seed.ts và npm run db:seed

### Tóm tắt trong một câu

Seed data là "nội dung ban đầu" của database — giúp môi trường development và test có dữ liệu mẫu sử dụng được.

### Cấu hình seed script

**1. Cài đặt dependency**:

```bash
npm install -D tsx
```

**2. Cấu hình package.json**:

```json
{
  "prisma": {
    "seed": "tsx prisma/seed.ts"
  }
}
```

**3. Tạo file seed**:

```typescript
// prisma/seed.ts
import { PrismaClient } from '@prisma/client'

const prisma = new PrismaClient()

async function main() {
  // Tạo user
  const user = await prisma.user.upsert({
    where: { email: 'admin@example.com' },
    update: {},
    create: {
      email: 'admin@example.com',
      name: 'Quản trị viên',
      role: 'ADMIN',
    },
  })

  // Tạo bài viết
  await prisma.post.createMany({
    data: [
      { title: 'Bài viết đầu tiên', content: 'Nội dung...', authorId: user.id },
      { title: 'Bài viết thứ hai', content: 'Nội dung...', authorId: user.id },
    ],
    skipDuplicates: true,
  })

  console.log('Seed completed!')
}

main()
  .catch((e) => {
    console.error(e)
    process.exit(1)
  })
  .finally(async () => {
    await prisma.$disconnect()
  })
```

### Chạy seed script

```bash
# Chạy thủ công
npx prisma db seed

# Tự động chạy khi migration (migrate reset sẽ trigger)
npx prisma migrate reset
```

### Thiết kế seed idempotent

**Dùng upsert để tránh trùng lặp**:

```typescript
// Idempotent: Chạy nhiều lần không báo lỗi
const user = await prisma.user.upsert({
  where: { email: 'admin@example.com' },
  update: { name: 'Quản trị viên' },  // Nếu tồn tại thì update
  create: {                      // Nếu không tồn tại thì create
    email: 'admin@example.com',
    name: 'Quản trị viên',
  },
})
```

**Dùng skipDuplicates**:

```typescript
await prisma.post.createMany({
  data: posts,
  skipDuplicates: true,  // Bỏ qua nếu trùng lặp
})
```

### Dùng Faker để sinh dữ liệu giả

```bash
npm install -D @faker-js/faker
```

```typescript
import { faker } from '@faker-js/faker'
import { PrismaClient } from '@prisma/client'

const prisma = new PrismaClient()

async function main() {
  // Sinh 10 user
  const users = Array.from({ length: 10 }, () => ({
    email: faker.internet.email(),
    name: faker.person.fullName(),
    avatar: faker.image.avatar(),
  }))

  for (const userData of users) {
    const user = await prisma.user.create({ data: userData })

    // Mỗi user tạo 3-5 bài viết
    const postCount = faker.number.int({ min: 3, max: 5 })
    await prisma.post.createMany({
      data: Array.from({ length: postCount }, () => ({
        title: faker.lorem.sentence(),
        content: faker.lorem.paragraphs(3),
        authorId: user.id,
      })),
    })
  }
}

main()
```

### Seed data theo môi trường

```typescript
// prisma/seed.ts
const isProduction = process.env.NODE_ENV === 'production'

async function main() {
  // Dữ liệu cơ bản cần cho tất cả môi trường
  await seedBaseData()

  // Chỉ môi trường development/test
  if (!isProduction) {
    await seedTestData()
  }
}

async function seedBaseData() {
  // Dữ liệu cơ bản như role, permission
  await prisma.role.upsert({
    where: { name: 'ADMIN' },
    update: {},
    create: { name: 'ADMIN', permissions: ['*'] },
  })
}

async function seedTestData() {
  // User test, dữ liệu mẫu
  // ...
}
```

### Best practices cho seed script

| Thực hành | Mô tả |
|------|------|
| **Thiết kế idempotent** | Chạy nhiều lần không báo lỗi, không trùng dữ liệu |
| **Dùng transaction** | Dùng transaction cho dữ liệu quan trọng đảm bảo tính nhất quán |
| **Chia theo môi trường** | Phân biệt dữ liệu production và test |
| **Output log** | Xuất log tiến trình để dễ debug |

```typescript
async function main() {
  console.log('Starting seed...')

  await prisma.$transaction(async (tx) => {
    console.log('Creating users...')
    await seedUsers(tx)

    console.log('Creating posts...')
    await seedPosts(tx)
  })

  console.log('Seed completed!')
}
```

### Dọn dẹp dữ liệu

```typescript
async function cleanDatabase() {
  // Xóa theo thứ tự phụ thuộc foreign key
  await prisma.comment.deleteMany()
  await prisma.post.deleteMany()
  await prisma.user.deleteMany()
}

async function main() {
  await cleanDatabase()
  await seedData()
}
```

### Tóm tắt phần này

- Cấu hình script `prisma.seed` trong package.json
- Dùng `upsert` hoặc `skipDuplicates` để implement idempotent
- Dùng Faker để sinh dữ liệu giả thực tế
- Phân biệt seed data cho môi trường production và test
