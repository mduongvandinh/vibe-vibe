# 4.4.2 Cấu trúc file Schema: generator/datasource/model

### Tóm tắt trong một câu

schema.prisma là file cấu hình cốt lõi của Prisma — nó định nghĩa kết nối database, code generator và data model.

### Ba thành phần chính của Schema file

```prisma
// 1. Cấu hình Generator
generator client {
  provider = "prisma-client-js"
}

// 2. Cấu hình Datasource
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// 3. Data Model
model User {
  id    String @id @default(cuid())
  email String @unique
  name  String?
  posts Post[]
}
```

### Generator: Cấu hình generator

```prisma
generator client {
  provider        = "prisma-client-js"  // Sinh JS/TS client
  previewFeatures = ["fullTextSearch"]   // Bật preview features
}
```

| Tùy chọn | Mô tả |
|------|------|
| `provider` | Loại generator, thường là `prisma-client-js` |
| `previewFeatures` | Bật các tính năng thử nghiệm |
| `output` | Đường dẫn output (thường không cần sửa) |

### Datasource: Cấu hình data source

```prisma
datasource db {
  provider = "postgresql"        // Loại database
  url      = env("DATABASE_URL") // Đọc connection string từ biến môi trường
}
```

**Các database được hỗ trợ**:

| provider | Database |
|----------|--------|
| `postgresql` | PostgreSQL |
| `mysql` | MySQL |
| `sqlite` | SQLite |
| `sqlserver` | SQL Server |
| `mongodb` | MongoDB |

### Model: Data model

```prisma
model User {
  // Định nghĩa field
  id        String   @id @default(cuid())
  email     String   @unique
  name      String?
  role      Role     @default(USER)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  // Định nghĩa relation
  posts     Post[]
  profile   Profile?
}

// Enum
enum Role {
  USER
  ADMIN
}
```

### Các field modifier thường dùng

| Modifier | Công dụng | Ví dụ |
|--------|------|------|
| `@id` | Primary key | `id String @id` |
| `@unique` | Unique constraint | `email String @unique` |
| `@default()` | Giá trị mặc định | `@default(now())` |
| `@updatedAt` | Tự động cập nhật thời gian | `updatedAt DateTime @updatedAt` |
| `@relation` | Định nghĩa relation | `@relation(fields: [userId], references: [id])` |
| `@map` | Map tên field database | `@map("user_id")` |
| `@@index` | Tạo index | `@@index([email])` |
| `@@unique` | Composite unique constraint | `@@unique([userId, teamId])` |

### Bảng tra cứu nhanh kiểu field

| Kiểu Prisma | Kiểu TypeScript | Mô tả |
|-------------|-----------------|------|
| `String` | `string` | Chuỗi ký tự |
| `Int` | `number` | Số nguyên |
| `Float` | `number` | Số thực |
| `Boolean` | `boolean` | Boolean |
| `DateTime` | `Date` | Ngày giờ |
| `Json` | `JsonValue` | Dữ liệu JSON |
| `Decimal` | `Decimal` | Số thập phân chính xác |

**Field tùy chọn**: Thêm `?` sau kiểu
```prisma
name String?  // Có thể là null
```

**Field array**: Thêm `[]` sau kiểu
```prisma
tags String[]  // Mảng string
```

### Tóm tắt phần này

- schema.prisma gồm ba phần: generator, datasource, model
- generator cấu hình code generation, datasource cấu hình kết nối database
- model định nghĩa cấu trúc dữ liệu và quan hệ
- Sử dụng các modifier (@id, @unique, etc.) để định nghĩa constraints
