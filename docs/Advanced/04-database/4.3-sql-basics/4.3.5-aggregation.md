# 4.3.5 Làm sao thống kê dữ liệu——Aggregate functions: COUNT/SUM/AVG/MAX/MIN

### Tóm tắt một câu

Hàm aggregate "nén" nhiều row dữ liệu thành một giá trị——thống kê số lượng, tính tổng, trung bình đều dựa vào nó.

### Năm hàm aggregate chính

| Hàm | Vai trò | Ví dụ |
|------|------|------|
| **COUNT** | Đếm số lượng | Tổng số bài viết |
| **SUM** | Tính tổng | Tổng tiền đơn hàng |
| **AVG** | Trung bình | Điểm đánh giá trung bình |
| **MAX** | Giá trị lớn nhất | Giá cao nhất |
| **MIN** | Giá trị nhỏ nhất | Giá thấp nhất |

### Cách dùng cơ bản

**COUNT: Đếm số lượng**
```sql
-- Thống kê tổng số user
SELECT COUNT(*) FROM users;

-- Thống kê số user có email (không tính NULL)
SELECT COUNT(email) FROM users;

-- Thống kê số city không trùng lặp
SELECT COUNT(DISTINCT city) FROM users;
```

**SUM: Tính tổng**
```sql
-- Tổng tiền đơn hàng
SELECT SUM(amount) FROM orders;

-- Tổng tiền đơn hàng của một user
SELECT SUM(amount) FROM orders WHERE user_id = 'xxx';
```

**AVG: Trung bình**
```sql
-- Số tiền đơn hàng trung bình
SELECT AVG(amount) FROM orders;

-- Điểm đánh giá trung bình
SELECT AVG(rating) FROM reviews WHERE product_id = 'xxx';
```

**MAX / MIN: Giá trị lớn nhất/nhỏ nhất**
```sql
-- Giá cao nhất và thấp nhất
SELECT MAX(price), MIN(price) FROM products;

-- Thời gian đơn hàng mới nhất
SELECT MAX(created_at) FROM orders;
```

### GROUP BY: Group aggregation

**Thống kê theo nhóm**:

```sql
-- Số đơn hàng của mỗi user
SELECT user_id, COUNT(*) as order_count
FROM orders
GROUP BY user_id;

-- Số sản phẩm và giá trung bình mỗi category
SELECT category_id, COUNT(*) as count, AVG(price) as avg_price
FROM products
GROUP BY category_id;
```

### HAVING: Lọc kết quả nhóm

```sql
-- User có số đơn hàng > 10
SELECT user_id, COUNT(*) as order_count
FROM orders
GROUP BY user_id
HAVING COUNT(*) > 10;
```

**WHERE vs HAVING**:
- WHERE: Lọc row gốc (trước khi group)
- HAVING: Lọc kết quả aggregate (sau khi group)

```sql
-- WHERE lọc đơn hàng đơn giá > 100
-- HAVING lọc user có tổng tiền > 1000
SELECT user_id, SUM(amount) as total
FROM orders
WHERE amount > 100
GROUP BY user_id
HAVING SUM(amount) > 1000;
```

### Aggregation trong Prisma

**Basic aggregation**:
```typescript
// Thống kê tổng số user
const count = await prisma.user.count()

// Thống kê có điều kiện
const activeCount = await prisma.user.count({
  where: { status: 'ACTIVE' }
})
```

**Aggregate functions**:
```typescript
const result = await prisma.order.aggregate({
  _count: true,
  _sum: { amount: true },
  _avg: { amount: true },
  _max: { amount: true },
  _min: { amount: true }
})
// { _count: 100, _sum: { amount: 50000 }, _avg: { amount: 500 }, ... }
```

**Group aggregation**:
```typescript
// Thống kê đơn hàng theo user
const result = await prisma.order.groupBy({
  by: ['userId'],
  _count: true,
  _sum: { amount: true }
})
// [{ userId: 'u1', _count: 5, _sum: { amount: 1000 } }, ...]
```

**Group filter (having)**:
```typescript
const result = await prisma.order.groupBy({
  by: ['userId'],
  _count: true,
  having: {
    amount: {
      _sum: { gt: 1000 }  // Tổng tiền > 1000
    }
  }
})
```

### Các tình huống thống kê thường gặp

**Tình huống 1: Dashboard thống kê user**
```typescript
const stats = await prisma.$transaction([
  prisma.user.count(),
  prisma.user.count({ where: { status: 'ACTIVE' } }),
  prisma.order.aggregate({ _sum: { amount: true } })
])
```

**Tình huống 2: Bảng xếp hạng**
```typescript
const topSellers = await prisma.order.groupBy({
  by: ['productId'],
  _count: true,
  orderBy: { _count: { productId: 'desc' } },
  take: 10
})
```

### Tóm tắt chương này

- Hàm aggregate tổng hợp nhiều row dữ liệu thành một giá trị
- COUNT/SUM/AVG/MAX/MIN là năm hàm aggregate chính
- GROUP BY group theo field để thống kê
- HAVING lọc kết quả group
- Prisma cung cấp method `count()`, `aggregate()`, `groupBy()`
