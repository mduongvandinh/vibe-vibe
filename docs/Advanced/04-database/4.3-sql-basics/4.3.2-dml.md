# 4.3.2 Làm sao thao tác dữ liệu trong bảng——DML data operations: INSERT/UPDATE/DELETE/SELECT

### Tóm tắt một câu

DML là ngôn ngữ để thao tác dữ liệu——chính là CRUD mà chúng ta quen thuộc, chỉ là viết bằng SQL.

### INSERT: Chèn dữ liệu

**Chèn một record**:
```sql
INSERT INTO users (id, email, name)
VALUES ('uuid-1', 'user@example.com', 'Nguyễn Văn A');
```

**Chèn nhiều record**:
```sql
INSERT INTO users (id, email, name) VALUES
  ('uuid-1', 'user1@example.com', 'User 1'),
  ('uuid-2', 'user2@example.com', 'User 2');
```

**So sánh với Prisma**:
```typescript
// Single record
await prisma.user.create({
  data: { email: 'user@example.com', name: 'Nguyễn Văn A' }
})

// Multiple records
await prisma.user.createMany({
  data: [
    { email: 'user1@example.com', name: 'User 1' },
    { email: 'user2@example.com', name: 'User 2' }
  ]
})
```

### SELECT: Truy vấn dữ liệu

**Truy vấn cơ bản**:
```sql
-- Truy vấn tất cả cột
SELECT * FROM users;

-- Truy vấn cột chỉ định
SELECT id, name FROM users;

-- Truy vấn có điều kiện
SELECT * FROM users WHERE email = 'user@example.com';
```

**Điều kiện thường dùng**:
```sql
-- Khớp mờ (fuzzy match)
SELECT * FROM users WHERE name LIKE 'Nguyễn%';

-- Truy vấn theo phạm vi
SELECT * FROM posts WHERE created_at > '2024-01-01';

-- Nhiều điều kiện
SELECT * FROM users WHERE role = 'ADMIN' AND status = 'ACTIVE';

-- Truy vấn IN
SELECT * FROM users WHERE id IN ('uuid-1', 'uuid-2');
```

**Sắp xếp và phân trang**:
```sql
-- Sắp xếp
SELECT * FROM posts ORDER BY created_at DESC;

-- Phân trang (PostgreSQL)
SELECT * FROM posts LIMIT 10 OFFSET 0;
```

**So sánh với Prisma**:
```typescript
await prisma.user.findMany({
  where: {
    name: { contains: 'Nguyễn' },
    role: 'ADMIN'
  },
  orderBy: { createdAt: 'desc' },
  take: 10,
  skip: 0
})
```

### UPDATE: Cập nhật dữ liệu

**Cập nhật một/nhiều record**:
```sql
-- Cập nhật record chỉ định
UPDATE users SET name = 'Trần Văn B' WHERE id = 'uuid-1';

-- Cập nhật hàng loạt
UPDATE users SET status = 'INACTIVE' WHERE last_login < '2024-01-01';
```

**So sánh với Prisma**:
```typescript
// Single record
await prisma.user.update({
  where: { id: 'uuid-1' },
  data: { name: 'Trần Văn B' }
})

// Batch update
await prisma.user.updateMany({
  where: { lastLogin: { lt: new Date('2024-01-01') } },
  data: { status: 'INACTIVE' }
})
```

::: warning Chú ý
UPDATE không có WHERE sẽ cập nhật tất cả record!
```sql
-- Nguy hiểm! Sẽ cập nhật tất cả user
UPDATE users SET status = 'DELETED';
```
:::

### DELETE: Xóa dữ liệu

```sql
-- Xóa record chỉ định
DELETE FROM users WHERE id = 'uuid-1';

-- Xóa hàng loạt
DELETE FROM users WHERE status = 'DELETED';
```

**So sánh với Prisma**:
```typescript
await prisma.user.delete({ where: { id: 'uuid-1' } })
await prisma.user.deleteMany({ where: { status: 'DELETED' } })
```

::: danger Cảnh báo
DELETE không có WHERE sẽ xóa tất cả dữ liệu!
```sql
-- Nguy hiểm! Sẽ xóa tất cả user
DELETE FROM users;
```
:::

### Bảng tra cứu nhanh SQL vs Prisma

| Thao tác | SQL | Prisma |
|------|-----|--------|
| Chèn | `INSERT INTO ... VALUES` | `create()` |
| Truy vấn toàn bộ | `SELECT * FROM` | `findMany()` |
| Truy vấn có điều kiện | `WHERE column = value` | `where: { column: value }` |
| Tìm kiếm mờ | `LIKE '%keyword%'` | `contains: 'keyword'` |
| Sắp xếp | `ORDER BY column DESC` | `orderBy: { column: 'desc' }` |
| Phân trang | `LIMIT 10 OFFSET 0` | `take: 10, skip: 0` |
| Cập nhật | `UPDATE ... SET ... WHERE` | `update()` |
| Xóa | `DELETE FROM ... WHERE` | `delete()` |

### Tóm tắt chương này

- DML dùng để thao tác dữ liệu (INSERT/SELECT/UPDATE/DELETE)
- Prisma cung cấp type-safe wrapper cho DML
- UPDATE và DELETE nhất định phải có điều kiện WHERE
- Hiểu SQL giúp debug các query mà Prisma tạo ra
