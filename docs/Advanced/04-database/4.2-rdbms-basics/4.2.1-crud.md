# 4.2.1 Đằng sau thêm/xóa/sửa/tra cứu — Thao tác CRUD: Cơ bản về Create/Read/Update/Delete

### Một câu giải thích

CRUD là bốn thao tác cơ bản của cơ sở dữ liệu — hầu hết mọi logic nghiệp vụ đều có thể quy về sự kết hợp của bốn thao tác này.

### Bốn thao tác CRUD

| Thao tác | SQL | Prisma | Giải thích |
|------|-----|--------|------|
| **C**reate | INSERT | create | Thêm dữ liệu |
| **R**ead | SELECT | findMany/findUnique | Truy vấn dữ liệu |
| **U**pdate | UPDATE | update | Sửa dữ liệu |
| **D**elete | DELETE | delete | Xóa dữ liệu |

### Create: Tạo dữ liệu

**Cách viết SQL**:
```sql
INSERT INTO users (email, name) VALUES ('user@example.com', 'Trần Anh');
```

**Cách viết Prisma**:
```typescript
const user = await prisma.user.create({
  data: {
    email: 'user@example.com',
    name: 'Trần Anh'
  }
})
```

**Tạo hàng loạt**:
```typescript
const users = await prisma.user.createMany({
  data: [
    { email: 'user1@example.com', name: 'Người dùng 1' },
    { email: 'user2@example.com', name: 'Người dùng 2' }
  ]
})
```

### Read: Truy vấn dữ liệu

**Truy vấn đơn**:
```typescript
const user = await prisma.user.findUnique({
  where: { id: 'xxx' }
})
```

**Truy vấn nhiều**:
```typescript
const users = await prisma.user.findMany({
  where: { name: { contains: 'Trần' } },
  orderBy: { createdAt: 'desc' },
  take: 10,
  skip: 0
})
```

**Truy vấn quan hệ**:
```typescript
const userWithPosts = await prisma.user.findUnique({
  where: { id: 'xxx' },
  include: { posts: true }
})
```

### Update: Cập nhật dữ liệu

**Cập nhật đơn**:
```typescript
const user = await prisma.user.update({
  where: { id: 'xxx' },
  data: { name: 'Tên mới' }
})
```

**Cập nhật hàng loạt**:
```typescript
const count = await prisma.user.updateMany({
  where: { role: 'USER' },
  data: { status: 'ACTIVE' }
})
```

**Cập nhật có điều kiện (upsert)**:
```typescript
// Nếu tồn tại thì cập nhật, không tồn tại thì tạo mới
const user = await prisma.user.upsert({
  where: { email: 'user@example.com' },
  update: { name: 'Tên sau khi cập nhật' },
  create: { email: 'user@example.com', name: 'Người dùng mới' }
})
```

### Delete: Xóa dữ liệu

**Xóa đơn**:
```typescript
const user = await prisma.user.delete({
  where: { id: 'xxx' }
})
```

**Xóa hàng loạt**:
```typescript
const count = await prisma.user.deleteMany({
  where: { status: 'DELETED' }
})
```

### Xóa mềm vs Xóa cứng

| Loại | Giải thích | Trường hợp áp dụng |
|------|------|----------|
| **Xóa cứng** | Thực sự xóa khỏi cơ sở dữ liệu | Dữ liệu tạm thời, dữ liệu log |
| **Xóa mềm** | Đánh dấu đã xóa, giữ lại dữ liệu | Dữ liệu người dùng, dữ liệu đơn hàng |

**Triển khai xóa mềm**:
```prisma
model User {
  id        String    @id
  deletedAt DateTime? // null nghĩa là chưa xóa
}
```

```typescript
// Xóa mềm
await prisma.user.update({
  where: { id: 'xxx' },
  data: { deletedAt: new Date() }
})

// Lọc bỏ dữ liệu đã xóa khi truy vấn
await prisma.user.findMany({
  where: { deletedAt: null }
})
```

### Tính nguyên tử của thao tác

Cơ sở dữ liệu đảm bảo một thao tác CRUD đơn lẻ là nguyên tử:

- Hoặc **thành công hoàn toàn**
- Hoặc **thất bại hoàn toàn**
- Không xuất hiện tình huống "sửa dở"

Nếu cần nhiều thao tác cùng thành công hoặc thất bại, cần sử dụng **transaction** (chi tiết ở mục 4.2.3).

### Hướng dẫn tránh lỗi

1. **Tránh truy vấn N+1**: Sử dụng `include` để truy vấn dữ liệu quan hệ một lần
   ```typescript
   // Sai: Truy vấn N+1
   const users = await prisma.user.findMany()
   for (const user of users) {
     const posts = await prisma.post.findMany({ where: { authorId: user.id } })
   }

   // Đúng: Một lần truy vấn
   const users = await prisma.user.findMany({ include: { posts: true } })
   ```

2. **Kiểm tra quan hệ trước khi xóa**: Ràng buộc khóa ngoại có thể ngăn xóa
   ```typescript
   // Xóa dữ liệu quan hệ trước, hoặc cấu hình cascade delete
   await prisma.post.deleteMany({ where: { authorId: userId } })
   await prisma.user.delete({ where: { id: userId } })
   ```

3. **Chú ý đồng thời khi cập nhật**: Nhiều người cùng cập nhật một dữ liệu có thể gây xung đột

### Tóm tắt phần này

- CRUD là bốn thao tác cơ bản của cơ sở dữ liệu
- Prisma cung cấp API CRUD an toàn về kiểu
- Xóa mềm an toàn hơn xóa cứng
- Chú ý tránh vấn đề truy vấn N+1
