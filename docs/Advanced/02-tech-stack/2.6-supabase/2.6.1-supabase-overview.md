# 2.6.1 Tổng quan dịch vụ Supabase

## Một câu phá đề

Supabase đóng gói PostgreSQL database, user authentication, file storage, realtime subscription thành một nền tảng BaaS (Backend-as-a-Service) sẵn sàng sử dụng — bạn chỉ cần viết code frontend, backend nó lo hết.

## Chi tiết các dịch vụ cốt lõi

### 1. Database: PostgreSQL database

```typescript
// Query database trực tiếp từ client
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
)

// Query
const { data, error } = await supabase
  .from('posts')
  .select('*, author:users(*)')
  .eq('status', 'published')
  .order('created_at', { ascending: false })

// Insert
const { data, error } = await supabase
  .from('posts')
  .insert({ title: 'Hello', content: 'World' })
  .select()
```

**Đặc điểm**:
- PostgreSQL đầy đủ, hỗ trợ tất cả tính năng SQL
- Row Level Security (RLS) tích hợp sẵn
- Tự động generate REST API và GraphQL API
- Giao diện quản lý database trực quan

### 2. Auth: Xác thực người dùng

```typescript
// Đăng nhập bằng email password
const { data, error } = await supabase.auth.signInWithPassword({
  email: 'user@example.com',
  password: 'password',
})

// Đăng nhập OAuth (Google/GitHub etc)
const { data, error } = await supabase.auth.signInWithOAuth({
  provider: 'google',
})

// Lấy user hiện tại
const { data: { user } } = await supabase.auth.getUser()

// Đăng xuất
await supabase.auth.signOut()
```

**Các phương thức xác thực được hỗ trợ**:
- Email password
- Magic Link (email link)
- OAuth (Google, GitHub, Twitter etc)
- Phone OTP

### 3. Storage: Lưu trữ file

```typescript
// Upload file
const { data, error } = await supabase.storage
  .from('avatars')
  .upload(`${userId}/avatar.png`, file)

// Lấy public URL
const { data } = supabase.storage
  .from('avatars')
  .getPublicUrl(`${userId}/avatar.png`)

// Download file
const { data, error } = await supabase.storage
  .from('documents')
  .download('report.pdf')
```

**Đặc điểm**:
- Tích hợp với Auth, hỗ trợ kiểm soát quyền
- Tự động CDN acceleration
- Hỗ trợ xử lý ảnh (resize, crop)

### 4. Realtime: Realtime subscription

```typescript
// Subscribe data changes
const channel = supabase
  .channel('posts')
  .on(
    'postgres_changes',
    { event: '*', schema: 'public', table: 'posts' },
    (payload) => {
      console.log('Thay đổi:', payload)
    }
  )
  .subscribe()

// Unsubscribe
supabase.removeChannel(channel)
```

**Tình huống áp dụng**:
- Realtime chat
- Collaborative editing
- Realtime notifications
- Data dashboard

## Row Level Security (RLS)

Một trong những tính năng mạnh nhất của Supabase là Row Level Security:

```sql
-- User chỉ có thể xem bài viết của mình
CREATE POLICY "User chỉ có thể xem bài viết của mình" ON posts
  FOR SELECT
  USING (auth.uid() = author_id);

-- User chỉ có thể sửa bài viết của mình
CREATE POLICY "User chỉ có thể sửa bài viết của mình" ON posts
  FOR UPDATE
  USING (auth.uid() = author_id);

-- Mọi người có thể xem bài viết đã publish
CREATE POLICY "Bài viết công khai mọi người có thể xem" ON posts
  FOR SELECT
  USING (status = 'published');
```

## Tích hợp với Next.js

### Cài đặt

```bash
pnpm add @supabase/supabase-js @supabase/ssr
```

### Cấu hình

```typescript
// lib/supabase/client.ts
import { createBrowserClient } from '@supabase/ssr'

export function createClient() {
  return createBrowserClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
  )
}
```

```typescript
// lib/supabase/server.ts
import { createServerClient } from '@supabase/ssr'
import { cookies } from 'next/headers'

export function createClient() {
  const cookieStore = cookies()

  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        get(name: string) {
          return cookieStore.get(name)?.value
        },
      },
    }
  )
}
```

### Sử dụng trong Server Component

```typescript
// app/posts/page.tsx
import { createClient } from '@/lib/supabase/server'

export default async function PostsPage() {
  const supabase = createClient()

  const { data: posts } = await supabase
    .from('posts')
    .select('*')
    .eq('status', 'published')

  return (
    <ul>
      {posts?.map(post => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  )
}
```

## Tóm tắt phần này

| Dịch vụ | Giá trị cốt lõi | Lưu ý |
|------|----------|----------|
| **Database** | PostgreSQL đầy đủ + API tự động | Cấu hình RLS phức tạp |
| **Auth** | Authentication sẵn sàng dùng | Tùy chỉnh bị hạn chế |
| **Storage** | Storage tích hợp với Auth | Chi phí cao với file lớn |
| **Realtime** | Realtime subscription không cần config | Số lượng kết nối bị giới hạn |
