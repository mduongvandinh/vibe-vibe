# 2.3.3 Server Actions Best Practice

## Giải thích một câu

Server Actions cho phép bạn gọi trực tiếp hàm server từ client, không cần tạo API route thủ công — nhưng để dùng tốt, cần nắm vững best practice về xử lý form, xử lý lỗi và optimistic update.

## Cách dùng cơ bản

### Định nghĩa Server Action

```typescript
// app/actions.ts
'use server'

export async function createPost(formData: FormData) {
  const title = formData.get('title') as string
  const content = formData.get('content') as string

  await db.post.create({
    data: { title, content }
  })

  revalidatePath('/posts')
}
```

### Dùng trong form

```typescript
// app/posts/new/page.tsx
import { createPost } from '@/app/actions'

export default function NewPostPage() {
  return (
    <form action={createPost}>
      <input name="title" required />
      <textarea name="content" required />
      <button type="submit">Đăng</button>
    </form>
  )
}
```

## Validate form

### Dùng Zod validate

```typescript
// app/actions.ts
'use server'

import { z } from 'zod'

const PostSchema = z.object({
  title: z.string().min(1, 'Tiêu đề không được để trống').max(100),
  content: z.string().min(10, 'Nội dung tối thiểu 10 ký tự'),
})

export async function createPost(formData: FormData) {
  const validatedFields = PostSchema.safeParse({
    title: formData.get('title'),
    content: formData.get('content'),
  })

  if (!validatedFields.success) {
    return {
      errors: validatedFields.error.flatten().fieldErrors,
    }
  }

  await db.post.create({ data: validatedFields.data })
  revalidatePath('/posts')
  redirect('/posts')
}
```

### Hiển thị lỗi validate

```typescript
// components/post-form.tsx
'use client'

import { useFormState } from 'react-dom'
import { createPost } from '@/app/actions'

export function PostForm() {
  const [state, formAction] = useFormState(createPost, { errors: {} })

  return (
    <form action={formAction}>
      <div>
        <input name="title" />
        {state.errors?.title && (
          <p className="text-red-500">{state.errors.title}</p>
        )}
      </div>
      <div>
        <textarea name="content" />
        {state.errors?.content && (
          <p className="text-red-500">{state.errors.content}</p>
        )}
      </div>
      <SubmitButton />
    </form>
  )
}
```

## Xử lý trạng thái submit

```typescript
// components/submit-button.tsx
'use client'

import { useFormStatus } from 'react-dom'

export function SubmitButton() {
  const { pending } = useFormStatus()

  return (
    <button type="submit" disabled={pending}>
      {pending ? 'Đang gửi...' : 'Gửi'}
    </button>
  )
}
```

## Optimistic update

```typescript
// components/like-button.tsx
'use client'

import { useOptimistic } from 'react'
import { likePost } from '@/app/actions'

export function LikeButton({ postId, likes }: { postId: string; likes: number }) {
  const [optimisticLikes, addOptimisticLike] = useOptimistic(
    likes,
    (state, _) => state + 1
  )

  async function handleLike() {
    addOptimisticLike(null)  // Cập nhật UI ngay lập tức
    await likePost(postId)    // Request thực tế
  }

  return (
    <form action={handleLike}>
      <button type="submit">
        ❤️ {optimisticLikes}
      </button>
    </form>
  )
}
```

## Xử lý lỗi

### Throw error trong Server Action

```typescript
// app/actions.ts
'use server'

export async function deletePost(postId: string) {
  const post = await db.post.findUnique({ where: { id: postId } })

  if (!post) {
    throw new Error('Bài viết không tồn tại')
  }

  if (post.authorId !== getCurrentUserId()) {
    throw new Error('Không có quyền xóa bài viết này')
  }

  await db.post.delete({ where: { id: postId } })
  revalidatePath('/posts')
}
```

### error.tsx bắt lỗi

```typescript
// app/posts/error.tsx
'use client'

export default function Error({
  error,
  reset,
}: {
  error: Error
  reset: () => void
}) {
  return (
    <div>
      <h2>Có lỗi xảy ra: {error.message}</h2>
      <button onClick={reset}>Thử lại</button>
    </div>
  )
}
```

## Server Actions vs API Routes

| Tình huống | Phương án đề xuất |
|------|----------|
| Submit form | Server Actions |
| Mutation data | Server Actions |
| Gọi từ bên thứ ba | API Routes |
| Webhook | API Routes |
| Query phức tạp | Server Actions |

## Nhận thức: Vấn đề thường gặp

### 1. Quên `'use server'`

```typescript
// ❌ Không có 'use server', không phải Server Action
export async function createPost(formData) {
  // Sẽ chạy trên client!
}

// ✅ Thêm 'use server'
'use server'
export async function createPost(formData) {
  // Chạy trên server
}
```

### 2. Thao tác nhạy cảm không validate

```typescript
// ❌ Không kiểm tra quyền
export async function deletePost(id) {
  await db.post.delete({ where: { id } })
}

// ✅ Thêm kiểm tra quyền
export async function deletePost(id) {
  const user = await getCurrentUser()
  const post = await db.post.findUnique({ where: { id } })

  if (post.authorId !== user.id) {
    throw new Error('Không có quyền thao tác')
  }

  await db.post.delete({ where: { id } })
}
```

## Tổng kết mục này

| Best practice | Giải thích |
|----------|------|
| Validate Zod | Luôn validate dữ liệu đầu vào |
| useFormState | Xử lý state và lỗi của form |
| useFormStatus | Hiển thị trạng thái submit |
| useOptimistic | Optimistic update nâng cao trải nghiệm |
| Kiểm tra quyền | Thao tác nhạy cảm phải validate |
