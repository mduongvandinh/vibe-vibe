# 12.3.4 Tối ưu hóa trải nghiệm người dùng — Trạng thái tải và xử lý lỗi: Thiết kế tương tác AI tinh tế

### Một dòng để phá đề

Trải nghiệm người dùng của ứng dụng AI không chỉ phụ thuộc vào khả năng mô hình, mà còn phụ thuộc vào cách xử lý tải, lỗi và các trường hợp biên — đây là điểm khác biệt giữa "có thể dùng" và "tốt để dùng".

### Giá trị cốt lõi

Ứng dụng AI tuyệt vời cần xử lý các kịch bản sau:

1. **Trạng thái tải**: Để người dùng biết AI đang suy nghĩ
2. **Hiển thị streaming**: Từng ký tự hiển thị, thay vì xuất hiện đột ngột
3. **Khôi phục lỗi**: Khi gặp lỗi hãy cung cấp tùy chọn thử lại
4. **Hủy hoạt động**: Cho phép người dùng dừng trong quá trình
5. **Trạng thái trống**: Hướng dẫn khi ở trạng thái ban đầu

### Thiết kế trạng thái tải

```tsx
function LoadingIndicator() {
  return (
    <div className="flex items-center gap-2 text-gray-500">
      <div className="flex gap-1">
        <span className="w-2 h-2 bg-gray-400 rounded-full animate-bounce" style={{ animationDelay: '0ms' }} />
        <span className="w-2 h-2 bg-gray-400 rounded-full animate-bounce" style={{ animationDelay: '150ms' }} />
        <span className="w-2 h-2 bg-gray-400 rounded-full animate-bounce" style={{ animationDelay: '300ms' }} />
      </div>
      <span>AI đang suy nghĩ...</span>
    </div>
  );
}

function ChatUI() {
  const { messages, isLoading, ... } = useChat();

  return (
    <div>
      {messages.map((m) => (
        <MessageBubble key={m.id} message={m} />
      ))}

      {isLoading && <LoadingIndicator />}
    </div>
  );
}
```

### Tối ưu hóa hiệu ứng máy đánh chữ

Đầu ra streaming mặc định đã là hiển thị từng ký tự, nhưng có thể tối ưu hóa thêm:

```tsx
function StreamingMessage({ content }: { content: string }) {
  return (
    <div className="relative">
      <span>{content}</span>
      <span className="inline-block w-2 h-4 bg-gray-800 animate-pulse ml-1" />
    </div>
  );
}
```

### Xử lý lỗi và thử lại

```tsx
function ChatWithErrorHandling() {
  const { messages, error, reload, isLoading } = useChat({
    onError: (error) => {
      // Có thể kết nối với dịch vụ giám sát lỗi
      console.error('Chat error:', error);
    },
  });

  if (error) {
    return (
      <div className="p-4 bg-red-50 border border-red-200 rounded-lg">
        <div className="flex items-center gap-2 text-red-700">
          <svg className="w-5 h-5" fill="currentColor" viewBox="0 0 20 20">
            <path fillRule="evenodd" d="M10 18a8 8 0 100-16 8 8 0 000 16zM8.707 7.293a1 1 0 00-1.414 1.414L8.586 10l-1.293 1.293a1 1 0 101.414 1.414L10 11.414l1.293 1.293a1 1 0 001.414-1.414L11.414 10l1.293-1.293a1 1 0 00-1.414-1.414L10 8.586 8.707 7.293z" clipRule="evenodd" />
          </svg>
          <span>Lỗi: {error.message}</span>
        </div>
        <button
          onClick={() => reload()}
          className="mt-2 px-3 py-1 bg-red-600 text-white rounded hover:bg-red-700"
        >
          Thử lại
        </button>
      </div>
    );
  }

  // ... Render bình thường
}
```

### Dừng tạo

```tsx
function ChatWithStop() {
  const { isLoading, stop, handleSubmit, ... } = useChat();

  return (
    <form onSubmit={handleSubmit}>
      {/* ... Input field */}

      {isLoading ? (
        <button
          type="button"
          onClick={stop}
          className="px-4 py-2 bg-red-500 text-white rounded"
        >
          Dừng tạo
        </button>
      ) : (
        <button type="submit" className="px-4 py-2 bg-blue-500 text-white rounded">
          Gửi
        </button>
      )}
    </form>
  );
}
```

### Hướng dẫn trạng thái trống

```tsx
function EmptyState() {
  const suggestions = [
    'Giúp tôi viết một bản tự giới thiệu',
    'Giải thích React Hooks là gì',
    'Kể cho tôi một câu chuyện vui',
  ];

  return (
    <div className="flex flex-col items-center justify-center h-full text-center p-8">

      <p className="text-gray-500 mb-6">Hãy thử các câu hỏi sau:</p>
      <div className="flex flex-wrap gap-2 justify-center">
        {suggestions.map((s) => (
          <button
            key={s}
            onClick={() => append({ role: 'user', content: s })}
            className="px-4 py-2 bg-gray-100 rounded-full hover:bg-gray-200"
          >
            {s}
          </button>
        ))}
      </div>
    </div>
  );
}

function Chat() {
  const { messages, append, ... } = useChat();

  return (
    <div>
      {messages.length === 0 ? (
        <EmptyState />
      ) : (
        // ... Danh sách tin nhắn
      )}
    </div>
  );
}
```

### Hướng dẫn hợp tác với AI

- **Ý định cốt lõi**: Để AI giúp bạn thiết kế các trạng thái tương tác hoàn chỉnh.
- **Công thức định nghĩa nhu cầu**: `"Vui lòng giúp tôi thực hiện xử lý trạng thái đầy đủ cho giao diện chat AI, bao gồm hoạt ảnh tải, thông báo lỗi, nút thử lại và chức năng dừng tạo."`
- **Thuật ngữ chính**: `isLoading`, `error`, `reload`, `stop`, `empty state`

### Hướng dẫn tránh lỗi

- **Trạng thái tải phải có phản hồi trực quan**: Đừng để người dùng đoán liệu có đang hoạt động không.
- **Thông báo lỗi phải thân thiện với người dùng**: Chuyển đổi lỗi kỹ thuật thành gợi ý dễ hiểu.
- **Cung cấp thoát ngã**: Người dùng nên có thể hủy các hoạt động chạy lâu.
