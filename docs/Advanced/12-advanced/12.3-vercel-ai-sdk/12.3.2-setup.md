# 12.3.2 Bộ công cụ chính thức — Vercel AI SDK: Cài đặt cấu hình và sử dụng cơ bản

### Một dòng để phá đề

Vercel AI SDK cung cấp một giao diện thống nhất để gọi các mô hình AI khác nhau, chỉ với vài dòng mã bạn có thể xây dựng một ứng dụng AI có khả năng đối thoại streaming.

### Bắt đầu nhanh chóng

#### 1. Cài đặt phụ thuộc

```bash
pnpm add ai @ai-sdk/openai
```

SDK được thiết kế theo kiến trúc mô-đun, các nhà cung cấp mô hình khác nhau cần cài đặt các gói tương ứng:

| Nhà cung cấp | Tên gói |
|--------|------|
| OpenAI | `@ai-sdk/openai` |
| Anthropic | `@ai-sdk/anthropic` |
| Google | `@ai-sdk/google` |
| Azure | `@ai-sdk/azure` |

#### 2. Cấu hình biến môi trường

```env
# .env.local
OPENAI_API_KEY=sk-xxxxxxxxxxxxx
```

#### 3. Tạo route API

```typescript
// app/api/chat/route.ts
import { openai } from '@ai-sdk/openai';
import { streamText } from 'ai';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: openai('gpt-4o'),
    messages,
  });

  return result.toDataStreamResponse();
}
```

#### 4. Gọi từ front-end

```tsx
'use client';

import { useChat } from 'ai/react';

export default function Chat() {
  const { messages, input, handleInputChange, handleSubmit, isLoading } = useChat();

  return (
    <div>
      {messages.map((m) => (
        <div key={m.id}>
          <strong>{m.role}:</strong> {m.content}
        </div>
      ))}

      <form onSubmit={handleSubmit}>
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="Nhập tin nhắn..."
          disabled={isLoading}
        />
        <button type="submit" disabled={isLoading}>
          Gửi
        </button>
      </form>
    </div>
  );
}
```

### Tổng quan API cốt lõi

| API | Mục đích | Loại trả lại |
|-----|------|----------|
| `streamText` | Tạo văn bản streaming | `StreamTextResult` |
| `generateText` | Tạo văn bản một lần | `GenerateTextResult` |
| `streamObject` | Đầu ra cấu trúc streaming | `StreamObjectResult` |
| `generateObject` | Đầu ra cấu trúc một lần | `GenerateObjectResult` |

### Chuyển đổi nhà cung cấp mô hình

Ưu điểm của SDK là giao diện thống nhất, chuyển đổi mô hình chỉ cần thay đổi một dòng mã:

```typescript
import { openai } from '@ai-sdk/openai';
import { anthropic } from '@ai-sdk/anthropic';
import { google } from '@ai-sdk/google';

// Sử dụng OpenAI
const result = streamText({
  model: openai('gpt-4o'),
  messages,
});

// Sử dụng Anthropic
const result = streamText({
  model: anthropic('claude-3-5-sonnet-20241022'),
  messages,
});

// Sử dụng Google
const result = streamText({
  model: google('gemini-1.5-pro'),
  messages,
});
```

### Hướng dẫn hợp tác với AI

- **Ý định cốt lõi**: Để AI giúp bạn xây dựng nhanh chóng chức năng đối thoại AI.
- **Công thức định nghĩa nhu cầu**: `"Vui lòng giúp tôi tích hợp Vercel AI SDK vào dự án Next.js của tôi, thực hiện một giao diện chat cơ bản, sử dụng mô hình gpt-4o từ OpenAI."`
- **Thuật ngữ chính**: `streamText`, `useChat`, `ai/react`, `toDataStreamResponse`

### Hướng dẫn tránh lỗi

- **Không để API Key tiếp xúc với front-end**: Biến môi trường chỉ khả dụng trên máy chủ, đây là cách thiết kế.
- **Chú ý giới hạn Token**: Các mô hình khác nhau có kích thước cửa sổ ngữ cảnh khác nhau.
- **Xử lý giới hạn tốc độ**: Các lệnh gọi API có thể gặp giới hạn tốc độ, cần thêm logic thử lại.
