# 12.3.3 Tạo nội dung thời gian thực — Tạo văn bản streaming: Thực hành useChat/useCompletion

### Một dòng để phá đề

`useChat` dùng cho đối thoại đa vòng, `useCompletion` dùng cho tạo đơn lần — chọn Hook phù hợp, công việc sẽ gấp rưỡi lúc.

### useChat so với useCompletion

| Tính năng | useChat | useCompletion |
|------|---------|---------------|
| Mục đích | Đối thoại đa vòng | Tạo văn bản đơn lần |
| Lịch sử tin nhắn | Tự động duy trì | Không duy trì |
| Kịch bản típ | Chatbot | Tạo bài viết, hoàn thành mã |
| Điểm cuối API | `/api/chat` | `/api/completion` |

### Sử dụng sâu useChat

```tsx
'use client';

import { useChat, Message } from 'ai/react';

export default function ChatBot() {
  const {
    messages,      // Lịch sử tin nhắn
    input,         // Nội dung ô nhập
    handleInputChange,
    handleSubmit,
    isLoading,     // Có đang tạo không
    error,         // Thông báo lỗi
    reload,        // Tạo lại tin nhắn cuối cùng
    stop,          // Dừng tạo
    setMessages,   // Đặt tin nhắn theo cách thủ công
    append,        // Thêm tin nhắn
  } = useChat({
    api: '/api/chat',
    initialMessages: [
      { id: '1', role: 'system', content: 'Bạn là một trợ lý thân thiện' },
    ],
    onFinish: (message) => {
      console.log('Tạo xong:', message);
    },
    onError: (error) => {
      console.error('Lỗi xảy ra:', error);
    },
  });

  return (
    <div className="flex flex-col h-screen">
      {/* Danh sách tin nhắn */}
      <div className="flex-1 overflow-auto p-4">
        {messages.filter(m => m.role !== 'system').map((m) => (
          <div
            key={m.id}
            className={`mb-4 ${m.role === 'user' ? 'text-right' : 'text-left'}`}
          >
            <span className={`inline-block p-3 rounded-lg ${
              m.role === 'user' ? 'bg-blue-500 text-white' : 'bg-gray-200'
            }`}>
              {m.content}
            </span>
          </div>
        ))}

        {isLoading && (
          <div className="text-gray-500">AI đang suy nghĩ...</div>
        )}
      </div>

      {/* Khu vực nhập liệu */}
      <form onSubmit={handleSubmit} className="p-4 border-t">
        <div className="flex gap-2">
          <input
            value={input}
            onChange={handleInputChange}
            placeholder="Nhập tin nhắn..."
            className="flex-1 p-2 border rounded"
            disabled={isLoading}
          />
          {isLoading ? (
            <button type="button" onClick={stop} className="px-4 py-2 bg-red-500 text-white rounded">
              Dừng
            </button>
          ) : (
            <button type="submit" className="px-4 py-2 bg-blue-500 text-white rounded">
              Gửi
            </button>
          )}
        </div>
      </form>

      {error && (
        <div className="p-4 bg-red-100 text-red-700">
          Lỗi: {error.message}
          <button onClick={() => reload()} className="ml-2 underline">
            Thử lại
          </button>
        </div>
      )}
    </div>
  );
}
```

### Thực hành useCompletion

```tsx
'use client';

import { useCompletion } from 'ai/react';

export default function ArticleGenerator() {
  const {
    completion,    // Văn bản được tạo
    input,
    handleInputChange,
    handleSubmit,
    isLoading,
    error,
  } = useCompletion({
    api: '/api/completion',
  });

  return (
    <div className="p-4">
      <form onSubmit={handleSubmit}>
        <textarea
          value={input}
          onChange={handleInputChange}
          placeholder="Nhập chủ đề bài viết..."
          className="w-full p-2 border rounded"
          rows={3}
        />
        <button
          type="submit"
          disabled={isLoading}
          className="mt-2 px-4 py-2 bg-blue-500 text-white rounded"
        >
          {isLoading ? 'Đang tạo...' : 'Tạo bài viết'}
        </button>
      </form>

      {completion && (
        <div className="mt-4 p-4 bg-gray-100 rounded whitespace-pre-wrap">
          {completion}
        </div>
      )}
    </div>
  );
}
```

Route API tương ứng:

```typescript
// app/api/completion/route.ts
import { openai } from '@ai-sdk/openai';
import { streamText } from 'ai';

export async function POST(req: Request) {
  const { prompt } = await req.json();

  const result = streamText({
    model: openai('gpt-4o'),
    prompt: `Vui lòng tạo một bài viết dựa trên chủ đề sau:\n\n${prompt}`,
  });

  return result.toDataStreamResponse();
}
```

### Nâng cao: Render tin nhắn tùy chỉnh

```tsx
import { useChat } from 'ai/react';
import ReactMarkdown from 'react-markdown';

export default function MarkdownChat() {
  const { messages, ... } = useChat();

  return (
    <div>
      {messages.map((m) => (
        <div key={m.id}>
          {m.role === 'assistant' ? (
            <ReactMarkdown>{m.content}</ReactMarkdown>
          ) : (
            <p>{m.content}</p>
          )}
        </div>
      ))}
    </div>
  );
}
```

### Hướng dẫn hợp tác với AI

- **Ý định cốt lõi**: Để AI giúp bạn thực hiện một chức năng đối thoại hoặc tạo cụ thể.
- **Công thức định nghĩa nhu cầu**: `"Vui lòng giúp tôi sử dụng useChat để thực hiện giao diện chat hỗ trợ render Markdown, có nút dừng tạo."`
- **Thuật ngữ chính**: `useChat`, `useCompletion`, `messages`, `isLoading`, `stop`

### Hướng dẫn tránh lỗi

- **Đừng hiển thị tin nhắn hệ thống trong UI**: Lọc bỏ các tin nhắn có `role === 'system'`.
- **Xử lý tin nhắn trống**: Người dùng có thể gửi tin nhắn trống, cần xác thực ở mức form.
- **Chú ý ID tin nhắn**: Mỗi tin nhắn cần ID duy nhất, SDK tự động tạo nhưng cần chú ý khi thêm tin nhắn thủ công.
