# 12.4.4 Xử lý ngoại lệ kết nối——Quản lý kết nối: Reconnection và đồng bộ hóa trạng thái

### Nội dung chính trong một câu

Mạng không đáng tin cậy là bình thường, ứng dụng thời gian thực tốt phải xử lý một cách tính toán các tình huống ngắt kết nối, reconnection và đồng bộ hóa trạng thái.

### Quản lý trạng thái kết nối

```tsx
'use client';

import { useEffect, useState } from 'react';
import { io, Socket } from 'socket.io-client';

type ConnectionStatus = 'connecting' | 'connected' | 'disconnected' | 'reconnecting';

export function useSocket(url: string) {
  const [socket, setSocket] = useState<Socket | null>(null);
  const [status, setStatus] = useState<ConnectionStatus>('connecting');

  useEffect(() => {
    const newSocket = io(url, {
      reconnection: true,
      reconnectionAttempts: 5,
      reconnectionDelay: 1000,
      reconnectionDelayMax: 5000,
    });

    newSocket.on('connect', () => {
      setStatus('connected');
      console.log('Đã kết nối');
    });

    newSocket.on('disconnect', (reason) => {
      setStatus('disconnected');
      console.log('Ngắt kết nối:', reason);
    });

    newSocket.on('reconnect_attempt', (attempt) => {
      setStatus('reconnecting');
      console.log(`Nỗ lực kết nối lại ${attempt}`);
    });

    newSocket.on('reconnect', () => {
      setStatus('connected');
      console.log('Kết nối lại thành công');
    });

    newSocket.on('reconnect_failed', () => {
      setStatus('disconnected');
      console.log('Kết nối lại thất bại');
    });

    setSocket(newSocket);

    return () => {
      newSocket.close();
    };
  }, [url]);

  return { socket, status };
}
```

### UI chỉ báo trạng thái kết nối

```tsx
function ConnectionIndicator({ status }: { status: ConnectionStatus }) {
  const config = {
    connecting: { color: 'bg-yellow-500', text: 'Đang kết nối...' },
    connected: { color: 'bg-green-500', text: 'Đã kết nối' },

  return (
    <div className="flex items-center gap-2">
      <span className={`w-2 h-2 rounded-full ${color}`} />
      <span className="text-sm text-gray-600">{text}</span>
    </div>
  );
}
```

### Chiến lược đồng bộ hóa trạng thái

Sau khi ngắt kết nối và kết nối lại, cần đồng bộ hóa trạng thái bị mất:

```typescript
// Phía máy chủ: Ghi lại lịch sử thông báo
const messageHistory = new Map<string, Message[]>();

io.on('connection', (socket) => {
  socket.on('joinRoom', (roomId: string) => {
    socket.join(roomId);

    // Gửi lịch sử thông báo
    const history = messageHistory.get(roomId) || [];
    socket.emit('messageHistory', history.slice(-50)); // 50 thông báo gần nhất
  });

  socket.on('sendMessage', ({ roomId, content }) => {
    const message = { id: Date.now().toString(), content, timestamp: Date.now() };

    // Lưu vào lịch sử
    if (!messageHistory.has(roomId)) {
      messageHistory.set(roomId, []);
    }
    messageHistory.get(roomId)!.push(message);

    io.to(roomId).emit('newMessage', message);
  });
});

// Phía máy khách: Xử lý lịch sử thông báo
socket.on('messageHistory', (history: Message[]) => {
  setMessages((prev) => {
    // Loại bỏ trùng lặp và hợp nhất
    const existingIds = new Set(prev.map((m) => m.id));
    const newMessages = history.filter((m) => !existingIds.has(m.id));
    return [...newMessages, ...prev].sort((a, b) => a.timestamp - b.timestamp);
  });
});
```

### Hàng đợi thông báo offline

Khi mạng không tốt, trước tiên hãy lưu trữ thông báo, sau khi phục hồi mới gửi:

```typescript
class MessageQueue {
  private queue: Array<{ event: string; data: unknown }> = [];
  private socket: Socket | null = null;

  setSocket(socket: Socket) {
    this.socket = socket;
    this.flush();
  }

  send(event: string, data: unknown) {
    if (this.socket?.connected) {
      this.socket.emit(event, data);
    } else {
      this.queue.push({ event, data });
    }
  }

  flush() {
    if (this.socket?.connected) {
      while (this.queue.length > 0) {
        const { event, data } = this.queue.shift()!;
        this.socket.emit(event, data);
      }
    }
  }
}
```

### Hướng dẫn hợp tác AI

- **Ý định cốt lõi**: Cho phép AI giúp bạn thực hiện quản lý kết nối mạnh mẽ.
- **Công thức xác định yêu cầu**: `"Vui lòng giúp tôi thực hiện một bao bọc máy khách Socket.io với trạng thái kết nối, reconnection tự động và hàng đợi thông báo offline."`
- **Thuật ngữ chính**: `reconnection`、`heartbeat`、`state synchronization`、`offline queue`

### Hướng dẫn tránh hố tương tự

- **Exponential backoff**: Khoảng thời gian reconnection nên tăng dần, tránh quá tải máy chủ.
- **Số lần thử tối đa**: Không thử vô hạn, hãy phản hồi với người dùng để họ tự làm tươi.
- **Tính chất idempotent**: Thông báo được gửi lại không nên gây ra tác dụng phụ (như trừ tiền hai lần).
