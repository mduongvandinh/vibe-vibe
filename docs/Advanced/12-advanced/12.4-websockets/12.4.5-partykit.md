# 12.4.5 Lựa chọn hiện đại——PartyKit: Giải pháp giao tiếp thời gian thực tính toán cạnh biên

### Nội dung chính trong một câu

PartyKit là nền tảng giao tiếp thời gian thực "ưu tiên cạnh biên", nó cho phép bạn xây dựng ứng dụng thời gian thực phân tán toàn cầu với mã tối thiểu.

### Tại sao chọn PartyKit

Vấn đề của máy chủ WebSocket truyền thống:

- **Triển khai một điểm**: Người dùng càng xa máy chủ, độ trễ càng cao
- **Khó mở rộng**: Cần tự xử lý cân bằng tải và đồng bộ hóa trạng thái
- **Gánh nặng vận hành**: Cần quản lý máy chủ, giám sát, nhật ký, v.v.

Giải pháp của PartyKit:

- **Triển khai cạnh biên**: Mã tự động được triển khai đến các nút cạnh biên toàn cầu
- **Zero DevOps**: Hoàn toàn được quản lý, không cần lo về cơ sở hạ tầng
- **Quản lý trạng thái**: Lưu trữ và đồng bộ hóa trạng thái được xây dựng sẵn

#### Mã phía máy chủ

```typescript
// party/index.ts
import type { PartyKitServer, PartyKitConnection, PartyKitRoom } from 'partykit/server';

export default {
  onConnect(connection: PartyKitConnection, room: PartyKitRoom) {
    console.log(`${connection.id} tham gia phòng ${room.id}`);

    // Gửi thông báo chào đón
    connection.send(JSON.stringify({ type: 'welcome', roomId: room.id }));

    // Phát sóng cho người khác
    room.broadcast(
      JSON.stringify({ type: 'userJoined', id: connection.id }),
      [connection.id] // Loại trừ người dùng hiện tại
    );
  },

  onMessage(message: string, connection: PartyKitConnection, room: PartyKitRoom) {
    const data = JSON.parse(message);

    // Phát sóng thông báo cho tất cả mọi người
    room.broadcast(
      JSON.stringify({
        type: 'message',
        from: connection.id,
        content: data.content,
        timestamp: Date.now(),
      })
    );
  },

  onClose(connection: PartyKitConnection, room: PartyKitRoom) {
    room.broadcast(
      JSON.stringify({ type: 'userLeft', id: connection.id })
    );
  },
} satisfies PartyKitServer;
```

#### Mã phía máy khách

```tsx
'use client';

import { useEffect, useState } from 'react';
import PartySocket from 'partysocket';

export default function PartyChat({ roomId }: { roomId: string }) {
  const [messages, setMessages] = useState<Array<{ from: string; content: string }>>([]);
  const [input, setInput] = useState('');
  const [socket, setSocket] = useState<PartySocket | null>(null);

  useEffect(() => {
    const partySocket = new PartySocket({
      host: 'your-project.partykit.dev', // hoặc localhost:1999 để phát triển
      room: roomId,
    });

    partySocket.addEventListener('message', (event) => {
      const data = JSON.parse(event.data);
      if (data.type === 'message') {
        setMessages((prev) => [...prev, { from: data.from, content: data.content }]);
      }
    });

    setSocket(partySocket);

    return () => {
      partySocket.close();
    };
  }, [roomId]);

  const sendMessage = () => {
    if (socket && input.trim()) {
      socket.send(JSON.stringify({ content: input }));
      setInput('');
    }
  };

  return (
    <div>
      {messages.map((msg, i) => (
        <div key={i}>
          <strong>{msg.from}:</strong> {msg.content}
        </div>
      ))}
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        onKeyPress={(e) => e.key === 'Enter' && sendMessage()}
      />
      <button onClick={sendMessage}>Gửi</button>
    </div>
  );
}
```

### PartyKit vs Socket.io

| Tính năng | Socket.io | PartyKit |
|------|-----------|----------|
| Cách triển khai | Máy chủ tự quản lý | Triển khai cạnh biên |
| Độ trễ toàn cầu | Tùy thuộc vào vị trí máy chủ | Tự động tối ưu hóa |
| Khả năng mở rộng | Cần tự xử lý | Tự động mở rộng |
| Lưu trữ thường xuyên | Cần cơ sở dữ liệu bên ngoài | Lưu trữ được xây dựng sẵn |
| Giá cả | Chi phí máy chủ | Trả theo mức sử dụng |

### Trạng thái lưu trữ thường xuyên

PartyKit có thể lưu trữ trạng thái trên cạnh biên:

```typescript
export default {
  async onConnect(connection, room) {
    // Lấy trạng thái được lưu trữ
    const state = await room.storage.get('messages') || [];
    connection.send(JSON.stringify({ type: 'history', messages: state }));
  },

  async onMessage(message, connection, room) {
    const data = JSON.parse(message);

    // Lưu vào lưu trữ
    const messages = await room.storage.get('messages') || [];
    messages.push({ from: connection.id, content: data.content });
    await room.storage.put('messages', messages.slice(-100)); // Giữ 100 thông báo gần nhất

    room.broadcast(message);
  },
} satisfies PartyKitServer;
```

### Hướng dẫn hợp tác AI

- **Ý định cốt lõi**: Cho phép AI giúp bạn sử dụng PartyKit xây dựng chức năng thời gian thực.
- **Công thức xác định yêu cầu**: `"Vui lòng giúp tôi sử dụng PartyKit thực hiện một bảng trắng hợp tác thời gian thực, hỗ trợ vẽ đồng thời của nhiều người và đồng bộ hóa trạng thái."`
- **Thuật ngữ chính**: `PartyKit`、`edge computing`、`room`、`broadcast`、`persistent storage`

### Hướng dẫn tránh hố tương tự

- **Thiết kế ID phòng**: ID phòng quyết định cách chia nhóm người dùng, hãy cân nhắc logic kinh doanh khi thiết kế.
- **Giới hạn kích thước thông báo**: Thông báo đơn có giới hạn kích thước, đối với dữ liệu lớn hãy cân nhắc truyền thành từng phần.
- **Độ trễ khởi động lạnh**: Kết nối lần đầu tiên có thể có độ trễ ngắn, hãy xử lý trạng thái loading tốt.
