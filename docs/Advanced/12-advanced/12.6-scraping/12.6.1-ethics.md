# 12.6.1 Quy tắc của Web Scraping——Đạo đức Scraping: robots.txt và Điều khoản Dịch vụ

### Một câu giải quyết vấn đề

robots.txt là "quy tắc kiểm soát truy cập" của một trang web đối với các scraper——mặc dù không phải luật pháp được thực thi, nhưng tuân thủ nó là nghi thức cơ bản của nhà phát triển scraper.

### Giải thích robots.txt

```
# https://example.com/robots.txt
User-agent: *        # Áp dụng cho tất cả các scraper
Disallow: /admin/    # Cấm scraping đường dẫn /admin/
Disallow: /private/  # Cấm scraping đường dẫn /private/
Allow: /public/      # Cho phép scraping đường dẫn /public/
Crawl-delay: 10      # Khuyến nghị khoảng cách 10 giây giữa các yêu cầu

User-agent: Googlebot  # Quy tắc dành riêng cho Google scraper
Allow: /               # Cho phép scraping tất cả nội dung

Sitemap: https://example.com/sitemap.xml  # Vị trí bản đồ trang web
```

### Phân tích robots.txt

```typescript
interface RobotRule {
  userAgent: string;
  allow: string[];
  disallow: string[];
  crawlDelay?: number;
}

async function parseRobotsTxt(domain: string): Promise<RobotRule[]> {
  const response = await fetch(`${domain}/robots.txt`);
  const text = await response.text();

  const rules: RobotRule[] = [];
  let currentRule: RobotRule | null = null;

  for (const line of text.split('\n')) {
    const trimmed = line.trim();
    if (trimmed.startsWith('#') || !trimmed) continue;

    const [key, ...valueParts] = trimmed.split(':');
    const value = valueParts.join(':').trim();

    switch (key.toLowerCase()) {
      case 'user-agent':
        if (currentRule) rules.push(currentRule);
        currentRule = { userAgent: value, allow: [], disallow: [] };
        break;
      case 'allow':
        currentRule?.allow.push(value);
        break;
      case 'disallow':
        currentRule?.disallow.push(value);
        break;
      case 'crawl-delay':
        if (currentRule) currentRule.crawlDelay = parseInt(value);
        break;
    }
  }

  if (currentRule) rules.push(currentRule);
  return rules;
}

function isPathAllowed(rules: RobotRule[], path: string, userAgent = '*'): boolean {
  const rule = rules.find(r => r.userAgent === userAgent) || rules.find(r => r.userAgent === '*');
  if (!rule) return true;

  for (const disallowed of rule.disallow) {
    if (path.startsWith(disallowed)) return false;
  }
  return true;
}
```

### Lưu ý về Điều khoản Dịch vụ

Ngoài robots.txt, bạn cần chú ý đến Điều khoản Dịch vụ (ToS) của trang web:

| Loại Điều khoản | Ví dụ | Mức độ Rủi ro |
|----------|------|----------|
| Cấm Truy cập Tự động | "Không được sử dụng công cụ tự động để truy cập trang web này" | Cao |
| Hạn chế Sử dụng Dữ liệu | "Không được sử dụng dữ liệu cho mục đích thương mại" | Cao |
| Hạn chế Tần suất | "Không quá 100 yêu cầu mỗi phút" | Trung bình |
| Tuyên bố Bản quyền | "Tất cả nội dung đều thuộc bản quyền của trang web này" | Cao |

### Nguyên tắc Thu thập Hợp pháp

1. **Tuân thủ robots.txt**: Đây là nghi thức cơ bản nhất
2. **Đọc Điều khoản Dịch vụ**: Hiểu các hạn chế cụ thể của trang web
3. **Kiểm soát Tần suất Yêu cầu**: Đừng tạo gánh nặng cho trang web
4. **Xác định Scraper của Bạn**: Đặt User-Agent hợp lý
5. **Tôn trọng Bản quyền**: Không sao chép nội dung được bảo vệ bản quyền

### Hướng dẫn Hợp tác với AI

- **Ý định cốt lõi**: Để AI giúp bạn hiểu và tuân thủ các quy tắc scraping.
- **Công thức định nghĩa yêu cầu**: `"Vui lòng giúp tôi phân tích tệp robots.txt này và xác định liệu tôi có thể scraping đường dẫn /products không."`
- **Các thuật ngữ chính**: `robots.txt`、`User-Agent`、`Disallow`、`Crawl-delay`

### Hướng dẫn Tránh Lỗi

- **robots.txt là thỏa thuận quân tử**: Về mặt kỹ thuật có thể bỏ qua, nhưng sẽ gây ra rủi ro pháp lý và đạo đức.
- **Các quy tắc User-Agent khác nhau**: Xác nhận danh tính scraper của bạn tuân theo quy tắc nào.
- **404 không có nghĩa là cho phép**: Robots.txt không tồn tại không có nghĩa là có thể scraping tùy tiện.
