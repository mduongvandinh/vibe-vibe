# 12.6.3 Trang web bảo vệ chống scraping——Cơ chế Chống Scraping: CAPTCHA/Chặn IP/User-Agent

### Một câu giải quyết vấn đề

Hiểu cơ chế chống scraping không phải để vượt qua chúng, mà để hiểu tại sao scraper của bạn lại thất bại, và cách thiết kế scraper sao cho không kích hoạt những cơ chế này.

### Cơ chế Chống Scraping Phổ biến

| Cơ chế | Nguyên lý | Điều kiện Kích hoạt |
|------|------|----------|
| Kiểm tra User-Agent | Kiểm tra request header để xác định scraper | Sử dụng UA mặc định hoặc đáng ngờ |
| Hạn chế Tần suất IP | Giới hạn số yêu cầu từ một IP | Nhiều yêu cầu trong thời gian ngắn |
| CAPTCHA | Yêu cầu xác minh thủ công | Hành vi bất thường hoặc yêu cầu thường xuyên |
| JavaScript Rendering | Nội dung được tạo động bởi JS | Không thể thực thi JS |
| Cookie/Session | Yêu cầu đăng nhập hoặc phiên hợp lệ | Thiếu Cookie cần thiết |
| Honeypot Links | Các liên kết bẫy ẩn | Scraper truy cập các liên kết mà con người không nhìn thấy |

### Đặt Các Request Header Hợp lý

```typescript
const headers = {
  'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
  'Accept': 'text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8',
  'Accept-Language': 'zh-CN,zh;q=0.9,en;q=0.8',
  'Accept-Encoding': 'gzip, deflate, br',
  'Connection': 'keep-alive',
  'Upgrade-Insecure-Requests': '1',
};

async function fetchAsHuman(url: string) {
  return fetch(url, { headers });
}
```

### Xử lý JavaScript Rendering

Nhiều trang web hiện đại sử dụng JavaScript để rendering nội dung động:

```typescript
// Sử dụng Playwright để xử lý JS rendering
import { chromium } from 'playwright';

async function fetchRenderedPage(url: string) {
  const browser = await chromium.launch();
  const page = await browser.newPage();

  await page.goto(url, { waitUntil: 'networkidle' });
  const content = await page.content();

  await browser.close();
  return content;
}
```

### Xử lý Cookie và Session

```typescript
import { CookieJar } from 'tough-cookie';

const jar = new CookieJar();

async function fetchWithCookies(url: string) {
  const cookies = await jar.getCookieString(url);

  const response = await fetch(url, {
    headers: { Cookie: cookies },
  });

  // Lưu Cookie mới
  const setCookie = response.headers.get('Set-Cookie');
  if (setCookie) {
    await jar.setCookie(setCookie, url);
  }

  return response;
}
```

### Kiểm tra Nếu Bạn Bị Chặn

```typescript
async function checkIfBlocked(url: string): Promise<boolean> {
  try {
    const response = await fetch(url);

    // Các dấu hiệu chặn phổ biến
    if (response.status === 403) return true;
    if (response.status === 429) return true;

    const text = await response.text();

    // Kiểm tra từ khóa trang chặn phổ biến
    const blockKeywords = [
      'access denied',
      'blocked',
      'captcha',
      'verify you are human',
      'unusual traffic',
    ];

    return blockKeywords.some(keyword =>
      text.toLowerCase().includes(keyword)
    );
  } catch {
    return true;
  }
}
```

### Hướng dẫn Hợp tác với AI

- **Ý định cốt lõi**: Để AI giúp bạn hiểu cơ chế chống scraping, chứ không phải để vượt qua chúng.
- **Công thức định nghĩa yêu cầu**: `"Vui lòng giải thích trang web này có thể sử dụng những cơ chế chống scraping nào, và tôi có thể điều chỉnh hành vi scraper của mình như thế nào để tránh kích hoạt chúng."`
- **Các thuật ngữ chính**: `User-Agent`、`IP blocking`、`CAPTCHA`、`JavaScript rendering`

### Hướng dẫn Tránh Lỗi

- **Đừng thử vượt qua chống scraping**: Điều này có thể bất hợp pháp và sẽ làm tổn thương mối quan hệ của bạn với trang web đích.
- **Giữ bình tĩnh khi bị chặn**: Tạm dừng scraping, kiểm tra xem hành vi của bạn có quá quyết liệt không.
- **Cân nhắc sử dụng API chính thức**: Nếu trang web có API, hãy ưu tiên sử dụng API.
