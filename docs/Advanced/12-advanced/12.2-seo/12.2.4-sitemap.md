# 12.2.4 Vẽ bản đồ cho Crawler——Sitemap：Tạo XML Sitemap và Gửi

### Giải quyết vấn đề một câu

Sitemap là một danh sách cho công cụ tìm kiếm biết "trang web tôi có những trang nào, trang nào quan trọng hơn, bao lâu cập nhật một lần", giúp crawler phát hiện và trích xuất nội dung của bạn hiệu quả hơn.

### Giá trị cốt lõi

Vai trò của sitemap đối với SEO：

1. **Tăng tốc độ lập chỉ mục**：Chủ động thông báo cho công cụ tìm kiếm về sự tồn tại của trang mới
2. **Hướng dẫn ưu tiên**：Cho biết crawler trang nào quan trọng hơn
3. **Tần suất cập nhật**：Giúp crawler quyết định bao lâu sẽ trở lại một lần
4. **Bao phủ các vùng mù**：Đảm bảo các "trang đơn lẻ" không có liên kết bên trong cũng được phát hiện

### Khôi phục bản chất：Cấu trúc Sitemap

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com/</loc>
    <lastmod>2024-01-15</lastmod>
    <changefreq>daily</changefreq>
    <priority>1.0</priority>
  </url>
  <url>
    <loc>https://example.com/blog/nextjs-tutorial</loc>
    <lastmod>2024-01-10</lastmod>
    <changefreq>weekly</changefreq>
    <priority>0.8</priority>
  </url>
</urlset>
```

| Trường | Ý nghĩa | Giá trị được đề xuất |
|------|------|--------|
| `loc` | URL trang (bắt buộc) | Sử dụng đường dẫn tuyệt đối |
| `lastmod` | Thời gian sửa đổi lần cuối | Định dạng ISO 8601 |
| `changefreq` | Tần suất cập nhật | always/hourly/daily/weekly/monthly/yearly/never |
| `priority` | Ưu tiên tương đối | 0.0-1.0, trang chủ thường là 1.0 |

### Tạo Sitemap trong Next.js

#### Phương pháp một：Sitemap tĩnh

```tsx
// app/sitemap.ts
import { MetadataRoute } from 'next';

export default function sitemap(): MetadataRoute.Sitemap {
  return [
    {
      url: 'https://example.com',
      lastModified: new Date(),
      changeFrequency: 'daily',
      priority: 1,
    },
    {
      url: 'https://example.com/about',
      lastModified: new Date(),
      changeFrequency: 'monthly',
      priority: 0.8,
    },
  ];
}
```

#### Phương pháp hai：Sitemap động

```tsx
// app/sitemap.ts
import { MetadataRoute } from 'next';
import { getAllPosts } from '@/lib/posts';

export default async function sitemap(): MetadataRoute.Sitemap {
  const posts = await getAllPosts();

  const postUrls = posts.map((post) => ({
    url: `https://example.com/blog/${post.slug}`,
    lastModified: new Date(post.updatedAt),
    changeFrequency: 'weekly' as const,
    priority: 0.7,
  }));

  return [
    {
      url: 'https://example.com',
      lastModified: new Date(),
      changeFrequency: 'daily',
      priority: 1,
    },
    ...postUrls,
  ];
}
```

Truy cập `/sitemap.xml` để xem sitemap được tạo.

### Trang web lớn：Sitemap Index

Khi số lượng trang vượt quá 50.000 hoặc kích thước tệp vượt quá 50MB, bạn cần sử dụng chỉ mục sitemap：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <sitemap>
    <loc>https://example.com/sitemap-posts.xml</loc>
    <lastmod>2024-01-15</lastmod>
  </sitemap>
  <sitemap>
    <loc>https://example.com/sitemap-products.xml</loc>
    <lastmod>2024-01-14</lastmod>
  </sitemap>
</sitemapindex>
```

### Gửi Sitemap

1. **Khai báo trong robots.txt**：
```txt
Sitemap: https://example.com/sitemap.xml
```

2. **Gửi qua công cụ webmaster**：
   - Google Search Console
   - Nền tảng Webmaster của Baidu
   - Bing Webmaster Tools

### Hướng dẫn hợp tác với AI

- **Ý định cốt lõi**：Cho phép AI giúp bạn tạo cấu hình sitemap hoặc giải quyết các vấn đề liên quan đến sitemap.
- **Công thức định nghĩa yêu cầu**：`"Vui lòng giúp tôi triển khai sitemap động trong Next.js, cần bao gồm tất cả các bài viết blog và trang sản phẩm, sử dụng thời gian cập nhật từ cơ sở dữ liệu làm lastmod."`
- **Thuật ngữ chính**：`sitemap.xml`、`MetadataRoute.Sitemap`、`Sitemap Index`、`lastmod`

### Hướng dẫn tránh sai lầm

- **Chỉ bao gồm các trang có thể lập chỉ mục**：Không đặt trang 404, trang sau khi đăng nhập vào sitemap.
- **Giữ lastmod chính xác**：Không đặt lastmod của tất cả các trang thành thời gian hiện tại, điều này sẽ giảm độ tin cậy của thông tin.
- **Cập nhật thường xuyên**：Sitemap nên cập nhật khi nội dung thay đổi.
- **Giám sát trạng thái trích xuất**：Kiểm tra xem sitemap có được đọc chính xác trong công cụ webmaster không.
