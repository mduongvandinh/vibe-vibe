# 10.5.4 Điểm nghẽn hiệu năng ở đâu — Phân tích hiệu năng: Giám sát thời gian phản hồi và sử dụng tài nguyên

Người dùng nói "chậm", bạn phải nói được chính xác chậm ở đâu.

## Chỉ số hiệu năng

### Chỉ số trải nghiệm người dùng

| Chỉ số | Giải thích | Giá trị mục tiêu |
|------|------|--------|
| TTFB | Thời gian byte đầu tiên | < 200ms |
| FCP | Lần vẽ nội dung đầu tiên | < 1.8s |
| LCP | Lần vẽ nội dung lớn nhất | < 2.5s |
| TTI | Thời gian có thể tương tác | < 3.8s |

### Chỉ số phía server

| Chỉ số | Giải thích | Giá trị mục tiêu |
|------|------|--------|
| Response time | Thời gian phản hồi API trung bình | < 200ms |
| P95 latency | Độ trễ tối đa 95% request | < 500ms |
| P99 latency | Độ trễ tối đa 99% request | < 1s |
| Throughput | Số request xử lý mỗi giây | Tùy business |

## Giám sát thời gian phản hồi

### Middleware đo thời gian request

```typescript
// NestJS middleware
@Injectable()
export class TimingMiddleware implements NestMiddleware {
  use(req: Request, res: Response, next: NextFunction) {
    const start = Date.now();

    res.on('finish', () => {
      const duration = Date.now() - start;

      console.log(JSON.stringify({
        level: 'info',
        event: 'request_completed',
        method: req.method,
        path: req.path,
        status: res.statusCode,
        duration,
        slow: duration > 1000,  // Đánh dấu request chậm
      }));

      // Cảnh báo request chậm
      if (duration > 3000) {
        this.alertSlowRequest(req.path, duration);
      }
    });

    next();
  }
}
```

### Giám sát query database

```typescript
// Prisma query log
const prisma = new PrismaClient({
  log: [
    { emit: 'event', level: 'query' },
  ],
});

prisma.$on('query', (e) => {
  if (e.duration > 100) {  // Ngưỡng slow query 100ms
    console.log(JSON.stringify({
      level: 'warn',
      event: 'slow_query',
      query: e.query,
      params: e.params,
      duration: e.duration,
    }));
  }
});
```

## Giám sát sử dụng tài nguyên

### Giám sát memory

```typescript
// Ghi định kỳ sử dụng memory
setInterval(() => {
  const usage = process.memoryUsage();

  console.log(JSON.stringify({
    level: 'info',
    event: 'memory_usage',
    heapUsed: Math.round(usage.heapUsed / 1024 / 1024),  // MB
    heapTotal: Math.round(usage.heapTotal / 1024 / 1024),
    rss: Math.round(usage.rss / 1024 / 1024),
  }));

  // Cảnh báo rò rỉ memory
  if (usage.heapUsed > 500 * 1024 * 1024) {  // > 500MB
    console.warn('High memory usage detected');
  }
}, 60000);  // Mỗi phút
```

### Giám sát CPU

```typescript
import * as os from 'os';

function getCpuUsage() {
  const cpus = os.cpus();
  let totalIdle = 0, totalTick = 0;

  cpus.forEach(cpu => {
    for (const type in cpu.times) {
      totalTick += cpu.times[type];
    }
    totalIdle += cpu.times.idle;
  });

  return 1 - totalIdle / totalTick;
}
```

## Vấn đề hiệu năng thường gặp

### Vấn đề N+1 query

```typescript
// Code có vấn đề - N+1 query
const users = await prisma.user.findMany();
for (const user of users) {
  const orders = await prisma.order.findMany({
    where: { userId: user.id }
  });
}

// Sau tối ưu - Dùng include
const users = await prisma.user.findMany({
  include: { orders: true }
});
```

### Rò rỉ memory

```typescript
// Code có vấn đề - Event listener leak
class Service {
  constructor() {
    eventEmitter.on('data', this.handleData);  // Mỗi lần khởi tạo đều thêm
  }
}

// Sau tối ưu - Dọn listener
class Service {
  constructor() {
    eventEmitter.on('data', this.handleData);
  }

  destroy() {
    eventEmitter.off('data', this.handleData);
  }
}
```

### Chặn đồng bộ

```typescript
// Code có vấn đề - Thao tác file đồng bộ
const data = fs.readFileSync('large-file.txt');

// Sau tối ưu - Thao tác bất đồng bộ
```

## Checklist tối ưu hiệu năng

### Tầng database

- [ ] Thêm index cần thiết
- [ ] Dùng `include` thay vì query nhiều lần
- [ ] Phân trang query tập dữ liệu lớn
- [ ] Dùng Redis cache dữ liệu hot

### Tầng ứng dụng

- [ ] Bật nén Gzip
- [ ] Dùng connection pool
- [ ] Tránh thao tác đồng bộ
- [ ] Tối ưu vòng lặp lớn

### Tầng network

- [ ] Dùng CDN
- [ ] Bật HTTP/2
- [ ] Thiết lập cache header hợp lý
- [ ] Nén hình ảnh/WebP

## Stress test

### Sử dụng k6

```javascript
// load-test.js
import http from 'k6/http';
import { check, sleep } from 'k6';

export const options = {
  vus: 100,         // 100 virtual user
  duration: '30s',  // Duy trì 30 giây
};

export default function() {
  const res = http.get('http://localhost:3000/api/health');

  check(res, {
    'status is 200': (r) => r.status === 200,
    'response time < 200ms': (r) => r.timings.duration < 200,
  });

  sleep(1);
}
```
