# 5.1.8 AI nào hiểu tôi nhất — Lựa chọn và ứng dụng model

### Ý chính trong một câu

Các model AI khác nhau có thế mạnh khác nhau, **chọn đúng công cụ quan trọng hơn nỗ lực**.

### So sánh các công cụ AI chủ đạo

| Công cụ | Thế mạnh | Tình huống áp dụng | Lưu ý |
|------|------|----------|----------|
| **Claude** | Hiểu văn bản dài, chất lượng code | Phân tích yêu cầu phức tạp, review code | Cửa sổ ngữ cảnh lớn |
| **GPT-4** | Khả năng tổng hợp cân bằng | Nhiệm vụ phát triển hàng ngày | Kiến thức rộng |
| **Cursor** | Tích hợp IDE, hoàn thiện code | Hỗ trợ code thời gian thực | Cần đăng ký |
| **GitHub Copilot** | Hoàn thiện code | Gợi ý thời gian thực khi viết code | Tích hợp tốt VS Code |

### Hướng dẫn chọn theo tình huống

#### Tình huống 1: Hiểu yêu cầu phức tạp

**Đề xuất**: Claude / GPT-4

```
Tình huống: Nhận một tài liệu yêu cầu sản phẩm 10 trang, cần trích xuất thông tin quan trọng

Cách làm:
1. Đưa tài liệu cho AI
2. Để nó tóm tắt điểm chức năng cốt lõi
3. Để nó nhận diện rủi ro kỹ thuật
4. Để nó sinh danh sách nhiệm vụ phát triển
```

#### Tình huống 2: Viết code thời gian thực

**Đề xuất**: Cursor / GitHub Copilot

```
Tình huống: Cần AI cung cấp gợi ý khi viết code

Cách làm:
1. Viết comment mô tả ý định
2. AI tự động hoàn thiện code
3. Tab chấp nhận hoặc sửa đổi
```

#### Tình huống 3: Debug và sửa lỗi

**Đề xuất**: Bất kỳ AI đối thoại nào

```
Tình huống: Gặp lỗi, cần hiểu nguyên nhân và phương án giải quyết

Cách làm:
1. Sao chép thông báo lỗi đầy đủ
2. Đính kèm đoạn code liên quan
3. Để AI giải thích và cung cấp phương án giải quyết
```

#### Tình huống 4: Review code

**Đề xuất**: Claude

```
Tình huống: Viết xong một chức năng, muốn AI giúp kiểm tra vấn đề

Cách làm:
1. Cung cấp code đầy đủ
2. Nói rõ chức năng mong đợi
3. Để AI review từ các góc độ bảo mật, hiệu năng, dễ đọc
```

### Lựa chọn phiên bản model

| Độ phức tạp nhiệm vụ | Model đề xuất | Lý do |
|------------|----------|------|
| Vấn đề đơn giản | GPT-3.5 / Claude Instant | Nhanh, rẻ |
| Phức tạp trung bình | GPT-4 / Claude 3 Sonnet | Cân bằng chi phí và chất lượng |
| Phức tạp cao | GPT-4 Turbo / Claude 3 Opus | Khả năng mạnh nhất |

### Gợi ý thực dụng

#### 1. Xây dựng quy trình làm việc cá nhân

```
Quy trình phát triển hàng ngày của tôi:
- Viết code: Cursor (Tab hoàn thiện)
- Vấn đề phức tạp: Claude (phân tích đối thoại)
- Tra cứu nhanh: GPT-4 (hỏi đáp tức thì)
```

#### 2. Đừng quá đuổi theo "mạnh nhất"

```
❌ Mọi vấn đề đều dùng model mạnh nhất

✅ Vấn đề đơn giản dùng model nhanh, vấn đề phức tạp mới dùng model mạnh
```

#### 3. Nhiều công cụ phối hợp sử dụng

```
Ví dụ sử dụng kết hợp:
1. [Cursor] Viết khung code
2. [Claude] Review chất lượng code
3. [GPT-4] Tối ưu hàm cụ thể
4. [Cursor] Tiếp tục phát triển
```

### Kiểm soát chi phí

| Chiến lược | Giải thích |
|------|------|
| **Sử dụng phân cấp** | Vấn đề đơn giản dùng model miễn phí/rẻ |
| **Xử lý hàng loạt** | Gộp nhiều vấn đề nhỏ thành một request |
| **Cache kết quả** | Ghi lại câu trả lời cho vấn đề thường gặp |
| **Tận dụng hạn mức miễn phí** | Các nền tảng đều có giới hạn sử dụng miễn phí |

### Cập nhật liên tục

Lĩnh vực AI phát triển rất nhanh, đề xuất:

1. **Theo dõi phát hành model mới**: Claude, GPT sẽ cập nhật định kỳ
2. **Thử công cụ mới**: Có thể có công cụ phù hợp hơn xuất hiện
3. **Tham gia cộng đồng**: Học hỏi best practice của người khác
