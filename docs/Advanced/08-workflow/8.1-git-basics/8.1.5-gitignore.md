# 8.1.5 File nào không nên bị theo dõi——Vai trò của .gitignore

Không phải tất cả file đều nên được Git theo dõi——khóa, gói phụ thuộc, sản phẩm build đều nên được loại trừ khỏi kiểm soát phiên bản.

## Tại sao cần .gitignore

Đưa file không nên commit vào kiểm soát phiên bản sẽ gây ra vấn đề nghiêm trọng:

| Loại vấn đề | Hậu quả |
|----------|------|
| Commit thông tin nhạy cảm | API key, mật khẩu bị rò rỉ, có thể dẫn đến sự cố bảo mật |
| Commit gói phụ thuộc | Kích thước repository tăng vọt, clone rất chậm |
| Commit sản phẩm build | Mỗi lần build tạo ra nhiều thay đổi vô nghĩa |
| Commit file hệ thống | `.DS_Store`, `Thumbs.db` làm ô nhiễm repository |

## Cú pháp cơ bản .gitignore

```gitignore
# Đây là comment

# Bỏ qua file đơn lẻ
.env

# Bỏ qua thư mục cụ thể
node_modules/
.next/

# Bỏ qua tất cả file .log
*.log

# Bỏ qua .DS_Store ở tất cả thư mục
**/.DS_Store

# Nhưng không bỏ qua important.log
!important.log

# Bỏ qua build ở thư mục gốc, nhưng không bỏ qua build của thư mục con
/build

# Bỏ qua tất cả file .txt trong thư mục doc
doc/**/*.txt
```

### Bảng tra cứu nhanh quy tắc cú pháp

| Pattern | Giải thích | Ví dụ |
|------|------|------|
| `*` | Khớp bất kỳ ký tự nào (không có /) | `*.log` |
| `**` | Khớp bất kỳ cấp thư mục nào | `**/node_modules` |
| `?` | Khớp một ký tự đơn | `?.txt` |
| `[]` | Khớp tập ký tự | `[abc].txt` |
| `/` đầu | Chỉ khớp thư mục gốc | `/build` |
| `/` cuối | Chỉ khớp thư mục | `logs/` |
| `!` | Phủ định (không bỏ qua) | `!important.log` |

## Xử lý vấn đề thường gặp

### File đã commit làm thế nào để xóa khỏi Git

```bash
# Xóa khỏi theo dõi Git, nhưng giữ file cục bộ
git rm --cached .env

# Xóa khỏi theo dõi Git toàn bộ thư mục
git rm -r --cached node_modules/

# Thêm vào .gitignore
echo ".env" >> .gitignore

# Commit thay đổi
git commit -m "chore: Xóa file nhạy cảm và cập nhật gitignore"
```

### Kiểm tra tại sao file bị bỏ qua

```bash
# Kiểm tra xem file nào đó có bị bỏ qua không
git check-ignore -v path/to/file

# Kiểm tra file nào đang được theo dõi
git ls-files
```

### .gitignore toàn cục

Đối với file mà tất cả dự án đều cần bỏ qua (như cấu hình IDE), có thể cài đặt cấu hình toàn cục:

```bash
# Tạo file gitignore toàn cục
touch ~/.gitignore_global

# Cấu hình Git sử dụng nó
git config --global core.excludesfile ~/.gitignore_global
```

Nội dung bỏ qua toàn cục thường gặp:

```gitignore
# macOS
.DS_Store
.AppleDouble
.LSOverride

# Windows
Thumbs.db
ehthumbs.db
Desktop.ini

# IDE
.idea/
.vscode/
*.sublime-project
*.sublime-workspace
```

## Tài nguyên template .gitignore

- **gitignore.io**: Tạo .gitignore theo loại dự án
- **GitHub gitignore repository**: Template các ngôn ngữ/framework do chính thức duy trì

```bash
# Sử dụng gitignore.io để tạo
curl -sL https://www.toptal.com/developers/gitignore/api/node,nextjs > .gitignore
```
