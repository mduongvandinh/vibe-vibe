# 8.4.3 Rác máy tính và cấu hình trình soạn thảo—Tệp hệ thống và IDE

Mỗi máy tính và trình soạn thảo của mọi người đều khác nhau—những "sở thích cá nhân" này không nên làm ô nhiễm kho lưu trữ mã.

## Tệp hệ điều hành

### macOS

```gitignore
# Siêu dữ liệu thư mục macOS
.DS_Store
.AppleDouble
.LSOverride

# Tệp biểu tượng
Icon?

# Thùng rác
.Trashes

# Chỉ mục Spotlight
.Spotlight-V100
```

### Windows

```gitignore
# Bộ nhớ đệm hình thu nhỏ
Thumbs.db
ehthumbs.db
ehthumbs_vista.db

# Cấu hình màn hình nền
Desktop.ini

# Lối tắt
*.lnk

# Thùng tái chế
$RECYCLE.BIN/
```

### Linux

```gitignore
# Tệp sao lưu
*~

# Tệp tạm thời
.fuse_hidden*
.nfs*
```

## Cấu hình IDE

### VS Code

```gitignore
# Cài đặt người dùng (sở thích cá nhân)
.vscode/settings.json

# Cấu hình không gian làm việc
.vscode/*.code-workspace

# Lịch sử
.history/

# Nhưng có thể cần giữ những cấu hình chia sẻ này:
# !.vscode/extensions.json      # Tiện ích mở rộng được đề xuất
# !.vscode/launch.json          # Cấu hình gỡ lỗi
# !.vscode/tasks.json           # Cấu hình tác vụ
```

### JetBrains (WebStorm/IntelliJ)

```gitignore
# Cấu hình dự án IntelliJ IDEA
.idea/

# Nhưng có thể giữ phong cách mã:
# !.idea/codeStyles/
# !.idea/inspectionProfiles/
```

### Vim/Neovim

```gitignore
# Tệp trao đổi
*.swp
*.swo
*~

# Tệp phiên bản
Session.vim
Sessionx.vim
```

### Emacs

```gitignore
# Sao lưu
*~
\#*\#
.#*

# Tự động lưu
.saves-*
```

## gitignore toàn cục

Thay vì cấu hình tệp hệ thống ở mỗi dự án, hãy đặt bỏ qua toàn cục:

### Phương pháp cấu hình

```bash
# 1. Tạo tệp gitignore toàn cục
touch ~/.gitignore_global

# 2. Yêu cầu Git sử dụng tệp này
git config --global core.excludesFile ~/.gitignore_global
```

### Cấu hình toàn cục được khuyến nghị

```gitignore
# ~/.gitignore_global

# macOS
.DS_Store
.AppleDouble

# Windows
Thumbs.db
Desktop.ini

# Trình soạn thảo
*.swp
*.swo
*~
.idea/
.vscode/settings.json

# Ghi chú cá nhân
TODO.md
NOTES.md
```

## Cấu hình chia sẻ dự án

Một số cấu hình IDE có thể cần chia sẻ với đội:

### Tiện ích mở rộng được đề xuất (.vscode/extensions.json)

```json
{
  "recommendations": [
    "dbaeumer.vscode-eslint",
    "esbenp.prettier-vscode",
    "prisma.prisma"
  ]
}
```

### Cấu hình gỡ lỗi (.vscode/launch.json)

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Next.js: debug",
      "runtimeExecutable": "pnpm",
      "runtimeArgs": ["dev"],
      "port": 9229
    }
  ]
}
```

## Chiến lược cấu hình

| Tệp | Khuyến nghị | Lý do |
|------|------|------|
| .vscode/settings.json | Bỏ qua | Sở thích cá nhân |
| .vscode/extensions.json | Cam kết | Thống nhất môi trường phát triển |
| .vscode/launch.json | Cam kết | Chia sẻ cấu hình gỡ lỗi |
| .idea/ | Bỏ qua | IDE cụ thể |
| .editorconfig | Cam kết | Định dạng chéo IDE |

## Giải pháp thay thế EditorConfig

Sử dụng `.editorconfig` có thể thống nhất định dạng cơ bản giữa các IDE:

```ini
# .editorconfig
root = true

[*]
charset = utf-8
end_of_line = lf
indent_style = space
indent_size = 2
insert_final_newline = true
trim_trailing_whitespace = true

[*.md]
trim_trailing_whitespace = false
```
