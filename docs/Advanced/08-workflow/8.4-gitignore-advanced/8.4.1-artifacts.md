# 8.4.1 Mục tiêu đầu tiên của danh sách đen—Phụ thuộc và sản phẩm xây dựng

node_modules là mục tiêu hàng đầu của .gitignore—nó quá lớn, có thể xây dựng lại, và có thể khác nhau trên mỗi máy tính.

## Thư mục phụ thuộc

### node_modules

```gitignore
# node_modules ở bất kỳ vị trí nào
**/node_modules/

# Lưu trữ pnpm (nếu sử dụng)
.pnpm-store/
```

**Tại sao không cam kết**:
- Kích thước khổng lồ (từ vài trăm MB đến vài GB)
- Có thể khôi phục hoàn toàn qua `pnpm install`
- Tệp nhị phân liên quan đến nền tảng có thể khác trên các hệ thống khác nhau

**Cách làm đúng**:
- Cam kết `package.json` và `pnpm-lock.yaml`
- Sử dụng tệp khóa để đảm bảo phiên bản phụ thuộc nhất quán

### Các thư mục phụ thuộc khác

## Xử lý tệp đã cam kết

Nếu vô tình cam kết node_modules:

```bash
# 1. Thêm vào .gitignore
echo "node_modules/" >> .gitignore

# 2. Loại bỏ khỏi lịch sử Git (nhưng giữ tệp cục bộ)
git rm -r --cached node_modules/

# 3. Cam kết những thay đổi
git commit -m "chore: xóa node_modules và thêm vào gitignore"

# 4. Nếu đã đẩy, cần đẩy mạnh (sử dụng cẩn thận)
git push --force-with-lease
```
