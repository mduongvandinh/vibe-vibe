# 4.2.2 Tạo trang tĩnh

> **Mục tiêu bước này**: Gửi Prompt cho AI, nhận được trang tĩnh phiên bản đầu tiên

## Gửi Prompt

Bây giờ, gửi Prompt bạn đã chuẩn bị ở bước trước cho AI IDE.

Còn nhớ bố cục giao diện được giới thiệu ở mục 4.1.2 không? Tìm **vùng hội thoại**, dán Prompt vào đó, nhấn Enter để gửi.

Vị trí vùng hội thoại của các AI IDE khác nhau có thể hơi khác, nhưng đều rất dễ tìm:

- Thường ở dưới cùng giao diện hoặc thanh bên
- Có thể được ghi chú là "Chat", "AI", "Composer", "Cascade" v.v.
- Một số công cụ có thể dùng phím tắt để mở (như `Cmd/Ctrl + L` của Cursor)

::: tip Không tìm thấy vùng hội thoại?
Xem lại phần giải thích bố cục giao diện trong [4.1.2 Chuẩn bị AI IDE của bạn](../4.1-before-start/4.1.2-prepare-ai-ide.md). Nếu công cụ bạn dùng không có trong danh sách thường gặp, có thể xem [1.4.1 Toàn cảnh công cụ lập trình AI](../../01-awakening/1.4-tools-guide/1.4.1-env-setup.md) để biết thêm thông tin công cụ.
:::

Sau khi gửi, chờ AI tạo code. Thường mất 10-30 giây.

## Bạn sẽ thấy gì

Sau khi AI tạo xong, bạn sẽ thấy một trang danh sách công việc, bao gồm cấu trúc sau:

```
┌─────────────────────────────────────┐
│                                     │
│        Danh sách công việc của tôi  │  ← Vùng tiêu đề
│                                     │
├─────────────────────────────────────┤
│  ┌─────────────────────┐ ┌────┐    │
│  │ Nhập nhiệm vụ mới... │ │Thêm│    │  ← Vùng nhập
│  └─────────────────────┘ └────┘    │
├─────────────────────────────────────┤
│                                     │
│  □ Hoàn thành báo cáo dự án [✓] [X] │  ← Vùng danh sách
│  □ Mua sữa                  [✓] [X] │    (dữ liệu giả)
│  □ Gọi cho mẹ               [✓] [X] │
│                                     │
└─────────────────────────────────────┘
```

Kiểm tra cụ thể các phần tử sau có tồn tại không:

- [ ] Trang có tiêu đề "Danh sách công việc của tôi"
- [ ] Có một ô nhập
- [ ] Có một nút "Thêm"
- [ ] Có danh sách nhiệm vụ, hiển thị vài dữ liệu giả
- [ ] Mỗi nhiệm vụ có nút "Hoàn thành" và "Xóa"
- [ ] Bố cục tổng thể canh giữa, trông khá gọn gàng

## Năm tình huống có thể xảy ra và cách xử lý

Kết quả tạo ra lần đầu tiên có thể khác nhau. Tùy theo tình huống bạn thấy, chọn cách xử lý tương ứng:

### Tình huống 1: Hoàn hảo đúng như mong đợi

**Hiện tượng**: Bố cục trang, style, phần tử đều đúng như mong đợi.

**Xử lý**: Tuyệt vời! Chuyển thẳng đến [4.2.4 Kiểm tra thành quả giai đoạn](./4.2.4-checkpoint.md).

### Tình huống 2: Cấu trúc đúng nhưng style không hài lòng

**Hiện tượng**: Tất cả phần tử đều có, nhưng màu quá tối, nút quá nhỏ, khoảng cách không đủ v.v.

**Xử lý**: Tiến vào [4.2.3 Điều chỉnh style và bố cục](./4.2.3-adjust-style.md), dùng hội thoại lặp để điều chỉnh.

### Tình huống 3: Thiếu một số phần tử

**Hiện tượng**: Ví dụ không có nút "Hoàn thành", hoặc không có dữ liệu giả.

**Xử lý**: Gửi thêm giải thích:

```
Trang nhìn chung không tệ, hãy bổ sung nội dung sau:
- Mỗi nhiệm vụ cần có nút "Hoàn thành" và nút "Xóa"
- Danh sách nhiệm vụ dùng trước 3 dữ liệu giả để hiển thị style
```

### Tình huống 4: Trang trắng

**Hiện tượng**: Trình duyệt hiển thị trang trắng, không có gì cả.

**Xử lý**: Thường là vấn đề lưu file hoặc preview, kiểm tra theo thứ tự sau:

1. **Xác nhận file đã lưu**: Trong AI IDE nhấn `Ctrl+S` (Mac dùng `Cmd+S`)
2. **Làm mới preview**: Nhấn `Ctrl+Shift+R` (Mac dùng `Cmd+Shift+R`) để làm mới cưỡng chế
3. **Kiểm tra vị trí file**: Xác nhận file HTML được lưu ở vị trí đúng
4. **Xem console**: Nhấn `F12` mở công cụ developer, xem có lỗi màu đỏ không

Nếu tất cả các cách trên không được, nhờ AI giúp kiểm tra:

```
Trang hiển thị trắng, hãy giúp tôi kiểm tra code có vấn đề không.
Nếu có vấn đề, hãy sửa và cho tôi code hoàn chỉnh đúng.
```

### Tình huống 5: Code báo lỗi

**Hiện tượng**: Console trình duyệt hiển thị thông tin lỗi màu đỏ.

**Xử lý**: Chuyển đến [4.5.2 Dùng AI giúp bạn sửa code của AI](../4.5-debug/4.5.2-fix-with-ai.md), học cách để AI giúp bạn sửa.

## Hiểu cấu trúc code do AI tạo ra

Bạn không cần hiểu hoàn toàn code, nhưng nắm được cấu trúc đại khái sẽ giúp bạn điều chỉnh sau này. File HTML do AI tạo ra thường như thế này:

```html
<!DOCTYPE html>
<html>
<head>
    <!-- Tiêu đề trang và cài đặt -->
    <title>Danh sách công việc của tôi</title>
    <style>
        /*
         * Đây là code CSS style
         * Điều khiển màu sắc, kích thước, bố cục của trang
         */
    </style>
</head>
<body>
    <!-- Đây là nội dung trang -->

    <div class="container">
        <!-- Tiêu đề -->
        <h1>Danh sách công việc của tôi</h1>

        <!-- Vùng nhập -->
        <div class="input-area">
            <input type="text" placeholder="Nhập nhiệm vụ mới...">
            <button>Thêm</button>
        </div>

        <!-- Danh sách nhiệm vụ -->
        <ul class="task-list">
            <li>
                <span>Hoàn thành báo cáo dự án</span>
                <button>Hoàn thành</button>
                <button>Xóa</button>
            </li>
            <!-- Nhiệm vụ khác... -->
        </ul>
    </div>
</body>
</html>
```

Hiểu đơn giản:

| Phần code | Tác dụng |
|---------|------|
| `<head>...</head>` | "Cài đặt hậu trường" của trang, bao gồm tiêu đề và style |
| `<style>...</style>` | CSS style, điều khiển vẻ ngoài |
| `<body>...</body>` | "Nội dung chính" của trang, phần người dùng nhìn thấy |
| `<div>` | Một container, dùng để nhóm và bố cục |
| `<input>` | Ô nhập |
| `<button>` | Nút |
| `<ul>` và `<li>` | Danh sách và mục danh sách |

::: info Không cần nhớ những điều này
Đây chỉ giúp bạn hiểu cấu trúc code. Trong Vibe Coding, bạn không cần tự viết code này - chỉ cần nói cho AI biết bạn muốn gì, nó sẽ giúp bạn viết.
:::

## Nhấn nút không phản hồi?

Nếu bạn thử nhấn nút "Thêm", phát hiện không có gì xảy ra - đây là **hoàn toàn bình thường**.

Trang hiện tại chỉ là một "vỏ", chưa có code chức năng. Giống như mô hình xe, trông giống xe, nhưng chưa chạy được.

Ở mục 4.3, chúng ta sẽ làm cho các nút này "sống" lại.

## Tra cứu nhanh vấn đề thường gặp

| Vấn đề | Nguyên nhân có thể | Cách giải quyết |
|-----|---------|---------|
| Trang hoàn toàn trắng | File chưa lưu hoặc preview không đúng | Lưu file, làm mới trình duyệt |
| Style trông rất xấu | Style mặc định của AI không đúng với thẩm mỹ của bạn | Tiến vào 4.2.3 điều chỉnh |
| Chỉ có chữ không có style | CSS chưa được nhúng đúng | Yêu cầu AI kiểm tra cấu trúc code |
| Trang hiển thị bất thường trên điện thoại | Thiếu cài đặt responsive | Yêu cầu AI thêm style responsive |
| Nhấn nút không phản hồi | Bình thường! Trang tĩnh không có chức năng | Mục 4.3 sẽ thêm chức năng |

## Điểm kiểm tra bước này

Trước khi tiếp tục, xác nhận:

- [ ] AI đã tạo code
- [ ] Có thể thấy trang trong trình duyệt
- [ ] Trang bao gồm tiêu đề, ô nhập, nút, danh sách nhiệm vụ

Nếu style không hài lòng, tiến vào bước tiếp theo điều chỉnh. Nếu đã hài lòng, có thể chuyển thẳng đến [4.2.4 Kiểm tra thành quả giai đoạn](./4.2.4-checkpoint.md).
