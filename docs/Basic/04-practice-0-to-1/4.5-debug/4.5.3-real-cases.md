# 4.5.3 Phân tích lại các trường hợp thực tế

## Trường hợp 1: Danh sách nhiệm vụ là undefined

### Hiện tượng lỗi

Sau khi nhấp vào nút thêm, nhiệm vụ không xuất hiện. Bảy điều khiển hiển thị thông báo lỗi màu đỏ.

### Thông báo lỗi từ bảy điều khiển

```
Uncaught TypeError: Cannot read properties of undefined (reading 'push')
    at addTask (index.html:45:15)
    at HTMLButtonElement.<anonymous> (index.html:52:5)
```

### Định vị vấn đề

Lỗi này có nghĩa là: mã cố gắng gọi phương thức `push` trên `undefined`. `push` là phương thức của mảng, có nghĩa là mã dự kiến đây là một mảng, nhưng thực tế nó là `undefined`.

Xem mã dòng 45:

```javascript
tasks.push({ text: taskText, completed: false });
```

Vấn đề nằm ở biến `tasks` — nó chưa được khởi tạo đúng.

### Cuộc hội thoại chẩn đoán

**Prompt bạn gửi**:
```
Mã danh sách việc cần làm của tôi báo lỗi:

【Hiện tượng】Sau khi nhấp vào nút thêm, nhiệm vụ không xuất hiện
【Thông báo lỗi】Uncaught TypeError: Cannot read properties of undefined (reading 'push')
    at addTask (index.html:45:15)

【Mã】
function addTask() {
    const input = document.querySelector('.task-input');
    const taskText = input.value.trim();
    if (taskText) {
        tasks.push({ text: taskText, completed: false });
        renderTasks();
        input.value = '';
    }
}

Vui lòng giúp tôi phân tích nguyên nhân.
```

**Phân tích của AI**:
> Lỗi này cho thấy biến `tasks` là `undefined` khi gọi `push`. Nguyên nhân vấn đề là `tasks` không được khởi tạo thành một mảng trước khi sử dụng. Bạn cần khai báo `let tasks = [];` ở đầu mã.

### Cuộc hội thoại sửa chữa

**Prompt bạn gửi**:
```
Vui lòng giúp tôi sửa. Cần:
1. Khởi tạo biến tasks ở đầu mã
2. Cung cấp mã đã sửa hoàn chỉnh
```

**Mã sửa chữa AI cung cấp** (phần chính):

```javascript
// Thêm dòng này ở đầu mã
let tasks = [];  // Khởi tạo mảng nhiệm vụ

function addTask() {
    const input = document.querySelector('.task-input');
    const taskText = input.value.trim();
    if (taskText) {
        tasks.push({ text: taskText, completed: false });
        renderTasks();
        input.value = '';
    }
}
```

### Cách xác minh

1. Thay thế mã và làm mới trang
2. Nhập nhiệm vụ vào hộp nhập, nhấp vào thêm
3. Xác nhận nhiệm vụ xuất hiện trong danh sách
4. Xác nhận bảy điều khiển không có thông báo lỗi màu đỏ

## Trường hợp 2: Hàm chưa được định nghĩa

### Hiện tượng lỗi

Sau khi trang tải, bảy điều khiển ngay lập tức hiển thị thông báo lỗi.

### Thông báo lỗi từ bảy điều khiển

```
Uncaught ReferenceError: addTask is not defined
    at HTMLButtonElement.onclick (index.html:15:42)
```

### Định vị vấn đề

`ReferenceError: xxx is not defined` cho thấy mã sử dụng một biến hoặc hàm không tồn tại.

Nguyên nhân thường gặp:
- Tên hàm bị viết sai
- Hàm được định nghĩa sau khi được gọi (vấn đề thứ tự mã)
- Hàm được viết ở vị trí sai

### Cuộc hội thoại chẩn đoán

**Prompt bạn gửi**:
```
Trang tải sẽ báo lỗi: ReferenceError: addTask is not defined

Tôi có nút này trong HTML:
<button onclick="addTask()">Thêm</button>

Tôi có hàm này trong JavaScript:
function addtask() {
    // ... nội dung hàm
}

Vui lòng giúp tôi phân tích nguyên nhân.
```

**Phân tích của AI**:
> Vấn đề nằm ở sự không nhất quán của tên hàm. HTML gọi `addTask()` (T in hoa), nhưng JavaScript định nghĩa `addtask()` (t in thường). JavaScript phân biệt chữ hoa chữ thường, vì vậy hai cái này được coi là các hàm khác nhau.

### Cách sửa chữa

Thay đổi tên hàm trong JavaScript thành `addTask` (khớp với HTML):

```javascript
// Trước khi sửa
function addtask() {

// Sau khi sửa
function addTask() {
```

### Cách xác minh

1. Thay thế mã và làm mới trang
2. Xác nhận bảy điều khiển không có `ReferenceError`
3. Nhấp vào nút thêm, xác nhận chức năng hoạt động bình thường

## Trường hợp 3: localStorage phân tích thất bại

### Hiện tượng lỗi

Trang báo lỗi khi tải, các nhiệm vụ đã lưu trước đó không thể hiển thị.

### Thông báo lỗi từ bảy điều khiển

```
Uncaught SyntaxError: Unexpected token 'u', "undefined" is not valid JSON
    at JSON.parse (<anonymous>)
    at loadTasks (index.html:68:24)
```

### Định vị vấn đề

Lỗi này xảy ra khi `JSON.parse()`. Thông báo lỗi `"undefined" is not valid JSON` có nghĩa là cố gắng phân tích nội dung là chuỗi `"undefined"` chứ không phải JSON hợp lệ.

Nguyên nhân thường gặp:
- Khi không có dữ liệu, `getItem` trả về `null`
- Mã không xử lý trường hợp `null`, gửi trực tiếp tới `JSON.parse`

### Cuộc hội thoại chẩn đoán

**Prompt bạn gửi**:
```
localStorage báo lỗi: SyntaxError: Unexpected token 'u', "undefined" is not valid JSON

Mã đọc của tôi:
function loadTasks() {
    const saved = localStorage.getItem('todoList');
    tasks = JSON.parse(saved);
    renderTasks();
}

Vui lòng giúp tôi phân tích.
```

**Phân tích của AI**:
> Khi localStorage không có khóa 'todoList', `getItem` trả về `null`. `JSON.parse(null)` sẽ cố gắng phân tích, nhưng trong một số trường hợp có thể gây ra vấn đề. Phổ biến hơn là nếu `undefined` chuỗi được lưu trước đó bị lưu trữ, lỗi này sẽ xuất hiện. Bạn cần kiểm tra xem dữ liệu có tồn tại trước khi phân tích.

### Cuộc hội thoại sửa chữa

**Prompt bạn gửi**:
```
Vui lòng giúp tôi sửa hàm loadTasks, đảm bảo:
1. Nếu localStorage không có dữ liệu, hãy sử dụng mảng trống
2. Nếu định dạng dữ liệu không đúng, cũng hãy sử dụng mảng trống
3. Cung cấp mã sửa chữa đầy đủ
```

**Mã sửa chữa AI cung cấp**:

```javascript
function loadTasks() {
    const saved = localStorage.getItem('todoList');

    // Kiểm tra xem có dữ liệu được lưu không
    if (saved && saved !== 'undefined') {
        try {
            tasks = JSON.parse(saved);
        } catch (e) {
            // Nếu phân tích thất bại, hãy sử dụng mảy trống
            console.log('Định dạng dữ liệu lỗi, đã đặt lại');
            tasks = [];
        }
    } else {
        // Không có dữ liệu được lưu, hãy sử dụng mảy trống
        tasks = [];
    }

    renderTasks();
}
```

### Cách xác minh

1. Thay thế mã và làm mới trang
2. Xác nhận bảy điều khiển không báo lỗi
3. Thêm vài nhiệm vụ, làm mới trang, xác nhận nhiệm vụ vẫn ở đó

## Trường hợp 4: Nhấp vào nút không có phản ứng

### Hiện tượng lỗi

Nhấp vào nút thêm không có bất kỳ phản ứng nào. Bảy điều khiển cũng không báo lỗi.

### Định vị vấn đề

Đây là lỗi logic điển hình — cú pháp mã đúng, nhưng hành vi không khớp với dự kiến.

Nguyên nhân có thể:
- Trình lắng nghe sự kiện không được liên kết chính xác
- Bộ chọn nút bị viết sai
- Vấn đề thứ tự mã (được thực thi trước khi DOM tải)

### Cuộc hội thoại chẩn đoán

**Prompt bạn gửi**:
```
Nút thêm của tôi nhấp vào không có phản ứng, bảy điều khiển cũng không báo lỗi.

Nút trong HTML:
<button class="add-btn">Thêm</button>

Liên kết trong JavaScript:
const addBtn = document.querySelector('.add-button');
addBtn.addEventListener('click', addTask);

Vui lòng giúp tôi kiểm tra vấn đề.
```

**Phân tích của AI**:
> Vấn đề nằm ở chỗ bộ chọn CSS không khớp. Nút trong HTML có class là `add-btn`, nhưng JavaScript tìm kiếm `.add-button`. Vì không tìm thấy phần tử, `addBtn` là `null`, lệnh gọi `addEventListener` tiếp theo thất bại (mặc dù đôi khi không báo lỗi).

### Cách sửa chữa

Thống nhất tên bộ chọn:

```javascript
// Trước khi sửa (bộ chọn không khớp)
const addBtn = document.querySelector('.add-button');

// Sau khi sửa (khớp với HTML)
const addBtn = document.querySelector('.add-btn');
```

### Cách xác minh

1. Thay thế mã và làm mới trang
2. Nhấp vào nút thêm, xác nhận chức năng hoạt động bình thường

## Trường hợp 5: Kiểu biến mất

### Hiện tượng lỗi

Sau khi để AI thêm chức năng mới, toàn bộ kiểu của trang biến mất, chỉ còn văn bản thuần.

### Định vị vấn đề

Điều này thường xảy ra khi AI sửa mã, không cẩn thận xóa hoặc làm hỏng phần CSS.

Nguyên nhân thường gặp:
- AI chỉ trả về phần JavaScript, bạn thay thế cả tệp
- Mã CSS có lỗi cú pháp
- Thẻ `<style>` bị xóa nhầm

### Cuộc hội thoại chẩn đoán

**Prompt bạn gửi**:
```
Sau khi bạn thêm chức năng xóa, kiểu của trang hoàn toàn biến mất.
Bây giờ trang chỉ hiển thị văn bản thuần, không có bất kỳ kiểu nào.

Vui lòng giúp tôi kiểm tra:
1. Thẻ <style> có hoàn chỉnh không
2. Cú pháp CSS có lỗi không
3. Nếu kiểu bị mất, vui lòng giúp tôi khôi phục

Đây là tệp HTML đầy đủ của tôi hiện tại:
[Dán mã đầy đủ]
```

**Phân tích của AI**:
> Tôi tìm thấy vấn đề. Trong sửa chữa trước đó, thẻ `<style>` bị xóa nhầm. Tôi sẽ giúp bạn khôi phục mã kiểu đầy đủ.

### Cách sửa chữa

Để AI tạo lại mã có kiểu hoàn chỉnh, hoặc khôi phục phần CSS từ phiên bản trước.

### Biện pháp phòng ngừa

- Trước mỗi lần để AI sửa mã, hãy sao lưu phiên bản hiện tại
- Nói rõ cho AI: "Chỉ sửa phần JavaScript, đừng thay đổi HTML và CSS"
- Nhận mã từ AI, kiểm tra cấu trúc có hoàn chỉnh rồi mới thay thế

## Trường hợp 6: Trạng thái hoàn thành không thể lưu

### Hiện tượng lỗi

Sau khi đánh dấu nhiệm vụ là "đã hoàn thành", làm mới trang, nhiệm vụ khôi phục thành trạng thái "chưa hoàn thành".

### Định vị vấn đề

Đây là lỗi logic của tính bền vững dữ liệu — thay đổi trạng thái hoàn thành không kích hoạt thao tác lưu.

### Cuộc hội thoại chẩn đoán

**Prompt bạn gửi**:
```
Trạng thái hoàn thành của nhiệm vụ không thể lưu.

【Các bước để tái tạo lỗi】
1. Thêm một nhiệm vụ
2. Nhấp vào nút hoàn thành, nhiệm vụ hiển thị là đã hoàn thành
3. Làm mới trang
4. Nhiệm vụ khôi phục thành trạng thái chưa hoàn thành

【Hiện tượng】
Các thao tác thêm và xóa có thể lưu, nhưng trạng thái hoàn thành không thể

【Mã liên quan】
function toggleComplete(index) {
    tasks[index].completed = !tasks[index].completed;
    renderTasks();
}

function saveTasks() {
    localStorage.setItem('todoList', JSON.stringify(tasks));
}

Vui lòng giúp tôi phân tích nguyên nhân.
```

**Phân tích của AI**:
> Hàm `toggleComplete` sửa đổi trạng thái nhiệm vụ và hiển thị lại, nhưng không gọi `saveTasks()` để lưu vào localStorage. Các chức năng thêm và xóa có thể lưu, có thể là vì chúng gọi `saveTasks()` trong hàm, nhưng `toggleComplete` bỏ sót.

### Cuộc hội thoại sửa chữa

**Prompt bạn gửi**:
```
Vui lòng giúp tôi sửa, thêm thao tác lưu vào hàm toggleComplete.
```

**Mã sửa chữa AI cung cấp**:

```javascript
function toggleComplete(index) {
    tasks[index].completed = !tasks[index].completed;
    saveTasks();  // Thêm dòng này: lưu vào localStorage
    renderTasks();
}
```

### Cách xác minh

1. Thay thế mã và làm mới trang
2. Thêm một nhiệm vụ
3. Nhấp vào nút hoàn thành
4. Làm mới trang
5. Xác nhận nhiệm vụ vẫn hiển thị là đã hoàn thành

## Các điểm chính của phần này

- Mỗi trường hợp tuân theo quy trình "hiện tượng → thông báo lỗi → định vị → sửa chữa → xác minh"
- TypeError thường là do biến chưa được định nghĩa hoặc loại không đúng
- ReferenceError thường là do lỗi chính tả hoặc vấn đề phạm vi
- SyntaxError trong JSON.parse thường là do dữ liệu trống hoặc định dạng sai
- Lỗi logic không có thông báo lỗi, cần so sánh "hành vi dự kiến" và "hành vi thực tế"
- Lỗi kiểu cần kiểm tra xem mã CSS có hoàn chỉnh không

Sau khi nắm vững những trường hợp này, bạn có thể giải quyết hầu hết các vấn đề khi phát triển danh sách việc cần làm.
