# 4.1.2 Chuẩn bị AI IDE của bạn

> **Mục tiêu của tiểu mục này**: Dùng 5 phút để xác nhận AI IDE của bạn đã sẵn sàng

## Xác nhận công cụ đã được cài đặt

Nếu bạn học theo Chương 1, bạn đã nên chọn và cài đặt một AI IDE.

Chưa cài đặt? Vui lòng xem lại [1.4 Hướng dẫn lựa chọn công cụ](../../01-awakening/1.4-tools-guide/), hoàn thành cài đặt rồi tiếp tục.

::: warning Quan trọng
Chương này sử dụng AI IDE được cài đặt trên máy cục bộ để phát triển. Vui lòng đảm bảo bạn đã cài đặt công cụ trên máy tính của mình.
:::

## Làm quen với bố cục giao diện AI IDE

Bất kể bạn sử dụng AI IDE nào, chúng đều có cấu trúc giao diện tương tự:

```
┌────────────────────────────────────────────────────────────┐
│                     Bố cục chung AI IDE                     │
├──────────────┬─────────────────────┬───────────────────────┤
│              │                     │                       │
│   Vùng file  │      Vùng code      │      Vùng preview     │
│ (File dự án) │   (Code do AI tạo)  │   (Hiệu quả trực tiếp)│
│              │                     │                       │
├──────────────┴─────────────────────┴───────────────────────┤
│                       Vùng hội thoại                        │
│              (Nơi bạn nhập Prompt)                          │
└────────────────────────────────────────────────────────────┘
```

### Vùng hội thoại: Nơi bạn giao tiếp với AI

Đây là khu vực quan trọng nhất. Bạn nhập Prompt (còn gọi là chỉ thị, mô tả yêu cầu) ở đây, AI sẽ hiểu ý định của bạn và tạo code.

**Tìm nó**: Thường ở dưới cùng hoặc bên cạnh giao diện, có một ô nhập liệu, có thể được ghi chú là "Ask AI", "Chat", "Composer" v.v.

### Vùng code: Nơi AI tạo code

Code do AI tạo ra sẽ hiển thị ở đây. Bạn thường không cần chỉnh sửa trực tiếp những code này, nhưng có thể xem.

**Tìm nó**: Thường ở giữa giao diện, hiển thị nội dung file như `index.html`, `app.js`.

### Vùng file: Nơi quản lý file dự án

Đây hiển thị tất cả các file và thư mục trong dự án. Khi phát triển tiến triển, bạn sẽ thấy ngày càng nhiều file xuất hiện ở đây.

**Tìm nó**: Thường ở bên trái giao diện, là một danh sách file dạng cây.

### Vùng preview: Nơi xem hiệu quả

Đây là khu vực mang lại cảm giác thành tựu nhất. Trang web của bạn sẽ hiển thị trực tiếp ở đây.

**Tìm nó**: Thường ở bên phải giao diện, có thể cần nhấn nút "Preview", "Run" hoặc tương tự mới xuất hiện. Một số AI IDE cũng hỗ trợ mở preview trong trình duyệt.

## Tạo thư mục dự án

Trước khi bắt đầu, khuyến nghị tạo một thư mục dự án riêng trên máy tính của bạn:

1. Mở thư mục "Tài liệu" hoặc "Desktop"
2. Tạo một thư mục mới, đặt tên `vibe-coding-projects`
3. Bên trong tạo thêm một thư mục con `todo-list` (dự án danh sách công việc)

Cấu trúc thư mục như sau:

```
Tài liệu/
└── vibe-coding-projects/
    └── todo-list/        ← Dự án chương này đặt ở đây
```

::: info 💡 Tại sao phải làm thế này
Đặt dự án ở vị trí cố định, thuận tiện cho bạn tìm lại sau này. Các file do AI IDE tạo ra đều sẽ được lưu trong thư mục này.
:::

## Mở thư mục dự án trong AI IDE

1. Mở AI IDE của bạn
2. Tìm tùy chọn "Mở thư mục" hoặc "Open Folder"
3. Chọn thư mục `todo-list` vừa tạo
4. Xác nhận mở

Bây giờ, AI IDE của bạn sẽ hiển thị một dự án rỗng.

## Xác minh công cụ hoạt động bình thường: Một bài kiểm tra đơn giản

Nhập Prompt sau vào vùng hội thoại để kiểm tra công cụ hoạt động bình thường hay không:

```
Hãy giúp tôi tạo một trang web đơn giản, hiển thị câu "Hello, Vibe Coding!", chữ canh giữa, dùng màu xanh dương.
```

### Kết quả dự kiến

Bạn sẽ thấy:
1. AI bắt đầu tạo code (thường là một file `index.html`)
2. Vùng code hiển thị code HTML được tạo ra
3. Vùng file xuất hiện file mới
4. Vùng preview hiển thị một trang web, có chữ "Hello, Vibe Coding!" màu xanh dương canh giữa

### Nếu mọi thứ bình thường

Chúc mừng! Công cụ của bạn đã sẵn sàng. Bạn có thể chuyển thẳng đến [4.1.4 Danh sách kiểm tra cuối cùng](./4.1.4-checklist.md).

### Nếu gặp vấn đề

| Vấn đề | Nguyên nhân có thể | Cách giải quyết |
|------|---------|---------|
| Vùng hội thoại không phản hồi | Vấn đề mạng hoặc chưa đăng nhập | Kiểm tra kết nối mạng, xác nhận đã đăng nhập tài khoản |
| AI phản hồi rất chậm | Độ trễ mạng | Kiên nhẫn chờ đợi, hoặc kiểm tra tình trạng mạng |
| Code được tạo nhưng không thấy preview | Preview chưa được bật | Tìm nút "Preview" hoặc "Run", hoặc mở file HTML được tạo trong trình duyệt |
| Thông báo hết hạn mức | Hết hạn mức miễn phí | Xem có thể mua thêm hạn mức không, hoặc chờ hạn mức hàng tháng làm mới |
| Giao diện toàn tiếng Anh | Cài đặt ngôn ngữ | Không ảnh hưởng sử dụng, AI có thể hiểu Prompt tiếng Việt |

## Về hạn mức miễn phí

Hầu hết AI IDE đều cung cấp hạn mức miễn phí hoặc thời gian dùng thử. Đối với dự án danh sách công việc trong hướng dẫn này, hạn mức miễn phí thường là đủ.

Nếu hạn mức không đủ:
1. Xem công cụ có tùy chọn trả phí không
2. Tối ưu Prompt của bạn, giảm hội thoại không cần thiết
3. Chờ hạn mức hàng tháng làm mới

## Điểm chính của tiểu mục này

✓ **Công cụ đã cài đặt**: Máy tính của bạn có một AI IDE khả dụng

✓ **Giao diện đã quen thuộc**: Biết vùng hội thoại, vùng code, vùng file, vùng preview ở đâu

✓ **Dự án đã tạo**: Có một thư mục dự án riêng, AI IDE đã mở thư mục này

✓ **Kiểm tra đã qua**: Dùng "Hello, Vibe Coding!" đã xác minh công cụ hoạt động bình thường
