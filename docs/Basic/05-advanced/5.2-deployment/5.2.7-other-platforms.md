# 5.2.7 Các lựa chọn triển khai khác

Ngoài Zeabur và Vercel, còn có một số nền tảng triển khai khác mà bạn có thể chọn. Phần này tóm tắt để bạn tham khảo.

## Netlify: Tải lên kéo thả

Netlify là một nền tảng lưu trữ trang web tĩnh phổ biến khác, đặc điểm lớn nhất của nó là hỗ trợ "tải lên kéo thả".

### Cách sử dụng

1. Mở [Netlify Drop](https://app.netlify.com/drop)
2. Kéo thả thư mục dự án của bạn vào trang trình duyệt
3. Chờ vài giây, triển khai hoàn thành
4. Nhận URL `*.netlify.app`

> **[Đề xuất hình ảnh]**
> Nội dung hình ảnh: Trang Netlify Drop, hiển thị khu vực kéo thả
> Prompt: web interface showing drag and drop zone, file folder being dragged, clean modern design, light background, 8k --ar 16:9

### Ưu và nhược điểm

| Ưu điểm | Nhược điểm |
|---------|-----------|
| Vô cùng đơn giản, chỉ cần kéo thả | Cập nhật cần kéo thả lại |
| Không cần tài khoản GitHub | Truy cập Trung Quốc có vấn đề |
| Triển khai ngay lập tức | Không thích hợp cho dự án thường xuyên cập nhật |

**Phù hợp với**: Trình diễn tạm thời, dự án một lần, không muốn phiền với Git.

### Cách triển khai liên tục

Nếu muốn code cập nhật tự động triển khai, bạn có thể:

1. Đăng ký tài khoản Netlify
2. Kết nối kho lưu trữ GitHub
3. Cấu hình cài đặt build

Như vậy sẽ y hệt Zeabur, Vercel, code cập nhật tự động triển khai.

## GitHub Pages: Hoàn toàn miễn phí

GitHub Pages là dịch vụ lưu trữ trang web tĩnh do GitHub cung cấp, hoàn toàn miễn phí, không cần bất kỳ tài khoản bổ sung nào.

### Nguyên tắc cơ bản

GitHub Pages sẽ chuyển các tệp HTML trong kho lưu trữ của bạn thành trang web công khai.

### Các bước sử dụng sơ lược

1. Đảm bảo kho lưu trữ của bạn là công khai (public)
2. Đảm bảo có tệp `index.html`
3. Vào Settings → Pages trong kho lưu trữ
4. Chọn nhánh cần triển khai (thường là main)
5. Chờ vài phút, nhận URL `username.github.io/repo-name`

### Ưu và nhược điểm

| Ưu điểm | Nhược điểm |
|---------|-----------|
| Hoàn toàn miễn phí | Chỉ hỗ trợ trang web tĩnh |
| Tích hợp sâu với GitHub | Truy cập Trung Quốc không ổn định |
| Hỗ trợ tên miền tùy chỉnh | Cấu hình phức tạp hơn |

**Phù hợp với**: Blog cá nhân, trang tài liệu, trang chủ dự án mã nguồn mở.

::: tip Gợi ý phần nâng cao
Cấu hình chi tiết của GitHub Pages và triển khai tự động bằng GitHub Actions sẽ được giải thích trong phần nâng cao.
:::

## Railway: Mức độ miễn phí ít

Railway là một nền tảng triển khai ứng dụng full-stack, hỗ trợ triển khai front-end, back-end, cơ sở dữ liệu trong một địa điểm.

**Đặc điểm**:
- Hỗ trợ nhiều ngôn ngữ và framework
- Cung cấp dịch vụ cơ sở dữ liệu
- Mức độ miễn phí mỗi tháng $5

**Trang chủ**: [railway.app](https://railway.app/)

**Phù hợp với**: Dự án cần dịch vụ back-end. Đối với danh sách việc cần làm front-end thuần túy, Railway có chút "giết gà bằng dao mổ trâu".

## Render: Triển khai full-stack

Render tương tự Railway, là một nền tảng triển khai full-stack.

**Đặc điểm**:
- Lớp miễn phí hỗ trợ trang web tĩnh
- Hỗ trợ dịch vụ back-end và cơ sở dữ liệu
- Triển khai tự động từ Git

**Trang chủ**: [render.com](https://render.com/)

## Cloudflare Pages: Triển khai cạnh

Cloudflare Pages là dịch vụ lưu trữ trang web tĩnh do Cloudflare cung cấp.

**Đặc điểm**:
- Hoàn toàn miễn phí
- Mạng lưới cạnh toàn cầu tăng tốc
- Tích hợp sâu với hệ sinh thái Cloudflare

**Hạn chế**:
- Truy cập Trung Quốc cần cấu hình bổ sung
- Cấu hình phức tạp hơn Zeabur

**Trang chủ**: [pages.cloudflare.com](https://pages.cloudflare.com/)

## Cách chọn

Đối với phần cơ bản, **không cần lo lắng** về việc chọn giải pháp nào. Khuyến nghị:

- Người dùng Trung Quốc: Dùng Zeabur
- Người dùng ngoài biên giới: Dùng Vercel
- Trình diễn tạm thời: Dùng Netlify Drop

Sau khi hoàn thành học phần cơ bản, khi có nhu cầu khác, hãy khám phá các nền tảng khác.
