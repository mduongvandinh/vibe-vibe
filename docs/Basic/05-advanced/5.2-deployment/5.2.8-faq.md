# 5.2.8 Câu hỏi thường gặp về triển khai

Gặp vấn đề trong quá trình triển khai là bình thường. Phần này tập hợp những câu hỏi thường gặp nhất và cách giải quyết.

## Bảng tra cứu vấn đề nhanh

| Vấn đề | Nguyên nhân có thể | Cách giải quyết |
|--------|----------------|-----------------|
| Triển khai thất bại | Code có lỗi cú pháp | Xác nhận dự án chạy bình thường ở cục bộ trước |
| Trang trống | Đường dẫn tệp khởi động không đúng | Đảm bảo `index.html` trong thư mục gốc dự án |
| Style bị mất | CSS sử dụng đường dẫn tuyệt đối | Sử dụng đường dẫn tương đối (ví dụ: `./style.css`) |
| Hình ảnh không hiển thị | Đường dẫn hình ảnh sai hoặc tên file chữ hoa chữ thường sai | Kiểm tra đường dẫn và tên file chữ hoa chữ thường |
| Chức năng không hoạt động | JavaScript báo lỗi | Mở bảng điều khiển trình duyệt (F12) để xem lỗi |
| Không thể truy cập ở Trung Quốc | Ô nhiễm DNS | Đổi sang Zeabur hoặc MaoZiYun |
| Tải trang rất chậm | Tệp tài nguyên quá lớn | Nén hình ảnh, kiểm tra xem có tệp lớn không cần thiết |
| Cập nhật sau không thấy thay đổi | Bộ nhớ đệm trình duyệt | Làm tươi cứng (Ctrl+F5) hoặc xóa bộ nhớ đệm |

## Giải thích chi tiết vấn đề

### Vấn đề 1: Triển khai thất bại, build báo lỗi

**Hiện tượng**: Sau khi nhấp triển khai, trạng thái vẫn "Building" rồi thành "Failed".

**Các bước xử lý sự cố**:

1. Xem nhật ký build, tìm thông báo lỗi màu đỏ
2. Kiểm tra xem dự án cục bộ có chạy bình thường không
3. Xác nhận tất cả tệp cần thiết đã được gửi lên GitHub

**Nguyên nhân thường gặp**:
- Code có lỗi cú pháp
- Thiếu tệp cấu hình cần thiết
- Phụ thuộc không được cài đặt đúng

**Mẫu yêu cầu AI**:

```
Tôi triển khai dự án trên [Zeabur/Vercel], build thất bại.

Nhật ký build hiển thị lỗi này:
[Dán thông báo lỗi màu đỏ]

Dự án của tôi là [trang web tĩnh HTML/CSS/JS / dự án React / ...].
Chạy ở cục bộ [bình thường / cũng có vấn đề].

Vui lòng giúp tôi phân tích nguyên nhân và đưa ra giải pháp.
```

### Vấn đề 2: Trang trống

**Hiện tượng**: Triển khai thành công, nhưng mở URL là trang trống.

**Các bước xử lý sự cố**:

1. Mở công cụ phát triển trình duyệt (F12)
2. Kiểm tra Console (Bảng điều khiển) có lỗi màu đỏ không
3. Kiểm tra Network (Mạng) có lỗi 404 không

**Nguyên nhân thường gặp**:
- `index.html` không ở thư mục gốc
- Đường dẫn tệp JavaScript sai, script load thất bại
- Sử dụng đường dẫn tuyệt đối, môi trường trực tuyến không tìm thấy tệp

**Cách giải quyết**:

```html
<!-- Sai: Đường dẫn tuyệt đối -->
<script src="/js/app.js"></script>

<!-- Đúng: Đường dẫn tương đối -->
<script src="./js/app.js"></script>
```

### Vấn đề 3: Style bị mất

**Hiện tượng**: Trang có nội dung, nhưng style hoàn toàn sai, hoặc không có style.

**Nguyên nhân thường gặp**:
- Đường dẫn tệp CSS sai
- Tệp CSS không được gửi lên GitHub
- Sử dụng đường dẫn tuyệt đối

**Cách giải quyết**:

```html
<!-- Sai -->
<link rel="stylesheet" href="/style.css">

<!-- Đúng -->
<link rel="stylesheet" href="./style.css">
```

### Vấn đề 4: Chức năng không hoạt động

**Hiện tượng**: Trang hiển thị bình thường, nhưng nút nhấp không có phản ứng, chức năng không hoạt động.

**Các bước xử lý sự cố**:

1. Mở bảng điều khiển trình duyệt (F12 → Console)
2. Kiểm tra có thông báo lỗi màu đỏ không
3. Cố gắng kích hoạt chức năng, xem có lỗi mới xuất hiện không

**Mẫu yêu cầu AI**:

```
Danh sách việc cần làm của tôi sau triển khai, chức năng [thêm nhiệm vụ / xóa nhiệm vụ / ...] không hoạt động.

Bảng điều khiển trình duyệt hiển thị lỗi này:
[Dán thông báo lỗi]

Chạy ở cục bộ, chức năng bình thường.
Vui lòng giúp tôi phân tích nguyên nhân.
```

### Vấn đề 5: Trang web không thay đổi sau cập nhật

**Hiện tượng**: Code đã được đẩy lên GitHub, nhưng trang web vẫn là phiên bản cũ.

**Nguyên nhân có thể**:
1. Triển khai chưa hoàn thành (vào bảng điều khiển kiểm tra trạng thái)
2. Bộ nhớ đệm trình duyệt

**Cách giải quyết**:
- Chờ triển khai hoàn thành (thường 1-2 phút)
- Làm tươi cứng trang: Windows bấm `Ctrl+F5`, Mac bấm `Cmd+Shift+R`
- Mở chế độ riêng tư/ẩn danh để truy cập

## Giải pháp phổ biến

Khi gặp bất kỳ vấn đề triển khai nào, bạn có thể sử dụng mẫu này để yêu cầu AI:

```
Tôi gặp vấn đề khi triển khai trang web.

【Thông tin môi trường】
- Nền tảng triển khai: [Zeabur / Vercel / Netlify / ...]
- Loại dự án: [trang web tĩnh HTML/CSS/JS / React / Vue / ...]
- Chạy ở cục bộ: [bình thường / có vấn đề]

【Mô tả vấn đề】
[Mô tả chi tiết vấn đề bạn gặp phải]

【Thông báo lỗi】
[Dán thông báo lỗi đầy đủ, bao gồm nhật ký build hoặc lỗi bảng điều khiển trình duyệt]

【Phương pháp đã thử】
[Liệt kê các cách giải quyết bạn đã thử]

Vui lòng giúp tôi phân tích nguyên nhân và đưa ra giải pháp.
```

::: tip Hãy nhớ
Gặp vấn đề không cần hoảng sợ. Vấn đề triển khai thường đều có thông báo lỗi rõ ràng, gửi thông báo lỗi cho AI, hầu hết vấn đề đều có thể giải quyết nhanh chóng.
:::
