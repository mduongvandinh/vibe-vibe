# 5.2.5 Các hoạt động hữu ích sau khi triển khai

Triển khai thành công chỉ là bước khởi đầu. Bạn sẽ liên tục cải thiện dự án của mình, cần biết cách cập nhật phiên bản trực tuyến, cách xem trạng thái triển khai, và cách quay lui khi có vấn đề.

## Cách cập nhật trang web

Đây là hoạt động được sử dụng nhiều nhất. Khi bạn sửa code ở cục bộ, muốn phiên bản trực tuyến cũng cập nhật, bạn cần làm:

```
Sửa code ở cục bộ → git add → git commit → git push → Triển khai tự động
```

Các bước cụ thể:

1. Sửa code ở cục bộ (ví dụ: thay đổi màu nút)
2. Dùng GitHub Desktop gửi thay đổi
3. Nhấp vào "Push origin" để đẩy lên GitHub
4. Chờ 1-2 phút
5. Làm tươi trang web của bạn, thấy cập nhật

**Bạn không cần** đăng nhập lại nền tảng triển khai, cũng không cần nhấp vào nút triển khai nào. Cả Zeabur và Vercel đều tự động phát hiện cập nhật code của bạn và tự động triển khai lại.

Đây là sự kỳ diệu của "Triển khai liên tục" (Continuous Deployment).

## Cách xem lịch sử triển khai

Mỗi lần cập nhật code sẽ để lại bản ghi triển khai. Bạn có thể xem trong bảng điều khiển nền tảng triển khai:

### Trong Zeabur

1. Đăng nhập vào bảng điều khiển Zeabur
2. Nhấp vào dự án của bạn
3. Nhấp vào dịch vụ của bạn
4. Tìm thẻ "Lịch sử triển khai" hoặc "Deployments"

Bạn có thể thấy:
- Thời gian mỗi lần triển khai
- Triển khai thành công hay thất bại
- Mỗi lần triển khai tương ứng với commit Git nào

### Trong Vercel

1. Đăng nhập vào Bảng điều khiển Vercel
2. Nhấp vào dự án của bạn
3. Nhấp vào thẻ "Deployments"

Mỗi lần Git Push sẽ tạo một bản ghi triển khai, thậm chí mỗi nhánh đều có liên kết xem trước độc lập.

## Cách quay lui về phiên bản trước

Nếu sau khi cập nhật bạn phát hiện trang web có vấn đề, có thể nhanh chóng quay lui về phiên bản bình thường trước đó.

### Trong Zeabur

1. Tìm lịch sử triển khai
2. Tìm bản ghi triển khai bình thường trước đó
3. Nhấp vào "Triển khai lại" hoặc "Redeploy"

### Trong Vercel

1. Trong trang Deployments tìm triển khai trước đó
2. Nhấp vào thực đơn ba chấm bên phải
3. Chọn "Promote to Production"

Quay lui là ngay lập tức, thường chỉ mất vài giây để có hiệu lực.

## Cách xem nhật ký triển khai

Khi triển khai thất bại, nhật ký là chìa khóa để tìm hiểu vấn đề.

Trong bản ghi triển khai, nhấp vào triển khai cụ thể, bạn có thể thấy:
- Nhật ký build: cách dự án được build
- Nhật ký chạy: đầu ra khi dự án chạy

Nếu thấy thông báo lỗi màu đỏ, bạn có thể sao chép cho AI để phân tích.

## Tên miền tùy chỉnh (Gợi ý nâng cao)

Bây giờ bạn đang sử dụng tên miền miễn phí do nền tảng cung cấp:
- Zeabur: `your-project.zeabur.app`
- Vercel: `your-project.vercel.app`

Nếu bạn muốn tên miền riêng (ví dụ: `my-todo.com`), cần:
1. Mua tên miền (từ Alibaba Cloud, Tencent Cloud, Cloudflare, v.v.)
2. Liên kết tên miền trong nền tảng triển khai
3. Cấu hình bản ghi DNS

Những hoạt động này phức tạp hơn một chút, thuộc loại nội dung nâng cao. Đối với học tập và sử dụng cá nhân, tên miền miễn phí hoàn toàn đủ.

::: tip Gợi ý phần nâng cao
Trong phần nâng cao, bạn sẽ học cách mua và cấu hình tên miền tùy chỉnh, cũng như cách sử dụng Cloudflare để tăng tốc trang web của bạn.
:::
