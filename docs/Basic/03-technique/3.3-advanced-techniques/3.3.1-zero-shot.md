# 3.3.1 Zero-shot Prompting: Nghệ thuật đặt câu hỏi trực tiếp

## Qua phần này bạn sẽ nắm được

- Định nghĩa và nguyên lý hoạt động của Zero-shot
- Tình huống phù hợp để sử dụng Zero-shot
- Cách viết prompt Zero-shot chất lượng cao
- Hạn chế của Zero-shot và cách ứng phó

## Zero-shot Prompting là gì

Zero-shot (không mẫu) nghĩa là: **Không đưa ra bất kỳ ví dụ nào, để AI thực hiện task trực tiếp**.

Đây là cách đặt câu hỏi trực tiếp nhất. Bạn mô tả task, AI dựa vào kiến thức đã học trong quá trình training để đưa ra câu trả lời.

```
Chuyển đổi đoạn code Python 2 sau sang cú pháp Python 3:
print "Hello, World!"
```

AI không cần bạn minh họa "cách chuyển đổi", nó đã "biết" sự khác biệt giữa Python 2 và Python 3. Đây chính là cốt lõi của Zero-shot: **Tận dụng kiến thức sẵn có của AI để hoàn thành task**.

## Tại sao Zero-shot hiệu quả

Các mô hình AI hiện đại trong quá trình training đã "nhìn thấy" lượng dữ liệu khổng lồ: code, tài liệu, hướng dẫn, Q&A. Với các task phổ biến, nó đã có khả năng thực hiện, chỉ cần bạn **mô tả task rõ ràng** là được.

Giống như nhờ đồng nghiệp giàu kinh nghiệm giúp đỡ—bạn không cần dạy họ cách viết code, chỉ cần nói rõ bạn muốn gì.

## Tình huống áp dụng

| Tình huống | Ví dụ | Tại sao phù hợp |
|-----|------|-----------|
| Chuyển đổi code | Python 2 → Python 3 | AI quen thuộc cả hai cú pháp |
| Phân loại văn bản | Đánh giá tâm trạng comment | Task NLP phổ biến |
| Chuyển đổi format | JSON → YAML | Format chuẩn, quy tắc rõ ràng |
| Tạo nội dung | Viết mô tả sản phẩm | Task sáng tạo, không cần ví dụ |
| Giải thích code | Giải thích đoạn code này làm gì | AI có khả năng hiểu code tốt |

**Cách đánh giá đơn giản**: Nếu task này "AI chắc chắn biết", thì dùng Zero-shot.

## Prompt kém vs Prompt tốt

### ❌ Prompt kém

```
Giúp tôi xử lý dữ liệu này
```

**Vấn đề**: Task không rõ ràng. Xử lý nghĩa là gì? Làm sạch? Chuyển đổi? Phân tích?

### ✅ Prompt tốt

```
Chuyển đổi dữ liệu CSV sau sang format JSON, mỗi dòng là một object:

name,age,city
Trần Văn A,25,Hà Nội
Nguyễn Thị B,30,Sài Gòn
```

**Điểm cải thiện**:
- Task rõ ràng: CSV → JSON
- Format rõ ràng: mỗi dòng một object
- Cung cấp dữ liệu đầu vào

### So sánh output

Prompt kém có thể nhận được: "Vui lòng cung cấp dữ liệu cụ thể và yêu cầu xử lý" (AI không thể thực hiện)

Prompt tốt nhận được:
```json
[
  {"name": "Trần Văn A", "age": 25, "city": "Hà Nội"},
  {"name": "Nguyễn Thị B", "age": 30, "city": "Sài Gòn"}
]
```

## Bốn yếu tố để viết tốt Zero-shot

### 1. Động từ task rõ ràng

| Mơ hồ | Rõ ràng |
|-----|------|
| Xử lý đoạn code này | **Refactor** đoạn code này, trích xuất logic lặp lại thành function |
| Xem dữ liệu này | **Phân tích** giá trị bất thường trong dữ liệu này |
| Chỉnh format | **Chuyển đổi** sang format bảng Markdown |

### 2. Yêu cầu output cụ thể

```
❌ "Cho tôi một function"
✅ "Cho tôi một function JavaScript, nhận tham số là array, trả về array đã loại bỏ phần tử trùng"
```

### 3. Điều kiện ràng buộc cần thiết

```
❌ "Viết một thuật toán sắp xếp"
✅ "Viết một thuật toán sắp xếp, yêu cầu: độ phức tạp thời gian O(n log n), không dùng phương thức sort có sẵn"
```

### 4. Dữ liệu đầu vào rõ ràng

Nếu task cần xử lý dữ liệu, cung cấp trực tiếp trong prompt.

## Kỹ thuật nâng cao: Tăng cường hiệu quả Zero-shot

### Role Prompting (Thiết lập vai trò)

Gán cho AI một vai trò, có thể khiến nó trả lời từ góc độ cụ thể.

```
Bạn là một kỹ sư frontend có 10 năm kinh nghiệm.
Vui lòng review đoạn code React sau, chỉ ra các vấn đề hiệu suất tiềm ẩn:
[code]
```

### Chỉ định format output

Nói rõ cho AI format bạn mong muốn.

```
Phân tích phản hồi người dùng sau, trích xuất các vấn đề chính.
Format output:
- Vấn đề 1: [mô tả]
- Vấn đề 2: [mô tả]
...
```

## Ví dụ thực chiến: Dự án todo list

Tiểu Lý muốn AI giúp viết một function format ngày tháng.

### Prompt Zero-shot

```
Viết một function JavaScript có tên formatDate, chức năng như sau:
- Input: object Date
- Output: chuỗi đã format, format là "YYYY年MM月DD日"
- Ví dụ: input new Date('2024-03-15'), output "2024年03月15日"
- Yêu cầu: tháng và ngày không đủ hai chữ số thì thêm số 0
```

### Output của AI

```javascript
function formatDate(date) {
  const year = date.getFullYear();
  const month = String(date.getMonth() + 1).padStart(2, '0');
  const day = String(date.getDate()).padStart(2, '0');
  return `${year}年${month}月${day}日`;
}
```

## Hạn chế của Zero-shot

| Hạn chế | Biểu hiện | Giải pháp |
|-----|------|---------|
| Format không ổn định | Mỗi lần output format khác nhau | Dùng Few-shot cung cấp ví dụ |
| Sai sót trong suy luận phức tạp | Logic nhiều bước dễ bỏ qua | Dùng Chain of Thought |
| Không hiểu yêu cầu cụ thể | Output không phù hợp với quy chuẩn dự án | Bổ sung context trong prompt |

**Tiêu chuẩn đánh giá**: Nếu Zero-shot liên tục hai lần output không thỏa mãn, cân nhắc chuyển sang kỹ thuật khác.

## Template có thể sao chép

### Template chuyển đổi code

```markdown
Chuyển đổi code [ngôn ngữ/phiên bản nguồn] sau sang [ngôn ngữ/phiên bản đích]:

[nội dung code]

Yêu cầu:
- Giữ nguyên chức năng
- Tuân theo best practices của [ngôn ngữ đích]
```

### Template tạo nội dung

```markdown
Bạn là [định vị vai trò].

Task: [mô tả task cụ thể]

Yêu cầu:
- [yêu cầu 1]
- [yêu cầu 2]

Format output: [giải thích format]
```

### Template review code

```markdown
Review code sau, từ góc độ [chiều review] chỉ ra vấn đề:

[nội dung code]

Format output:
1. Vấn đề: [mô tả] | Vị trí: [dòng số] | Đề xuất: [phương án sửa]
```

## Những điểm chính của phần này

✓ **Bản chất của Zero-shot**: Tận dụng kiến thức có sẵn của AI, thực hiện task trực tiếp

✓ **Tình huống áp dụng**: Task mà AI "chắc chắn biết"—chuyển đổi, phân loại, tạo nội dung

✓ **Chìa khóa viết tốt Zero-shot**: Động từ rõ ràng + Output cụ thể + Ràng buộc cần thiết

✓ **Hạn chế**: Format không ổn định, suy luận phức tạp dễ sai

✓ **Kỹ thuật tăng cường**: Thiết lập vai trò, chỉ định format output

Phần tiếp theo, chúng ta sẽ học cách "dạy" AI bằng ví dụ—Few-shot Prompting.
